# モスの森 素材別・透過PNG依頼文（ChatGPT 用）

1回の依頼 = 1素材（またはその状態違い一式）。毎回、下の【共通前置き】を先頭に貼り、
スタイルシート（`docs/art/reference/moss/00_style_sheet.png`）と素材シート
（`05_asset_sheets.png`）を添付してください。

## 【共通前置き】（毎回コピー）

```
添付のスタイルシートと素材シートと同じ画風（やや斜め見下ろしのピクセルアート調の手描き、
苔むした古い森、落ち着いた緑と灰色、少量の青白い魔法光）で、ゲーム用素材を1点だけ作ってください。

必須条件:
- 背景は完全な透明（アルファ付きPNG）。市松模様、白/黒/緑の背景、地面の影板、枠線は焼き込まない
- 対象物は1点のみ。素材シート形式・複数並べ・文字・ラベル・数字・透かしは入れない
- 画像の周囲に十分な余白（上下左右 約8%）を取り、見切れさせない
- 足元（接地面）が画像下端の中央付近に来る構図。柔らかい接地影は物体に密着した小さなもののみ可
- 光は左上から。他素材と並べても浮かないよう彩度を抑える
- 指定サイズの縦横比に合わせる（ピクセル寸法が守れない場合は比率優先。後で当方で拡縮します）
- 出力は PNG ファイルとしてダウンロードできる形で
```

## 検収チェック（当方）
1. 実アルファがあるか（四隅が透明）／市松模様が焼き込まれていないか
2. 比率・向き・接地位置／余計な断片・ゴミが無いか
3. 合格 → `img/field/moss/<名前>.png` に置き、`manifest.json` に `{"match":"^名前","file":"名前.png","w":..,"h":..}` を追加

`w×h` はゲーム内ワールドpx（下端中央アンカー）。画像は比率が合えば何pxでも可（推奨は2倍〜4倍）。

## 優先度1: A3 古樹の領域（最重要）

### 1-1. a3_seal（風の結界）— 3状態、同一構図・同一サイズ
比率 144:90（横長）。ワールド 144×90。
```
【共通前置き】
素材: 古い遺跡の通路をふさぐ「風の結界」。地面に沿って横に長い、淡い青緑の光の壁と
風紋の帯（半透明の光の膜、上端が少し揺らぐ）。両端に低い石の台座。
同一の構図・同一サイズで次の3枚を別ファイルで:
  a3_seal_closed … 結界が張られ、光が安定して満ちている
  a3_seal_corrupted … 結界に紫黒い苔の侵食とひびが入り、光が弱く濁っている
  a3_seal_opening … 結界が中央から左右に割れて開きかけ、光の粒が舞う
中央が通路の幅。台座は3枚で完全に同じ位置。
```
追加: `a3_seal_opening` は6コマ（開き度 0→100%）が理想。まず3状態で可。

## 依頼のコツ
- 失敗（背景が付く・市松模様が焼き込まれる）時の追い依頼: 「背景を完全な透明にしたPNGで出し直してください。市松模様に見える部分も実際には透明にしてください」
- 状態違い（a3_seal 等）は必ず1回の依頼で一緒に作ると構図が揃います。
- 複数枚が出てきたら、1枚ずつ別ファイルでダウンロードして送ってください（ファイル名は上表の名前で）。
