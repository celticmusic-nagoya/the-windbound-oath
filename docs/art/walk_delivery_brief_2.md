# 次回納品ブリーフ: エイダン / フィオナ 歩行・停止 補填(2026-10-11 時点)

前回(`aidan_fiona_walk.zip`)の組み込み結果、歩行がぎこちなく見える原因は「コマ数・ポーズ不足」。以下を補填してください。取り込みは `tools/field/install_hero_frames.py` が自動で正規化します(キャンバス・サイズ・足元位置は不問)。

## 共通仕様
- 1コマ = 透明背景 RGBA PNG 1枚(背景色・市松・影の焼き込み不可)。画面端に絵が接しないこと。
- 全コマで**同一キャラ縮尺・同一の見た目**(服・髪・持ち物・剣/杖の持ち手)。足元(最下端)が揃っていると良いが、ズレは取り込み側で補正。
- ファイル名は下記の最終名(`<hero>` = `aidan` / `fiona`)で納品。名前を付けずに納品された場合は内容から振り分けるが、手間が増える。
- 歩行は**4コマ/方向**(右足前→立ち→左足前→立ち、の1周)。6コマまで可(全方向同数)。
