# 高さ Phase 2 先行3素材: 最終生成プロンプトと検収チェックシート

STATUS: 依頼文・検収表の整備のみ。画像生成は ChatGPT 側（作者）。**正式採用・ゲーム組込は納品後の品質確認を経て作者が判断。** 設計は `height_phase2_render_spec.md` v2（承認済み）。対象: `height_cliff_rock_01`（PNG 160×112）、`height_cliff_ruin_01`（PNG 160×112）、`height_foreground_canopy_01`（PNG 280×300）。

## 1. 進め方
1. ChatGPT の新しいチャットを1つ作り、**同じチャットで3点を順に**依頼する（画風を揃える）。
2. 最初に参考画像として `img/field/moss/art/` の既存素材を添付する: `rock_moss_01.png`・`rock_moss_02.png`（岩の質感）、`ruins_stone_01.png`・`ruins_stone_02.png`（石積み）、`tree_ancient_sentinel_01.png`（葉の質感）。**参考であり、そのコピー・置換の依頼ではない**。
3. §2 の共通前置きを貼り、続けて素材ごとのプロンプト（§3〜§5）を別々の依頼として送る。
4. 納品は `docs/art/reference/height/` ではなく**作者側の保管先**（容量方針により大きな画像をゲーム repo に置かない）。Claude Code は納品された画像を検収チェック（§6）にかけ、結果を報告する。
5. 生成サイズについて: 画像生成は固定サイズ（例: 1536×1024）で出ることが多い。**縦横比を指定どおり（10:7 / 14:15）にした大きな原稿**を受け取り、検収前に**指定 PNG 寸法へ縮小**する（縮小方法とツールを記録）。縮小後に §6 を実施する。

## 2. 共通前置き（毎回貼る）
```text
添付の既存素材（rock_moss / ruins_stone / tree_ancient_sentinel）と同じ画風で、ゲーム用の新規素材を1点だけ作ってください。
参考画像は画風・質感の見本です。構図や形をコピーしたり、参考画像を置き換えたりしないでください。
- 画風: 高精細なピクセルアート調の手描き、やや斜め俯瞰の2D JRPGフィールド素材。苔むした古い森、深緑・苔緑・灰色、控えめな古代ケルト風。左上からの柔らかい光。低〜中彩度、中明度（真っ黒な潰れ・純白の飛びなし）。昼・夕・夜の色補正をかけても輪郭が読めること。
- 対象物1点だけ。素材シート／複数並べ／文字／数字／透かし／人物／既存キャラ／地面の影板／光源／背景を描かない。
- 背景は完全な透明（実アルファ付きPNG）。白い縁取り、市松模様、ぼかした影の板を焼き込まない。透明が出力できない場合は、素材と無関係な単色マゼンタ（#FF00FF）一色の背景にしてください（素材内にマゼンタ系の色を使わない）。
- 指定の縦横比を厳密に守ってください。最終PNGは後で指定寸法に縮小します。
```

## 3. height_cliff_rock_01（PNG 160×112、縦横比 10:7）
```text
【共通前置き】
素材: 苔むした岩の崖の「正面」1段分。縦横比 10:7（最終 160×112 px、ゲーム内 幅80×高さ56）。
左右に何枚も並べて連結できる岩壁の部品。上辺は高台の天端、下辺は低地との接地線。
- 横方向に走る古い割れ目・層状の岩肌と、薄い苔。厚い丸岩を積み上げない。
- 左右の端まで岩肌を描き、端に黒い縁線・透明な余白・苔の突起を置かない（2枚並べて継ぎ目が見えないこと）。左右の端の色・模様の高さをそろえる。
- 上辺は天端として水平に近く終え、上に木・草・高台の床を描かない。下辺は接地線で、地面や影を描かない。
- 斜め俯瞰でも「高さ1段の壁」が読めること（壁面が画像の全高いっぱい）。
- 色の目安: 中明度の灰緑の岩、薄い苔緑。
```

## 4. height_cliff_ruin_01（PNG 160×112、縦横比 10:7）
```text
【共通前置き】
素材: 苔むした古代遺跡の石積みの崖の「正面」1段分。縦横比 10:7（最終 160×112 px、ゲーム内 幅80×高さ56）。
- 低彩度の灰色の石、摩耗した不揃いな石組み、細い蔦と薄い苔。文字・ルーン・発光は描かない（夕・夜の色補正で色が暴れないよう無彩色寄り）。
- 左右に繰り返して連結できる端面にする。端に黒い縁線や透明な余白を置かず、左右の端の石の目地の高さをそろえる。
- 上辺は天端（水平に近い）、下辺は低地の接地線。高台の床・地面・人物を描かない。
- 既存の ruins_stone と似すぎない、壁としての石積み（積み方は整った層状）。
```

## 5. height_foreground_canopy_01（PNG 280×300、縦横比 14:15）
```text
【共通前置き】
素材: 道の手前に重なる古木の「樹冠だけ」。縦横比 14:15（最終 280×300 px、ゲーム内 幅140×高さ150）。
- 葉の見える範囲は幅いっぱい・高さの上から80%（最終では上 240px）。**画像の下 20%（最終 下 60px）は完全に透明**にする（葉の下端を下辺から離す）。
- 幹・根・枝の付け根・地面・影・人物を描かない。葉と小枝だけ。葉の間と外周は本当の透明（隙間から背景が抜ける）。白い縁取りや市松模様を焼き込まない。
- 深緑と苔緑に少量の黄緑、柔らかい左上光。中明度。黒い大面積や純白の木漏れ日を作らない。
- 林全体や背景は描かず、葉冠1点だけ。
```

## 6. 検収チェックシート
判定欄は納品後に Claude Code が記入する（自動測定の値と目視を分けて記録）。「自動」は数値で測れる項目、「目視」は人が見る項目。

### 6.1 共通
| # | 項目 | 方法 | 合格基準 | 判定 |
|---|---|---|---|---|
| C1 | PNG 寸法 | 自動 | 160×112 / 160×112 / 280×300 ちょうど（world 枠×2）。縮小方法を記録 | |
| C2 | 形式 | 自動 | RGBA、8bit。背景が実アルファで透明（マゼンタ背景の場合は除去後に残渣なし） | |
| C3 | 白縁・マゼンタ残渣 | 自動 | α<255 かつ輝度>0.9 の画素が全α境界画素の 2% 以下。マゼンタ系の画素 0 | |
| C4 | 輝度（不透明画素） | 自動 | 平均 0.35〜0.46、p5 ≥ 0.04、p95 ≤ 0.90（既存素材の実測: 平均 0.37〜0.43）。外れる場合は理由を記録 | |
| C5 | 彩度 | 自動 | 平均 0.45〜0.80（既存: 0.48〜0.76）。極端な高彩度なし | |
| C6 | 焼き込みなし | 目視 | 地面・影板・人物・文字・光源・背景がない | |
| C7 | 画風整合 | 目視 | 既存の rock_moss / ruins_stone / tree_ancient_sentinel と並べて違和感がない（線の太さ・質感・陰影の向き=左上光） | |
| C8 | 色補正耐性 | 自動+目視 | DEV の昼・夕・夜グレードを掛けた画像で輪郭が読める（黒潰れ・白飛びなし） | |
| C9 | 既存素材を変更していない | 自動 | `git diff` で `img/` の既存ファイル 0 件（納品物は別保管先） | |

### 6.2 崖2点（cliff_rock / cliff_ruin）
| # | 項目 | 方法 | 合格基準 | 判定 |
|---|---|---|---|---|
| K1 | 連結（左右） | 自動 | 左端列と右端列の色差（平均 ΔRGB）が画像内の隣接列の平均色差の 2 倍以内。**横に2枚並べた画像**で継ぎ目が見えない（目視） | |
| K2 | 端の不透明 | 自動 | 左右端の列の不透明率 ≥ 98%（連結辺に透明余白なし） | |
| K3 | 壁の高さ | 自動+目視 | 不透明領域の縦が画像の全高の 95% 以上（56 world の壁面が読める）。上辺は水平に近い（天端） | |
| K4 | 焼き込み禁止 | 目視 | 上に木・草・高台の床なし／下に地面・影板なし | |
| K5 | 黒い縁線 | 自動 | 左右端の暗画素（輝度<0.08）が端列の 5% 以下 | |
| K6 | ruin 固有 | 目視 | 文字・ルーン・発光なし。無彩色寄り（彩度平均が rock より低い、0.65 以下が目安）。既存 ruins_stone の置換ではない | |

### 6.3 樹冠（foreground_canopy）
| # | 項目 | 方法 | 合格基準 | 判定 |
|---|---|---|---|---|
| N1 | 下部の透明 | 自動 | 下 60px（最終）の α>0 の画素が 0（アンカーまで 30 world の空き） | |
| N2 | 葉の範囲 | 自動 | α>0 の外接矩形が x 全幅の 90% 以上・y 0〜240px 内に収まる（幅 140×高さ 120 world の葉冠） | |
| N3 | 実透過の隙間 | 自動 | 葉の内部に α=0 の連結領域（枝間の抜け）が存在し、背景色が出ていない | |
| N4 | 幹・根・影なし | 目視 | 幹・根・地面影・人物・林全体・背景が描かれていない | |
| N5 | 色の幅 | 自動 | 深緑〜黄緑の幅。黒（輝度<0.08）の面積 5% 以下、純白（輝度>0.95）の面積 1% 以下 | |
| N6 | 現 DEV 樹冠との整合 | 目視 | 登録枠 140×150、アンカー=足元 y470、葉下端 440（`dev_height_proto` の tree_canopy 140×120 と重なる位置）で actor を覆う見え方になる想定 | |

### 6.4 仮置き確認（組込ではない）
