## ART-06B 歩行仕様（`js/field/field-walkers.js` と実測）

| 項目 | 仕様 |
|---|---|
| 使用箇所 | 一般兵士の巡回NPCは2体: 砦の城壁 `w_f2_lookout`（(2440,340)⇄右へ70）、王都城前広場 `w_r2_herald`（(2300,2600)⇄左へ70）。どちらも**水平移動のみ**、速度24 world/s、休止2〜4.5秒 |
| コマ構成 | 停止中（休止・プレイヤーが56px以内）＝`rule.file`（正面idle）。歩行中＝walk 6コマをループ |
| 表示タイミング | 既定7fps＝**1コマ約143ms、1周約0.86秒**（実測で約150ms刻みを確認）。1周の移動量は約20.6 world |
| ループの再開 | 歩行用の時計は停止中もリセットされず、**再開時は前回止まったコマから続く**。どのコマから始まっても破綻しない絵にする |
| 方向・反転 | 横移動の向きだけで判定し、左へ動くと**画像全体を左右反転**（`scaleX(-1)`）。反転は停止中のidleにもそのまま残る。上下専用のコマはない |
| 足元anchor | 全コマ同じ箱（47.6×71.4 world）に、足元を下中央にそろえて描く。キャンバスは**112×168px**（idleと同じ縮尺0.425 world/px） |
| 旧6コマの動き | 正面向き。1・4コマが基本姿勢、2・5コマで体が4px（約1.7 world）上がり、3・6コマは中間。脚を左右交互に出す。槍は常に地面まで届いている |
| idle→歩行の切替 | 補間なしで即座に切り替わる。idleと歩行で**縮尺・接地線・持ち手が同じ**でないと、切り替えのたびに跳ねて見える |

**決定事項（仕様）**

- 表示サイズ47.6×71.4 world・112×168キャンバスは維持（ユーザー決定）。
- 採用idleの房が上端（y=0）に接しているため、**歩行コマはidleより上に出さない**。上下の弾みは「接地の瞬間に体が2〜3px沈む」形で付け、浮き上がる方向には付けない（旧コマのように上へ4px上げると房が切れる）。
- 向きは**正面向きの歩行**とする（採用idleと同じ向きで、同一人物の再現性が最も高い。現行の旧コマとも同じ）。代案として右向き3/4の歩行も考えられるが、idleとの見た目の差が大きいので今回は採らない。

## ART-06C ChatGPT向け 制作仕様

### 参照（必ず添付して渡す）

1. 正本: `img/field/moss/props/npc_soldier_idle_v2.png`（112×168、採用済みの正面idle）
2. ガイド: `docs/art/candidates/art-06/walk_guide_112x168_x4.png`（接地線 y=165・中心 x=56・兜の頂部 y≈16・房の上端 y=0・槍の軸 x≈18）
3. タイミングの参考: `docs/art/candidates/art-06/walk_reference_strip_x2.png`（採用idle＋旧6コマ。**旧コマは脚の順番と弾みの参考のみで、デザイン・持ち手は使わない**）

### 必須条件

- 採用idleと**同一人物**。顔・兜（鋲・赤い房）・鎧・青いマントと金の縁・ベルトとポーチ・赤い盾と金の紋・槍・茶色のブーツのデザインと配色を変えない。新しい装備を足さない。
- 頭身・縮尺はidleと同じ（全コマで兜の頂部 y≈16、ただし沈み込みのコマは18〜19まで下がってよい）。
- 持ち手はidleと同じ: **槍は画像の左（キャラクターの右手）で垂直に持つ／盾は画像の右（キャラクターの左腕）**。槍の長さ・穂先の形を変えず、穂先はキャンバス内に収める。
- 向きは正面（カメラ向き）。歩く方向への体の傾きは付けない（左右はゲーム側の反転で表現する）。
- 足元: 接地している足の靴底は **y=165**。足元の中心は x=56±2。コマごとに体を左右へずらさない（移動はゲーム側で行う）。
- 背景は**完全透過**（外側α0、本体は**α255**。半透明は輪郭のなめらかさ分だけ）。チェッカー柄や影の焼き込みはしない。
- 手足・装備の不自然な変形（腕が伸びる・盾の形が変わる・槍が曲がる・指の破綻）を禁止。

### 6コマの定義（7fps・ループ）

| コマ | ポーズ | 弾み |
|---|---|---|
| walk_01 | 右足を前に出して接地（左足は後ろ、つま先で地面に触れる） | 沈み込み 2〜3px |
| walk_02 | 右足に体重、左足が持ち上がり前へ通過中 | 基本の高さ（idleと同じ） |
| walk_03 | 左足が右足を追い越す直前、両肩は水平 | 基本の高さ |
| walk_04 | 左足を前に出して接地（walk_01の左右逆） | 沈み込み 2〜3px |
| walk_05 | 左足に体重、右足が通過中（walk_02の左右逆） | 基本の高さ |
| walk_06 | 右足が左足を追い越す直前（walk_03の左右逆） | 基本の高さ |

マントの裾と房は、接地のコマで少し遅れて揺れる程度にする（シルエットが大きく変わらないこと）。槍を持つ腕は大きく振らず、盾の側の腕を小さく前後させる程度。

### 納品形式

- **1コマ＝1ファイル**の透過PNG: `soldier_walk_01.png` 〜 `soldier_walk_06.png`、各112×168。
- 縮小前の原寸版（4倍の448×672を推奨）も同じ構図で添付する（余白や品質の調整用）。
- アニメーション用の横並びシート（6コマ）を追加で付けてもよい（ASSET_GENERATION_RULESのアニメーション例外。スライス用であることを明記）。

### 受け入れ検査（納品後にClaude/Codexが実施）

1. 寸法112×168・RGBA・外側α0・本体α255（idleと同じ検査）
2. 全コマ、接地している足の靴底がy=165、中心がx=56±2
3. idleとの差分: 顔・兜・盾・槍の形と色（目視、2倍拡大）
4. 7fpsのループ再生（PC・Android縦横相当）、どのコマから再開しても破綻しないこと、左右反転時の見え方
5. ユーザーの視覚承認 → その後に実装（manifestの`walk.file`を新しい6コマへ。旧6コマは削除せずrollback用に残す）
