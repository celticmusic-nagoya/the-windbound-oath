# エイダン 不足歩行アセット 生成指示文(ChatGPT用・剣あり統一)
作成: 2026-10-12 / 必要数: 計18コマ(側面4 + 前斜め6 + 後ろ斜め6 + 斜め待機2)。右向き斜めは左右反転で作るため、左向きだけ生成する。
参照画像として、毎回 `aidan_front/front_idle_standing.png` と `aidan_side6/side_right_sheet.jpg`(旧・剣あり)を添付すること。

## 共通ブロック(各プロンプトの先頭に貼る)
同一キャラクター「エイダン」(17歳の人間の剣士)のフィールド用歩行スプライトを描いてください。添付の参照画像とキャラクターデザインを完全に一致させます。
- 外見: 茶〜金色のくしゃっとした髪、緑の瞳、深緑のフード付きマント(金の縁取りと模様)、アイボリーの上衣、アンティークゴールドの肩当て・籠手・ブーツ、茶色の手袋と革ポーチ。
- 装備: 鞘に納めた長剣を背中に斜めに背負い、剣の柄が肩越しに見える(参照画像と同じ位置・同じ柄のデザイン)。全コマで剣の有無・位置・大きさを統一する。手には何も持たない。
- 画風: 参照画像と同じ高精細アニメ調の塗り(線の太さ、陰影、色味を揃える)。
- 背景: 完全な純白(#FFFFFF)の単色。影・地面・グラデーション・文字・枠線・番号は入れない。
- 配置: 各コマは重ならず、コマ同士の間に十分な余白を空ける(マントの端が隣のコマに触れない)。全コマで同じ縮尺・同じ頭の大きさ・足元の高さ(接地ラインの水平位置)を揃える。全身を切らずに収める。
- 出力: 1枚の画像に指定のコマを左から右へ順に横一列で並べる。

## A. 側面・右向き歩行 4コマ(横一列)
(共通ブロックの後に)
完全な横向き(右向き)で歩く4コマ。1歩ぶんのサイクルとして次の順に描く。
1. 接触: 前足のかかとが接地し、後ろ足は爪先で蹴り出し。
2. 通過: 後ろ足が地面から離れ、膝を曲げてかかとが高く上がり、ブーツの靴底が見える。
3. 後ろ足が最も高く上がった瞬間(膝が前へ出る)。軸足はまっすぐ接地。
4. 後ろ足が前へ振り出され、次の接触の直前。
どのコマも「後ろ足が上がっている」ことが一目で分かる、左右の足が交互に動いて見える描き方にする。上体はほぼ同じ高さで、体幹の位置が左右にぶれないこと。マントは進行方向と逆(左)へなびかせるが、コマ間で形を大きく変えない。

## B. 前斜め・左向き歩行 6コマ(横一列)
(共通ブロックの後に)
前方から見て斜め(約45度)で、画面の左手前へ歩いてくる6コマ。顔と体は画面の左下を向く。右足と左足が交互に出る1サイクル(接触→通過→接触を左右それぞれ)で描く。後ろ足(蹴り出す足)のかかとが上がって見えるコマを少なくとも2コマ含める。手前の足と奥の足が重なっても、どちらの足か分かるようにブーツの向きを描き分ける。背中の剣の柄は、斜め前から見て肩の後ろにわずかに見える形にする。

## C. 後ろ斜め・左向き歩行 6コマ(横一列)
(共通ブロックの後に)
後方から見て斜め(約45度)で、画面の左奥へ歩いていく6コマ。背中・マント・背負った剣が主に見え、頭は進行方向(左)へ少し向く。左右の足が交互に出る1サイクルで描き、後ろ足のかかとが上がって見えるコマを少なくとも2コマ含める。背中の剣は鞘全体が斜めに見える形で全コマ同じ位置にする。

## D. 斜め待機 2コマ(横一列)
(共通ブロックの後に)
直立して静止した待機ポーズを2コマ。左から「前斜め・左向き」「後ろ斜め・左向き」(B・Cと同じ角度と縮尺)。足は肩幅に揃え、腕は自然に下ろす。
