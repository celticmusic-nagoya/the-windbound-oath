## 方式（`tools/art/make_art08c_aidan_side.py`）

監査（ART-07B）の結論は、横向き4コマに「2歩目の通過コマがない」ことと、「手前と奥の脚が同じ描き方」であること。描き直しをせずにできる範囲で、次のように試作した。

1. 奥の脚に影を付ける（明るさ0.66倍・少し彩度を下げる）。手作業で測った脚の範囲のうち、脚の色（ブロンズの装甲・茶色の布）の画素だけを暗くする。緑や白のマントには触れない。動かす・描き足す画素はない。
2. **05＝02の役割を入れ替えたもの**（接地している前足を奥＝影、持ち上がる後ろ足を手前＝明るく）。
3. **06＝03の役割を入れ替えたもの**（接地している足を奥＝影、膝を上げて前へ振る足を手前＝明るく）。
4. ループ全体を通して、手前の脚Aは常に明るく、奥の脚Bは常に影になるようにした（01は後ろ足、02は持ち上がる足、03は前へ振る足、04は前足がB）。そのため、6コマの再生確認には01〜04にも同じ影を付けた版を使う（スクリプトで再生成できる）。

## 品質条件との照合

| 条件 | 試作で満たせたか |
|---|---|
| 顔・髪・服・剣・ポーチの同一性 | ○（脚以外の画素は変更なし） |
| 左右の脚の交互接地 | ○（手前と奥の脚が明るさで見分けられ、6コマで「A接地→B通過→B接地→A通過」が一巡する） |
| 6→1のループ境界 | ○（06で前へ振った手前の脚が、01でそのままかかと接地する） |
| かかと着地・つま先での蹴り出し | △（既存の01・04のかかと接地をそのまま使う。蹴り出しを強める描き直しはしていない） |
| 膝・足首の自然な動き | △（既存の通り。ただし03では奥の脚が手前の脚の前に重なって描かれている。奥の脚として正しくするには重なり部分の描き直しが必要） |
| 腕と脚の逆方向の連動 | ✕（05・06は02・03と上半身が同じなので、2歩目では腕の振りが脚と同じ側になる） |
| マントの遅延した揺れ | ✕（05・06のマントは02・03と同じ。1コマ遅れの揺れは描き直しが必要） |

→ **判定 ADJUST**: 脚の交互動作とループのつながりは改善できるが、既存画像の加工だけでは品質条件のすべては満たせない。

## 新規描画が必要な範囲（ChatGPT等への依頼範囲）

1. **05・06の上半身**: 腕の振りを02・03と逆にする（手前の腕を後ろへ、奥の腕を前へ）。
2. **マントの裾**: 05・06（と、できれば01〜04）で、体の動きから1コマ遅れた揺れを描く。
3. **03・06の脚の重なり**: 奥の脚が前へ振られるコマ（03）では、奥の脚を手前の接地脚の後ろに描く（重なって隠れる部分の描き直し）。
4. **蹴り出し**: 02・05で、後ろ足のつま先が地面を押す形を少しはっきりさせる。
5. 左向きも同じ構成で別に描く（現行どおり反転では作らない）。

技術条件は現行と同じ（2048×1280の透過PNG、足元anchor (1024,1230)、頭頂≈126〜134、靴底≈1228）。仕上がった6コマは、`STRIDE_CYCLE`を絵の歩幅×2（≈52、ART-08B）で再生して確認する。

再現: `python3 tools/art/make_art08c_aidan_side.py && python3 tools/art/preview_art08c.py`
