## 方式（`tools/art/make_art06r_walk.py`）

キャラクターは描き直していない。正面idleの画素を、次の3つに分けて動かしただけ（`candidates/art-06r/parts_split_x3.png`）。

1. **上半身・装備**: 頭部・兜・房・鎧・マント・チュニックの裾・盾・槍。脚を除いた残りすべて
2. **画面左の脚**（キャラクターの右脚）: 膝当て＋ブーツ（x33〜54、y131〜167）
3. **画面右の脚**（キャラクターの左脚）: 膝当て＋ブーツ（x60〜92、y129〜167。右マントの裾は含めない）

- 脚は上半身より奥に描く。持ち上げた脚は太ももがチュニックの裾の下に隠れ、足だけが上に見える。
- **前に出した足**はidleの位置のまま、靴底は接地線（y=165）に乗せる。
- **後ろ足**は9px（約3.8 world）持ち上げ、縦を0.93倍に縮め、明るさを0.82倍にして、奥にある足に見せる。
- 接地のコマなので、上半身を1px沈める。上には弾ませない（房がもともと上端に接しているため。1pxなら槍の石突きも画面内に収まる）。
- 新しく描いた画素はない。脚が動いて空いた場所は透過のまま（地面が見える）。脚を切り離したときに出る、αの小さい輪郭の粒や小さな断片は取り除いた。

## 所見

- 左右の足が交互に前へ出ていることは、静止画で明確に分かる（前の足は接地線、後ろの足は約4 world上）。
- 膝当てとブーツは回転させず平行移動・縦の縮小だけなので、足首や膝が逆を向いたり、靴が裏返ったりしない。
- 実際の表示サイズ（等倍）では、違いは後ろ足が少し上がる程度で控えめ。これ以上はっきりさせると、正面向きの1枚絵では足が浮いて見えやすい。
- 正面向きなので、前足を手前（画面の下）へ大きく出すことはできない（キャンバスの下端と接地線が2pxしか離れていない）。
- 残りの4コマ（walk_02/03/05/06）は承認後に、同じ部品で作る。中間の高さ（後ろ足を半分だけ上げる、通過中の足を少し上げる）で、上半身は沈めない予定。

## 第2段階: 6コマ候補（PR #106 コメント 2026-11-02 の指示による）

**変更点**: 「前の足は接地しているのに後ろ足が浮いて見える」という指摘を受け、接地コマ（01・04）の後ろ足の持ち上げを **9px → 4px** に下げた（かかとが浮いて奥にある程度）。そのため walk_01／walk_04 は第1段階と画素が異なる（前の版はgit履歴に残っている）。

### 足の高さの流れ（左右それぞれ連続した弧）

| | 01 | 02 | 03 | 04 | 05 | 06 |
|---|---|---|---|---|---|---|
| 画面左の脚（右足） | 接地 0 | 接地 0 | 接地 0 | 後ろ 4 | 通過 7 | 前へ 3 |
| 画面右の脚（左足） | 後ろ 4 | 通過 7 | 前へ 3 | 接地 0 | 接地 0 | 接地 0 |
| 上半身 | 1px沈む | 0 | 0 | 1px沈む | 0 | 0 |

単位はpx（1px＝0.425 world）。「後ろ」は縦0.95倍・明るさ0.86倍、「通過」は0.93・0.90、「前へ」は0.98・0.97。どのコマでも、少なくとも片足は接地線（y=165）に乗っている（重心が抜けるコマはない）。軸足は 01〜03が右足、04〜06が左足で、03→04・06→01で入れ替わる。

### 所見

- 左右の足が交互に、接地 → 後ろ → 通過 → 前へ と一続きに動き、ループのつなぎ目（06→01）でも高さが急に跳ばない。
- 上半身は接地コマで1px沈むだけで、兜・房・盾・槍の形と持ち手は全コマ同一。
- 正面向きの1枚絵を部品として動かす方式なので、足を手前へ踏み出す（大きく見せる）表現はできない。歩きの印象は「足が交互に上がる」程度で控えめ。
- idleから歩行に切り替わるとき、後ろ足が最大4px上がるだけなので跳ねは小さい。反転しても足の交互動作は保たれる。
