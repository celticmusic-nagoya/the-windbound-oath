## 4. Operational checklist (all AI agents)

1. Read current main AGENTS/index/registry/rules and scoped owner PR; compare exact source revision, dependency pins, prior receipt and live lease. Distinguish policy, test fixtures and real production qualification.
2. Prefer reusable successful output over a rerun. For changed inputs, qualify only the affected component with a cheap preflight and bounded regression. Keep source immutable, isolate working copies and validate rights.
3. Use one existing authorized writer. If a failure occurs, record run/job/stage, exact input and code revision, diagnosis/confidence, one causal change and stop condition. Preserve private evidence before runner teardown when permitted. Two same-cause failures trigger method reassessment, not repeated unchanged attempts.
4. After verified writer stop and preservation, resolve only the exact run-bound lease by authorized CAS; verify remote readback. Do not force reclaim, delete unrelated refs or rerun an old request. If the current AI lacks required capability, route to the qualified operator and continue independent work.
5. Validate actual outputs and private readback; track structural transfer, independent art/technical/runtime QA, rights and formal adoption separately. Retain the native source, verified blend and prior checkpoints. Do not confuse a private candidate with a release-ready asset.
6. Record new verified findings in the owning PR and update the shared evidence only when materially changed. No separate engine, new paid resources, new secrets, blanket rights or duplicated production tasks.
