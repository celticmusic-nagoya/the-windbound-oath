## 実装

- `tools/morwen_head/extract_stage.py`: ZIP経路・サイズ検査、指定ステージと既存検査JSONの回収。元検査JSONと回収インベントリを別名で保持。
- `verify_provenance.py`: 公式配布ZIP/BlenderのSHAと素体座標・トポロジーの照合、資材メタデータ記録。
- `build_candidate.py`: 元形状をBasis形状キーで保持。顔・体のトポロジーを維持し、頭部縮尺と首の連続した補間、頬・顎・鼻・眼窩の局所形状調整。独立した眼球・紫虹彩・瞳孔・眉、金色眼鏡、厚みを実体化した広いクアッド面のボブと前髪を制作。髪は平面画像や円断面の管ではない。
- `.blend` 内で頭体、目、眼鏡、髪束を編集可能。Subdivisionは保持。顔リグ・UV再制作・変形保証は未実施。
- `qa_candidate.py`: RGBA/可視面積/白飛び/黒潰れ、全身の余白、頭部の実頂点投影範囲、非空メッシュ、非多様体・退化面・符号付き体積、再オープン、SHAを検査。6方向頭部コンタクトシートと実頂点の測定図を出力。肩を切る顔アップと全身フレームを区別。
- `.github/workflows/morwen-head-sculpt-review.yml`: 固定参照コミット・指定Artifactからビルド、Blender 4.2 CPU/Cycles、48 samples、seed 0、AgX、デノイズなし。候補・PNG・検査JSON・SHAを14日保持。

## 再現

```
blender -b -t 4 --python tools/morwen_head/build_candidate.py -- \
  --stage /path/to/morwen_head_landmark_review_UNAPPROVED.blend \
  --canonical /path/to/verified/2026-11-16 --output /path/to/new-output --samples 64
python tools/morwen_head/qa_candidate.py /path/to/new-output
```
