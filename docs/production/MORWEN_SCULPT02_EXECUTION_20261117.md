## 実行可能性の実測

標準共有デスクトップは設定上enabledだが、操作用NodeREPL/CUA/Sky/ビューアのツールが提供されず、DISPLAYも空だった。実際のBlender GUI起動はGHOST/X11表示不能で失敗した。

そこで既存Xorg dummyドライバーを調査し、ユーザー所有のローカル仮想画面`:99`、ソフトウェアOpenGL、XTest入力、ImageMagickスクリーンショットで**Blender 4.3.2の実GUI操作**を確認した。標準共有デスクトップとは別のローカル画面であり、人間のスカルプト担当者が操作したものではない。

ブラシ実行の検証用球体で11頂点・最大0.062329単位の変位を確認。単にSculpt Modeへ切り替えただけではない。Essentialsブラシ資材が未収録でも、Blenderのネイティブブラシを作成・有効化して実ポインターストロークが通った。結果は **EXPERIMENTAL_LOCAL_GUI_SCULPT_VERIFIED**。今回はBLOCKED_SCULPT_CAPABILITYではない。

Blender 4.3.2はGPLアプリ、素体は既存の公式CC0 Human Base Meshes。新しい有料API、購入、外部画像生成サービスは使用していない。ツール調査と比較は `docs/qa/morwen-sculpt02/ENVIRONMENT_CAPABILITY.md`、実入力ログは `gui_session_actions.json`。Nomad/ZBrushは比較のみで、購入・実行していない。

## 参照画像の配置と限界

正式JPEG＋Layer0正面・背面・左右の5ファイルは実バイトのSHAを確認し、保存済み`.blend`のpacked imageでも全5件を照合する。

正面・左向き側面の画素ランドマークを記録し、原画像の縦横比を保つ画像Emptyとカメラ比較オーバーレイを用意。顎と見えている髪の頂点による**仮の二点位置合わせ**である。頭蓋頂点・隠れた目頭等は画像で直接見えず、推測した頭蓋の位置を確定座標にしない。JPEGの3/4顔は意匠判断の基準であり、正投影の実測図とは呼ばない。

眉、眼の端、鼻先、口線、顎、見える耳、髪の分け目・前髪・ボブ外周の画素位置は `reference_registration.json` に記録。この登録から自動顔フィットはしていない。頭身の違う全身絵を全身の同一縮尺図として強制一致させていない。**G1はBLOCKED**。

## レンダリングと技術QA

保存されたGUI造形済みソースだけを読み、専用rendererで正面・背面・左右・斜め2方向の**色付き6枚＋クレイ6枚**を出力。旧造形generatorは呼ばない。固定カメラ、768×768 RGBA、Cycles CPU、48 samples、seed 0、AgXを使用。64px／128pxの縮小レビューとコンタクトシート、仮登録オーバーレイを生成する。

技術検査は、原本不変・Blender再オープン・packed参照SHA・実形状差分・評価後メッシュの非多様体／退化面／有限座標／符号付き体積・アルファと白飛び・実頭部の投影範囲を検査する。下肩を意図的に切る頭部アップと、頭髪自体の欠けを区別。自己交差・UV・リグ・変形・ゲーム適性は別工程。

ローカルGUI/レンダーはBlender 4.3.2、Actionsはbpy 4.3.0。版差のため画像バイト一致を保証せず、実行ごとのSHAを残す。保存済み形状からのレンダーは再実行可能。GUIストロークの厳密な再生には同じ画面・版・ブラシ状態が必要で、ポインターログだけによるbit単位一致は主張しない。編集可能な保存済み形状を制作原本とする。

## 直接の美術自己比較

| 要素 | 正式画像との差分／今回の結果 |
|---|---|
| 顔の同一性 | 鼻の突出・眼裂に変更はあるが、写実素体の鼻孔・人中・顎の印象が強い。正式モルウェンの柔らかなアニメ調の面には未達。FAIL |

| ボブ | 後頭部を連続した形にし左右差を追加。元の均等な尖った殻板は再利用していないが、大きなヘルメット状の量感が残る。FAIL |
| 頭頂 | 初版レンダーで被覆不足と小さい橋状パーツの浮きを発見。旧パーツを隠して保存し、連続ボリュームを新設したv02で被覆は改善。ただし太い帯状の盛り上がりとして読め、まだ不自然。FAIL。完全な交差検査ではない |

| 64/128px | 縮小時の顔・髪・眼鏡の可読性を確認する補助画像。ゲーム組込・Androidテストではない |

新方式の実造形は実施したが、低品質な試作を完成品・正式採用としない。初版と頭頂補正v02を保存し、顔・髪の美術未達が残ることを記録する。新方式の初版とv02とも自己美術FAILのため、この低密度の大形状＋小局所Grabによる完成美術方式も停止する。3回目の数値微調整はしない。
