## 材質設定の出発点（暫定、正式値ではない）

| 材質 | Metallic | Roughness |
|---|---|---|
| 磨いた金属 | 1 | 0.15–0.25 |
| 艶消し金属 | 1 | 0.30–0.45 |
| 経年金属 | 露出金属1、腐食・塗装は非金属として分離 | 0.40–0.65 |
| 金糸 | 金属巻きと繊維を分離、混合材近似時のみ0.3–0.7 | 0.40–0.65 |
| 布地 | 0 | 0.55–0.85 |
| 肌・唇・髪・眼 | 非金属部分0 | 実素材と実モデル比較から決定 |

Base ColorはsRGB、Normal・Roughness・Metallicは非カラー。接線空間Normalの方向規約を検証する。物理量の実測と推定を区別する。露出した導体はMetallic 1、非金属は0が原則。複合材や下位シェーダー近似での中間値には理由を記録する。光沢・反射・陰影は実マップ照明に対応させる。SSS・異方性・透過等は実際の対応機能と性能が確認できた場合のみ採用候補とする。

## 共通実行カード

1. D0: 最新main・所有PR・正式参照SHA・native親SHA・素材URL・作者・利用権・同意・元画像SHA。権利不明は観察のみ。無課金。
2. D1/D2: 独自デザイン、部位ID、実UV、方向・縮尺・保護領域、色と質感の分離。
3. D3: 操作ID、目標・単位・座標・許容差・不確かさ・保護対象を明記。未観測はHOLD。D4独立設計QA。
4. 実制作: VRoid-first、既存native保護、実編集・比較・保存・再読込・SHA。未対応のPBRはnative readiness後に適格なBlender工程で補完。同一ファイルの競合書き込みなし。
5. G1: 権利・正式設定・来歴。G2: 独立美術QA。G3: UV・材質・構造・リグ・保存再読込。G4: 実ゲームWebGL/Android・性能・動作。昼光・日陰・室内灯、近中遠距離、アニメーションで確認。実機未検証はNOT_RUN。
6. 完了: 所有PRに実成果物・再現手順・出所・SHA・実画像・独立評価を保存。優位性がない素材は採用しない。単体比較の成功だけでG2–G4合格としない。同原因・同方式2FAILで変更。正式採用は別承認。
