## 4. 歩幅と移動速度の実測
- **ゲームの移動速度：** `FieldMovement.settings.pointerStep` = 5px/フレーム（60Hz）なので、300px/s。
- **72の描画上の足の移動量：** 48×64で3px/コマ、1周期（6コマ）で18px（96×128では36px）。
- **足が滑らない条件：** 8fpsでは移動速度が24px/sである必要があり、ゲームの速度の8%しかない。
- **初期値（8fps）での滑り：** 1コマあたり34.5pxの足滑りが出る。
- **strideを18pxにした場合：** 滑りはなくなるが、300px/sでは表示が100fps相当になり、1フレームで複数コマ飛ぶため歩行として見えない。
- **結論：** 現在の素材は、ゲームの移動速度に対して歩幅が約12分の1しかない。足滑りをなくすには、ASSET-74で歩幅（脚の開き）を大きく描き直すか、移動速度を下げる必要がある。DEV実装は初期値の8fpsのまま置き、プレビューで比較できるようにした。
