# Asset Generation Rules / 画像生成・納品ルール

**Status: MANDATORY / 必須**  
**Scope:** THE WINDBOUND OATH の画像生成、編集、切り出し、アセット整理、レビュー、納品を行うすべての担当者・AI（ChatGPT、Codex、Claude等）。

## 1. 1ファイル＝1独立アセット（厳守）

- 複数アセット、別バリエーション、独立パーツを並べた**シート形式・コラージュ形式は全面禁止**。
- 1回の成果物につき、**1画像ファイルに1つの指定された独立素材のみ**を収める。
- 祭壇の石柱・階段など、**単一の完成オブジェクトを構成する不可分の装飾**は同一素材に含めてよい。別々に使うエフェクトや状態違いは、それぞれ別ファイルにする。
- 比較シート、素材一覧、ラベル付きコンセプトボードを正式アセットとして納品しない。

## 2. 背景透過・単体切り出し

- ゲーム用の独立素材は原則**透過PNG（有効なアルファチャンネル付き）**で納品する。
- 背景色、背景風景、チェック柄の焼き込み、ラベル、不要な枠・余白、切り抜き残りを含めない。
- 輪郭の欠損、不要な光の縁、半透明の背景残り、オブジェクトの不自然な切断を検査する。
- 背景込みのイラストが明示的に指定された場合はその指示を優先するが、シート禁止と単体出力は維持する。

## 3. 提出前の非公開セルフチェック（品質ゲート）

ユーザーに**提出・表示する前**に、内部で少なくとも以下を確認する。

- [ ] 画像内に複数の独立部品やバリエーションを並べていないか。
- [ ] 指示された**単体アセット1点**のみか。
- [ ] 透過が必要な場合、実際にアルファチャンネルが存在し背景が除去されているか。
- [ ] 指定のキャラクター・造形・画風・方向・縮尺・構図に適合するか。
- [ ] 輪郭、欠損、余白、文字、余計な要素に問題がないか。

**不合格品はユーザーに提出・表示しない。** 内部でプロンプトや編集工程を修正し、可能なら再生成・再検証する。合格品が用意できない場合は、完成と偽らず未完成・理由を報告する。ツールが生成画像を即時表示する場合、非公開検証を保証できないため、その制約を明示し、未検証の出力を正式納品扱いしない。

## 4. 正式採用素材の保護

- 正式採用された素材は無断で加工・差し替え・再生成しない。
- 状態違い、演出、魔法エフェクトは独立ファイルで作る。
- 既存採用素材を変更する場合はユーザーの明示承認を得る。
- 例：`moss_ancient_altar_idle_v1.png` は古代祭壇の正式採用済み通常状態。契約発動エフェクトは別ファイルにする。

## 5. DIRECTIVE / 作業指示書への必須記載

**今後のすべてのDIRECTIVE・作業指示書の冒頭**に、次の文を明記する。

> **必読・最優先：** 作業開始前に `docs/ASSET_GENERATION_RULES.md` を読み、画像生成・編集・アセット整理・納品では「1ファイル＝1独立アセット」「シート形式全面禁止」「必要な背景透過」「提出前の非公開品質検証」を厳守する。画像を扱わない作業でも本規則を確認し、該当作業が生じた場合に適用する。

担当AIやセッションが変わっても、このルールを引き継ぐ。ルール変更にはユーザーの明示承認を要する。
