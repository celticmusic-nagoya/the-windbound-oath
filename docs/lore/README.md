## 参照ルール
1. **優先順位**: ユーザーの後日の明示採用 ＞ v5.0 の最新追補 ＞ v5.0 のそれ以外 ＞ 旧版アーカイブ（履歴参照のみ）＞ 企画案・仮案。
2. **ラベルの区別**: 確定／脚本採用案／未決定／撤回／要コード照合 を原本どおりに区別する。候補・脚本採用案・未決定を、ユーザーの承認なしに確定へ昇格しない。
3. **設定確定 ≠ 実装済み**: 実装状況は現行 main のコード・Git 履歴・テスト結果で確認する。コード上の数値を公式設定へ昇格しない。
4. **独断で変えない**: 既存のシナリオ・台詞・キャラクターデザイン・ゲームバランスを、資料だけを根拠に変更しない。
5. **読めない場合**: 推測や記憶で補完しない。ユーザーに確認し、設定に依存する部分は現状維持にする。
6. **相違の報告**: 設定と実装に相違があれば「設定／実装／差分／推奨対応／優先度」で報告する。

## 追補・変更履歴の管理
- 原本は編集しない。正式採用された変更は追補として記録し、版番号を更新する（記録は非公開リポジトリで管理）。
- 追補には「採用日・項目・旧設定との差分・関連ファイル・承認根拠」を残す。
