# FIELD-HD-V5.1 — 比較シート初稿のレビューと制作ゲート

2026-11-08 / **未採用・比較用**

- エイダン、フィオナ、セレナ、モルウェン、エマの5人について、2.8–3.0頭身を狙った高密度ピクセル風の立ち4方向・歩行姿勢の**比較シート**を制作した。
- **これは単一の背景付きRGB比較画像**であり、キャラクター別透過RGBA、統一原点、4方向の実ゲーム用素材ではない。見た目の描画比率も未実測。
- 公式イラストとのピクセル単位の一致・正式衣装・髪型の照合は**NOT_RUN**。正式採用済みのモルウェンv3やセレナ原本は上書きしない。
- モルウェンは**王立魔法学院の首席生徒（18歳）／王立魔法研究院の研究協力生**。学院と研究院は別組織。学生らしい知的な制服の表現を重視し、性的な誇張は行わない。
- エマは老婆の養母であり、若返らせない。セレナの成人設定は正式資料で確認してから身体表現の制作仕様を確定する。
- 比較シート上の「4フレーム歩行」は**動作イメージ**。実装方針は静止方向別画像＋JS/CSS共通バウンスを維持。余分なフレーム制作を強制しない。
