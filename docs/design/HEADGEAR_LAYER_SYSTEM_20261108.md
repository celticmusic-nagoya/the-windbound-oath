# HEADGEAR-LAYER-01 — 頭装備着せ替え設計・将来実装計画

**ステータス:** 設計採用 / 合成ロジック候補実装 / 本番描画未接続。既存SAVE・キャラクター画像を保護。

## コンセプト
オリジナルのRO風・ペーパードール式レイヤー合成。既存ゲームの画像や他作品の頭装備を複製しない。正式採用キャラクターの髪型・眼鏡・制服・装備は原本照合後にベース画像とレイヤーへ分離する。未照合のv5.3シートは本番利用禁止。

## スロット
- `upper`: 頭頂部、帽子、リボン、兜、耳飾り。
- `middle`: 目元、メガネ、仮面。
- `lower`: 口元、首元、マフラー、マスク。
- モルウェンの公式メガネは**初期middle装備**として扱い、無装備化で顔の正式デザインが変化しないよう、ベース素体にメガネを焼き込む場合は重複表示を防止する。正式髪型・ニーソックスは変更しない。
- 上下段をまたぐ帽子・兜などの占有競合は `occupies` に列挙し、装備変更は原子的に判定。上段/中段/下段の優先描画順はデフォルト `upper,middle,lower`、装備ごとの `zIndex` は個別設定可能。

## アセット規約
`assets/candidates/headgear/<id>/<direction>.png` (RGBA PNG)。方向は `down,left,right,up`。ベースと全く同じcanvas寸法・anchor座標・倍率。レイヤー側の余白も保持。頭部位置の差分が必要な場合は方向別の `headAnchor` とフレーム別オフセットをメタデータで管理し、実行時に一度だけ適用。透明部・SHA-256・四方向・寸法・前後重なりをCI検証。スプライト原本は無加工保護。

## 描画
- 1キャラクター=共通の外側コンテナ。ベース・上中下装備レイヤーに**同一の変形行列**を適用。CSS/JSバウンスは外側コンテナに一度だけ適用し、個々の装備には重複適用しない。
- Canvasの場合、同じフレーム時刻に `drawImage` をベース→各装備の順に呼ぶ。DOMの場合はabsoluteな子imgを同一座標に重ね、親だけをtransform。
- `prefers-reduced-motion` を尊重。アニメーションは見た目のみ。SAVE、当たり判定、歩行速度、ゲーム状態に副作用を与えない。
- 戦闘・会話の高精細イラストは独立した任意の差分レイヤーを将来追加。未制作の差分は従来の正式画像を表示し、存在しない画像の自動生成や無理な合成をしない。
