# モルウェン HD歩行素材 パーツ分割仕様書（ChatGPT向け）

この仕様書は、モルウェン（17歳の見習い魔女）の高頭身HDドット絵を、ゲーム内で歩かせるための素材の作り方を定めます。
- 原画のデザインは変えないでください（顔・体型・年齢・衣装）。
- 対応する機械可読データ: `data/sprite-rig/morwen_hd_left_walk6.json`

| 項目 | 値 |
|---|---|
| キャンバス | **1024×1280 px**、RGBA 8bit PNG、背景は完全透過 |
| 足元の基準点（アンカー） | **(512, 1230)**。足の裏がこの行に乗る |
| 身長（帽子の先端から足の裏まで） | **約1104 px**（帽子の先端は y≈126） |
| 左右の中心 | x = 512。左向きの場合、顔と体の前側は x が小さい側 |
| ゲーム内の表示 | 1/16（scale 0.0625）で約69 px。エイダン（69 px）と同じ大きさ |
| 最小の線幅 | **12 px 以上**（金縁・メガネ・鎖・紐）。これより細い線は画面で消える |
| 透過 | αは0か255のみ。半透明の縁、影、背景色は入れない |

全ファイルで、キャンバスの大きさと足元の基準点を同じにしてください。キャラクターを枠の中で移動させてはいけません。

## 2. 推奨フレーム数とfps
| 動作 | コマ数 | 速度 |
|---|---|---|
| 歩行（各方向） | **6コマ** | **10fps**（1コマ100ms、1周期0.6秒） |
| 待機 | 1コマ（任意で呼吸の2〜4コマ） | 2〜4fps |

ゲーム内の速度は、移動距離30pxにつき1コマ（移動速度300 px/s で10fps）です。

### 左向き歩行6コマのポーズ
| F | ポーズ | 腰の上下 | 手前の腕 |
|---|---|---|---|
| 01 | 奥の脚（右脚）を前に出してかかとで接地、手前の脚（左脚）は後ろでつま先立ち。両足が最も開く | 0 | 前 |
| 02 | 奥の脚に体重が乗って沈む。手前の脚は地面から離れ始める | 16 px 下がる | やや前 |
| 03 | 通過。奥の脚が真下で支え、手前の脚は膝を曲げて前へ振り出す（足は約40 px 上がる） | 16 px 上がる | 体の横 |
| 04 | F01の左右逆。手前の脚が前でかかと接地 | 0 | 後ろ |
| 05 | 手前の脚に体重が乗って沈む | 16 px 下がる | やや後ろ |
| 06 | 通過。手前の脚が支え、奥の脚を振り出す | 16 px 上がる | 体の横 |

- 地面に着いている足の裏は、支えている間ずっと同じ位置（y=1230）に描いてください。足が滑って見えないようにするためです。
- 腕は脚と逆方向に振ります。
- マント・後ろ髪・帽子先の水晶は、体より1〜2コマ遅れて揺らします。
- 体型は誇張しないでください。

## 4. 透過PNGの命名規則
| 種類 | 形式 | 例 |
|---|---|---|
| 完成コマ | `morwen_hd_{向き}_{動作}_{番号}.png` | `morwen_hd_left_walk_01.png` 〜 `_06.png`、`morwen_hd_left_idle_01.png` |
| 待機ポーズのパーツ | `morwen_hd_{向き}_part_{パーツ名}.png` | `morwen_hd_left_part_near_arm.png` |
| コマ別に描き直したパーツ | `morwen_hd_{向き}_{動作}_{番号}_part_{パーツ名}.png` | `morwen_hd_left_walk_03_part_near_leg.png` |

- 向きは `left` / `right` / `up` / `down` のいずれか。
- すべて小文字で、空白は入れず、番号は01から始まる2桁にしてください。
- 優先順位は「完成コマ6枚 → 待機のパーツ → コマ別パーツ」です。完成コマだけでも受け取れます。

## 5. ゲーム内表示の制約
1. 1/16に縮小されるため、元画で12 px未満の細部は見えません。紋章・メガネ・瞳は大きめに、はっきり描いてください。
2. 表示では滑らかに縮小されます。輪郭は暗い色で太めに描くと読みやすくなります。
3. 背景は草地・石畳・洞窟・夜など、明るいものも暗いものもあります。完全透過にし、輪郭色を背景に頼らないでください。
4. 当たり判定は足元の小さな矩形で、絵の大きさとは無関係です。足の裏を必ず y=1230 に置いてください。
5. 4方向（左・右・上・下）は同じ頭身・同じ画風にそろえてください。現在のちびキャラ（74I・75）とは混ぜて使いません。
6. 左右は反転で代用しません（鞄・帽子の花が左右非対称のため）。右向きは別に描いてください。
