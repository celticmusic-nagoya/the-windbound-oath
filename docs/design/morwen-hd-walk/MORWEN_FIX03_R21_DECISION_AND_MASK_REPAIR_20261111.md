# MORWEN FIX-03 — R2.1 作業基準とマスク修正指示（2026-11-11）

## 判定
- 素体R2.1: **条件付き作業基準として採用**。隠れた関節は推定値・信頼度を保持し、完成アートの正式採用とは区別する。正面の体型を基準とし、後ろ肩の約40px低下・腕の約9%短縮を修正する。脚部とFIX-01ブーツは保護する。
- 帽子・肩ケープ・袖口と手: **限定的な位置移動を許可**。既存の金模様、花、葉、紋章、フリル、ボタンの画素を可能な限り保護し、移動で露出する髪・襟・布・袖・紐を新規に再描画する。画素ワープ、異方性拡縮、無理な切り貼りは認めない。
- 背面ボブ幅: **再設計**。現状の約280pxを自動的に維持も243pxへ機械的縮小もしない。正面の頭蓋・頭身基準を使い、後頭部の丸み、髪の厚み、リボンの遮蔽を考慮して自然な幅を描く。最終幅は独立QAとディレクターの完成画像確認で決定する。

## 必須マスク修正
1. **C3**: 肩ケープ上端を実輪郭に沿ってトレースし、襟と紋章上部の星を適切な衣装レイヤーへ移す。y455/456の水平断裁線を解消し、髪との前後関係を定義する。
2. **C4**: 肩ケープ1段目下端を金縁・布の曲線に沿ってトレースし、y597の直線境界を解消する。
3. **C5**: 袖口と手だけをアルファ形状に沿って選択し、背後のローブ画素を除外。袖口上端の取りこぼしを含める。移動後の手の実領域がy790を越える場合、移動パーツの厳密なアルファ領域のみ例外的に更新可。ローブとスリットの保護を優先し、交差する場合は再設計してFAIL扱い。
4. **C8**: スリット保護を布の実境界と露出脚の形に沿って再定義し、左ローブの刺繍を保護領域から切り離す。直線三角形マスクは禁止。

## 再構築仕様の矛盾解消
- **y790境界:** 一律の「y790以下の全画素不変」を撤回。手・袖口の形状に沿う移動領域だけを例外とし、その他の下半身・刺繍・スリット・ガーター・FIX-01ブーツは保護する。例外画素数と領域を記録する。
- **y455/456境界:** 直線的な編集境界ではなく、襟・肩ケープ・髪・紋章星の実輪郭とレイヤー優先順で処理。移動後の露出領域は再描画し、未割当画素ゼロを検証する。
- **腕:** 肩から手首までの長さと関節角度を優先。R2.1の(356,786)/(844,786)は初期目標であり、実画像で自然な姿勢を確認して微調整可。調整量を記録する。
