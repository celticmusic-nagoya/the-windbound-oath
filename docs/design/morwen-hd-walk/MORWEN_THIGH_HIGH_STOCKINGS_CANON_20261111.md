# MORWEN — ニーソックス・絶対領域・履き口の正式デザイン（2026-11-11）

## ディレクター採用仕様
- **ガーターベルトはPASSを維持**。本人の右脚だけに前後連続で装着。正面では画面左脚、背面では画面右脚。左脚に装着しない。
- **両脚ともニーソックス**。腰まで連続するタイツ表現を禁止する。
- **絶対領域**：正面・背面ともスカート裾とニーソックス上端の間に素肌が明瞭に見える。
- **履き口**：ニーソックス上端が太ももにごく軽く食い込み、その直上に自然で控えめな肌の丸みが乗る。過度な圧迫・不自然な膨張は禁止。
- 左右の履き口高さと肌の露出幅を整合させる。ただしガーター装着側の局所的な布の引き上げ・重なりは自然な範囲で許容。
- **ローブ内側構造PASS**：背面V字開口を正とし、正面の脚背後に中央の垂れ布を描かない。
- ブーツ、金刺繍、帽子、バッグ、スカートの非対称チェック柄などの既存正式意匠は保護。
