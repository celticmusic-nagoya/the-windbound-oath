## 2. 共通骨格・アンカー
- 基準: 96×128の格子、中心列48、接地行124（48×64では中心24、接地62）。
- 関節: 頭・首・胸郭・骨盤、左右の肩・肘・手首・股関節・膝・足首、左右の足裏。
- 各関節の静止位置（上・下）と、12コマ分のオフセットを `morwen_rig_4dir.json` に記録する。オフセットは頭・胸郭・骨盤・ケープ裾の(dx, dy)と、左右の脚の足元行・持ち上げ量・接地中かどうか。
- 側面は既存の74E／74F-C／74Gの表を参照する。値は複製しない。
- 位相: 74F-Cの「骨盤→胸郭（1コマ遅れ）→頭（胸郭が2コマ下がった後だけ下げる）」を共通にする。
- 正面・背面の重心移動:
  - 左右移動: 骨盤は支えている脚の側へ寄り、肩は逆へ1コマ遅れて動く。
  - 傾き: 振り出す脚の側のケープ外側が下がる。
  - 頭は左右に揺らさない。
  - 側面の腰の前後移動は転用しない。
- 48px: オフセットは `(v+1)//2`。左右移動はピークのコマだけ1px入れる。

## 3. 装備スロット（将来の着せ替え）
- スロット: Head, HairAccessory, Inner, Outer, Cape, Bottom, Legs, Feet, Bag, Accessory。
- 装備ID: `<character|*>.<set>.<item>`（例: `morwen.default.hat`）。
- 画像の置き場所: `{facing}/{anim}/{frame:02d}_{size}.png`。または合成済みのキャラクターシートに焼き込む。
- 各装備の属性:
  - `anchor`: 骨格のどの点に付くか
  - `fit`: 共通モーションを使う（default）か、専用モーションを使う（custom_motion）か。形が大きく異なる衣装には専用モーションや補正を許す。
  - `hides`: 隠れる基本パーツ
  - `palette`: 共通ランプのID
- 標準衣装: `equipment_slots.json` の `default_outfit_morwen`。
- セーブとの連携は提案にとどめる（`save_schema_proposal_NOT_ACTIVE`）。**本番のセーブ形式は変更していない。**

## 4. 描画・合成方式
| 段階 | 方式 |
|---|---|
| 開発 | パーツを個別に管理し、`partdraw.composite` で各コマに合成する。合成後に外周の輪郭を引き、コマごとの補正（境界・陰影・装飾）を加える |
| 本番（第一候補） | 合成済みのスプライトシート（方向×12コマ×2サイズ）。DOMの画像数・デコード量・Androidでの負荷が今の74Gと同じで、画質もコマ単位で確定できる |
| 本番（将来） | 装備を変えたときだけ、実行時にシートを合成してキャッシュする。毎フレームの重ね描きはしない |

パーツを単純に重ねただけの状態は美術QAの合格対象にしない。合成後のコマで美術QAを行う。
