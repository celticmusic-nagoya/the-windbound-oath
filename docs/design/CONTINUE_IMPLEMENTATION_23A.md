## Adopted 23B acquisition compatibility

`prologue.legacyEvents` is optional/additive inside existing v30/prologue-v2 SAVE. Version `v:1` contains exact booleans for drawer, pot and the existing balloon/cat legacy quest flags. Explicit false means unclaimed. Missing the entire profile means old/unknown: only drawer and pot become unavailable. `unknown:['drawer','pot']` preserves the reason when the player later explicitly saves; it does not assert that collection happened and does not add inventory. Missing fields in a present profile are rejected, not treated as false. Actual known subquest completion/objective data can restore quest substate; story flags/conversations are not marked complete by the unknown-item rule. New game resets the legacy event state. LOAD/CONTINUE failure restores flags and unknown provenance before a newer owner may operate.
