# SAVE-SLOTS-20 — streaming-friendly save/load design

Status: FOUNDATION ONLY; not connected to runtime; tests not executed.

## Approved target
- Exactly 20 numbered manual slots; SAVE and LOAD are separate system-menu tabs.
- Display slot number, save date/time and canonical progression label after mapping stages to user-facing names.
- Confirm overwrite and deletion; never silently replace any occupied slot.
- Legacy single-key save (`windbound_oath_v028`) stays intact and visible as import source; no automatic destructive migration.
- From GAME OVER, choose a valid saved slot for recovery; title return always available.
- Save/load guard uses existing LoadCoordinator, TrainingCheckpoint, SaveContinue validation and game state application, not a second implementation.
- On quota errors, show an error without deleting any save; support export/import backup as a later improvement.
- Android portrait/landscape and keyboard focus/scroll are mandatory QA.
