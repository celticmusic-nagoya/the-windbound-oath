# FAST-TRACK｜Android実機QA・mainマージ運用方針

- 決定日: 2026-11-02
- 対象: THE WINDBOUND OATH / オープニング〜プロローグ改訂（TASK-PROLOGUEシリーズ）
- 状態: ディレクター承認済みの開発運用方針。個別PRのマージ承認ではない。
- 参照: AGENTS.md / 統合引き継ぎ書 v2.1

## 必須の順序
1. Claude/Codexが承認済み範囲を専用ブランチに最小差分で実装する。
2. 構文・起動・主要進行・SAVE/CONTINUE・変更関連の既存回帰テストを最小限実施する。
3. PRを作成し、変更内容・QA結果・既知の問題をディレクターへ報告する。
4. **ディレクターからそのPRについて明示的な事前マージ承認を得た後にmainへマージする。**
5. **mainマージ後**、ディレクター本人がAndroid実機でNEW GAMEからプロローグ終了まで通しプレイし、最終受入QAを行う。
6. 発見された不具合は修正PRで対処し、完成判定を行う。

## 判断基準
- Android実機QAが未実施であることのみを理由に、事前mainマージをブロックしない。実機QAにはmain反映が必要。
- 大規模な事前QAは省略可能。ただし、構文エラー・起動不能・既知の重大な進行不能・SAVE破損を見逃したままマージしない。
- mainマージと本番公開が連動する場合、その影響をPR報告に明記する。
- **方針の承認と個別PRのマージ承認は別。包括的な自動マージ権限は与えない。**
- AGENTS.mdの保護規則（main無断変更禁止、正式採用素材・確定シナリオ保護、承認範囲厳守）を維持する。
