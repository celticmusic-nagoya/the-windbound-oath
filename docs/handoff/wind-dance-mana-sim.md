# S: 風の舞 + 魔弾MP回復の比較

## 要約

基準main e694817、work/codex-wind-dance-sim2。確定仕様の全体15pt/3敵フェーズ/MP10/更新のみを固定攻撃列へ適用した。暫定回復3では18フェーズ内のcastが両ケース3→6回になる。ゲームコード・数値データは変更していない。

## 出典と比較の条件

- `js/prologue-combat.js:72–102`（通常）、`:182–210`（Raider）: 生存した実行者と選択した生存対象の確認後、damageを直接適用する。**命中率の式・miss判定は存在しない**。有効な通常攻撃の暗黙命中率は100%。魔弾名称/MP回復はまだ本経路に実装されていない。
- `js/battle-critical.js:5–18`: randomは会心判定に使用する。通常/会心ともdamageを返し、命中抽選ではない。
- `index.html:695,1292`: 初期MP30/36。`js/battle-action-targets.js:34` のエーテル上限30/36をモデルの回復上限として使用。アイテムは今回使用しない。
- `docs/handoff/codex-brief-S-wind-dance-mana.md` が風の舞の確定条件と魔弾回復の暫定2/3/4を指定。旧support-magic-dataの未決nullは更新しない。

Nと同じ18フェーズ・敵攻撃列/交互target・全員生存を仮定する。各フェーズにFionaは1行動、風の舞が切れていてMP10以上なら再使用、それ以外は有効対象へ魔弾。ヒール/風花/アイテム/防御/祈りは選ばない。回復は魔弾直後、再使用は次フェーズ以降。使用したフェーズを持続の1つ目とする。castは持続更新のみ、回避加算はしない。

これは**固定期間のMP台帳と被ダメージ機会の比較**であり、戦闘再現ではない。風の舞が魔弾の行動枠を消費することは台帳に反映するが、その火力減少・追加魔弾による撃破や敵攻撃列の変化は反映しない。回復を使った最適行動計画でもない。
