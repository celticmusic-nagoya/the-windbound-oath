# Codex 指示 S: 風の舞+魔弾MP回復 シミュレーション拡張 (2026-10-13)
前提: standing-orders に従う。ブランチ `work/codex-wind-dance-sim2`(基点は最新main)。ゲームコードは触らない(実装はClaude側)。

## 確定した基本仕様(作者決定)
風の舞: フィオナ/味方全体/回避率+15pt(被ダメ軽減ではなく回避)/3フェーズ/MP10/重複加算なし・再使用は持続更新。
魔弾(フィオナ通常攻撃): MP回復 **3**(暫定)、上限超過なし。回復条件は「命中時」と「攻撃実行時」の2案を比較。

## 依頼
`tools/sim/wind_dance_sim.py` を拡張し、次の4条件を比較:
1. 風の舞なし 2. 風の舞あり・魔弾回復なし 3. 風の舞あり・魔弾**命中時**+3 4. 風の舞あり・魔弾**実行時**+3
可能な範囲で出力: フィオナの支援行動数/回復行動数/魔弾回数、戦闘終了時MP、撃破ターン、勝率。
- 現sim(固定攻撃列の反実仮想)で出せない項目は、理由を表で明記(出せないものを創作しない)。
- 魔弾の命中率はエンジンの命中式から取得し、出典(ファイル/行)を記載。
- 既存の「cast回数とMP予算」の議論に、魔弾回復で cast 回数がどう変わるかを加える。MP回復量 2/3/4 の感度も付記。
- 成果: `docs/handoff/wind-dance-mana-sim.md` と結果JSON。自己テスト必須。
- 禁止: 数値の最終確定、ゲーム側の変更。
