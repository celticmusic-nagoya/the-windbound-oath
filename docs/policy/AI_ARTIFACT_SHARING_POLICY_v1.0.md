# THE WINDBOUND OATH AI成果物共有・GitHub一元管理ポリシー v1.0（2026-11-11 ディレクター指示）

- 適用対象: ChatGPT / Claude / Codex

## 基本方針
- 開発成果物は、作業ブランチと Draft PR で共有する。
- チャットの添付ファイルや ZIP は補助的な受け渡し手段とし、正式な納品完了の証拠にはしない。

## 必須事項
- すべての成果物を、指定された作業ブランチに登録する。
- 正式原本を無断で上書き・削除しない。
- 素材には MANIFEST と SHA-256 を付ける。
- 修正候補・正式採用・参考資料を明確に区別する。
- QA 報告と検証の証跡を GitHub に保存する。
- Draft PR に、変更ファイルの一覧、コミット SHA、QA 結果、残課題を書く。
- 必須ファイルの存在を確認し、ハッシュを照合する。
- 検証していない項目を PASS と書かない。
- main へのマージ、ゲーム本体への組み込み、公式サイトへの公開には、個別の承認が必要。

## 納品完了の条件
1. 必須ファイルがすべて GitHub にある。
2. MANIFEST と実ファイルが一致している。
3. QA 結果が記録されている。
4. Draft PR から成果物をたどれる。
5. 検証の対象になったコミット SHA が確定している。

## 例外
- GitHub に直接登録できない場合は、BLOCKED として報告する。
- 一時的に ZIP で受け渡した場合も、GitHub への登録と照合が終わるまでは納品完了としない。
