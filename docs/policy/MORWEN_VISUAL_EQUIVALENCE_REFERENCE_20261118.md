# MORWEN｜視覚的同一デザインの参照運用（2026-11-18 ディレクター承認）

## 決定と適用範囲
ディレクターは、繰り返し提出された**同一デザインの画像ならどれでも制作参照に利用してよい**と承認した。対象はモルウェンのデザイン参照・3D制作。画像バイナリのSHA-256完全一致を、制作開始の必須条件にはしない。

- **原本保護**：既存のv5.61原本の識別情報（JPEG/JFIF、SHA-256 `47d58cbeb0f8ad41f51543716d872bfcc8c7d0dc91d45196c9c02b22402df638`）は履歴・来歴として保持し、書き換えない。SHA不一致を「同一バイト列」と報告しない。
- **使用可能な参照**：既に正式採用されたLayer 0四方向画像を身体・顔・プロポーションの優先参照とする。その他の既存画像は、採用デザインと**目視で一致した場合のみ**制作参照として利用できる。単なるファイル名・v5.61表記・画像サイズの一致では認めない。
- **照合点**：頭部・短いボブ・メガネ、体格と左右非対称性、帽子・花飾り、衣装・肩紋章、鞄・魔導書、ニーソックス・靴、配色と装備位置。後発の方向別正式採用・デザイン変更があれば、それを優先し、矛盾は記録して該当パーツのみBLOCKEDとする。
- **記録**：制作に用いた画像ごとにパス、実際のSHA-256、由来、参照する方向・部位、目視照合結果（PASS/FAIL/BLOCKED）、未一致箇所を残す。画像形式や再圧縮でハッシュが異なっても、デザイン一致の根拠があれば制作を停止しない。
- **区別**：視覚的同一性の確認は原本バイト同一性の確認ではない。制作参照として使用できることは、画像・3Dアセットの**正式採用**、美術QA PASS、ゲーム組込を意味しない。
- **工程**：独立して進められるLayer 0身体・頭部造形を進める。デザイン未確認の衣装・装飾部位だけをBLOCKEDとする。G1〜G4を個別判定し、3D完成・採用・本番マージには従来の品質ゲートを適用する。
- **禁止**：旧候補を無条件に正式昇格させること、正本バイナリの置換、正式設定の推測補完、失敗方式の無根拠な再試行。

この決定は**制作参照の運用規則のみ**を更新する。旧来のv5.61 SHA記録、旧スプライトのSUPERSEDED指定、原本保護、正式採用ゲートは維持する。
