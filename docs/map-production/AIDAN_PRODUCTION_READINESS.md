## 3. 完成品質の評価チェックリスト（制作側が候補ごとに記入）

### G1 正典・基準
- [ ] 外観仕様（階数・ドーマー・軒・煙突位置・扉の向き）がディレクター決定済みで、出典を記録
- [ ] 屋根は青灰色の石板葺き。赤茶・茅葺き・緑の板葺きを使用していない
- [ ] 壁は不整形の自然石積み、木組み・建具は背景CGの様式と一致
- [ ] 室内マップ（暖炉・窓・扉）と外観の位置関係に矛盾がない（提案事項として確認）
- [ ] 使用素材がすべて台帳上 `CANDIDATE` 以上で、CC BY素材はCREDITS登録済み

### G2 美術（各5段階、全項目4以上かつ致命的欠陥0）
- [ ] シルエット: 27°・表示幅256/290/384pxで、棟・軒・けらば・煙突・ドーマーの輪郭が判別できる
- [ ] 屋根: スレート行の不揃い、軒先・けらばの厚み、棟の納まり、青灰色の色むらが見える。一枚板に見えない
- [ ] 壁: 乱石積み、隅石、目地の陰影。妻壁が平面露出していない
- [ ] 木部・建具: 梁・柱の構造が成立、扉・雨戸・格子窓に框と金物
- [ ] 生活感: 樽・薪・花箱等が配置され、苔・汚れが軒下・地際・北面に偏在（全面均一でない）
- [ ] 背景CGとの並置比較画像でディレクターが確認

### G3 技術
- [ ] 固定Blender（`aidan_blender_config.json`）で headless レンダ成功、`.blend` が開ける
- [ ] 同一入力で再実行し、PNGのSHA-256一致（または許容差を記録）
- [ ] 紫（テクスチャ欠落）なし、全メッシュにUV、法線反転なし、非多様体は意図したもののみ
- [ ] 透過PNGのアルファ縁に背景色のにじみなし、接地線・基準点を別データで出力
- [ ] 入力素材・出力のSHA-256をマニフェストに記録、試行台帳（attempt ledger）更新
- [ ] G0で屋根スレート・煙突石の寸法ばらつき（変動係数）を検査

### G4 統合（§4）

## 4. G4 検証計画（ゲーム内表示・性能・互換性）
本番マップ・本体は変更しない。検証は分離したプレビュー（既存 `feature/map-mvp-02-quarter-view` の27°試作画面等）で行う。

| 項目 | 方法 | 合格基準（提案） |
|---|---|---|
| 表示サイズ | 27°正投影レンダを現行配置相当の 290×230px と、390px幅スマホ表示倍率で並置 | 扉・窓・煙突が判別可能。キャラ（約2.8頭身ドット）と縮尺が自然 |
| キャラとの視認性 | エイダン静止スプライトを家の前・軒下に重ねる | キャラ輪郭が背景に埋もれない（明度差を目視＋輝度差を計測） |
| 奥行き・当たり判定 | 接地線・衝突ポリゴンを画像と別JSONで出力し、プレビューで歩行 | 屋根越しに足が見えない／扉前でめり込まない |
| 昼・襲撃後の連続性 | 同一ジオメトリから燃焼・破壊版を派生できる構成か確認 | 配置・輪郭の連続性（AGENTS.md §13） |
| 性能（ブラウザ） | 画像サイズ・枚数・デコード時間をPCとAndroid Chromeで計測 | 既存 `lind_aidan_house.png`（約2.2MB）以下を目安。WebP/圧縮後の画質確認 |
| 性能（3D実行時を採る場合） | 結合・アトラス後の描画呼出し数・三角形数・テクスチャメモリ | 描画呼出し数十以下、テクスチャは1K主体 |
| 互換性 | GitHub Pages相対パス、`prefers-reduced-motion`、SAVE/CONTINUE復元後の表示 | 既存SAVEで破綻しない |
| Android実機 | 実機のChromeで確認 | **未実施**。実施まで NOT_RUN と記録 |

## 6. ブロッカー・ディレクター判断事項
1. **エイダンの家の外観仕様が正典に存在しない**（G1 BLOCKED）。決定が必要: 階数（平屋／1.5階＋ドーマー）、正面の向き、煙突位置、玄関庇、敷地の小物構成。
2. 屋根の青灰色の具体値（素材監査 §5 の提案値の採否）。
3. Blenderの固定バージョン（5.2.4 LTS 推奨／4.5 LTS 継続）と、移行時に既存候補との比較を行うか。
4. CC BY素材（樽・薪・ランタン）の採用可否とクレジット表記の方針。Sketchfab取得用アカウントの扱い（トークンをリポジトリに置かない）。
5. Quaternius（QAL）素材は再配布制限のため現状不採用。必要なら法務判断。
6. PR #307（屋根正典の文書反映）が未マージ。mainの規約文書は旧「赤茶屋根」のまま。
