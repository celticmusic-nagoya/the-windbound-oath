### CI・QA運用の問題（同ブランチ）
1. `Aidan Candidate PBR 1K Intake` が FAIL: 期待テクスチャ数 `==15` のassertが、実際の18件（地面代替候補追加後）に追随していない。
2. `Aidan PBR Shortlist Verification` が FAIL: `Ground111` を UNVERIFIED と判定。API v2 `full_json?id=Ground111` では存在する（照会方法の問題）。ただし素材自体が不適（[素材監査](AIDAN_ASSET_SOURCE_AUDIT.md) §4）。
3. `qa_aidan_render_artifact.py` の G3 は **PNGヘッダとハッシュのみ**（`scope: G3_HEADER_HASH_ONLY`）。アルファ縁、空レンダ、接地、カメラ角は未検査。
4. `aidan_g0_preflight.py` は壁石の寸法CVを検査するが、**屋根スレート・煙突石の均一性を検査しない**（今回の最大の欠陥を見逃す）。
5. `_qa/aidan_home_attempt_ledger.json` は `attempts: []`・`HISTORICAL_ATTEMPTS_NOT_YET_RECONCILED` のまま。ループ防止台帳が機能していない。
6. 全オブジェクトが単一コレクション。`AIDAN_HOME_MASTER_01.md` が要求する基礎／壁／目地／木組み／屋根／建具／煙突／小物／植生／当たり判定・LODの分離が未実装。

## 4. 根本原因（なぜ繰り返し修正しても品質が上がらないか）
- **最終表示サイズから逆算していない。** 現行配置は約290×230px。この大きさでは個々のスレート厚(8.5cm)や石の微小な凹凸は1px未満で、見えるのは「輪郭線の不揃い」「明度の段差」「色むら」「影の落ち方」。A は予算（三角形の約4割）を見えない部分に使い、見える部分（軒の出・棟・けらば・煙突頂部）が欠けている。
- **プリミティブの複製で質感を作ろうとしている。** 同一キューブの繰り返しは、ばらつき付与をしても規則性が残る。テクスチャ0のため面内の情報がない。
- **建築として組み立てていない。** 妻壁・軒・棟・けらばの納まり（部材同士の関係）が未定義のため、継ぎ目が平面や隙間として露出する。

→ 同一方式（プリミティブ複製＋単色）での再修正は打ち切り、方式を変更すべき（AGENTS.md「3回目の前に方式を変える」に該当）。

## 6. 改善優先順位
1. **G1確定**: エイダンの家の外観仕様（階数、ドーマー有無、軒、煙突位置、扉向き）をディレクターが決定。正典には外観記述がない（§0 素材監査）。室内マップ `data/maps/rilde_in_aidan.json` に暖炉があるため、外観に煙突は整合的（提案）。
2. 屋根: 方式変更（§5）＋青灰色マテリアル補正。最も視認性に効く。
3. 27°ゲームカメラと表示サイズ比較の出力を全候補で標準化。
4. 壁: 乱石積みPBR＋隅石。妻壁の平面露出を解消。
5. 建具・煙突・軒の納まり。
6. 生活小物と苔・汚れの分布。
7. QA強化: G0にスレート／煙突の寸法ばらつき検査、G3にアルファ縁・接地・カメラ角検査（`AIDAN_PRODUCTION_READINESS.md` のチェックリスト）。
8. CIの既知FAIL（§3 の1・2）を担当側で修正。
