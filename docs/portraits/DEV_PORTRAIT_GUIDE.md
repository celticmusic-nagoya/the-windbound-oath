## 操作

ゲーム開始 → 会話を閉じる → `DEV ▶` → `立ち絵・モーションテスト`。

1. 人物と表情を選択。「正式採用」「瞬き対応／静止表示」を確認。
2. 「今すぐ瞬き」で1回、「自動瞬き」で3〜6秒間隔、「連続テスト」で繰り返し。
3. 「フレーム0〜4」で実際のcanvasの開眼〜閉眼を確認。「停止・開眼」で停止。
4. 左右切り替え・縦横回転を確認。横画面は「操作パネル」で開閉でき、長い操作欄はスクロールできます。
5. 「閉じる」で立ち絵・瞬き・状態更新タイマーを解除。

静止表情では瞬きボタンとフレーム1〜4は無効。reduced-motion有効時は動画再生を停止し、静止フレーム確認は可能です。READY/MISSINGは読込状態、RUNNING/STOPPEDはタイマー状態で、正式採用かどうかとは別です。

`dev/talk-portrait-preview.html`はエイダン6表情の簡易プレビューです。4人全表情・連続/自動/状態確認にはゲーム内DEVを使ってください。
