# Aidan battle idle v1（完成候補 / 未統合）

**状態: 候補。ゲームには未接続（`BATTLE_IDLE_ASSETS`・`battle-idle-motion.js`・`motion-manifest.json` は無変更）。公式MASTERは上書きしていない。mainへマージしない。**

## 方式
- 素材は採用済みMASTER（1312×1199 RGBA）1枚のみ。`idle_v1/aidan_idle_master.png` はMASTERとバイト一致のコピー（SHA-256は `idle_v1.json`）。再生成・ドット絵化・SD化なし。
- まばたき: 左右の目を個別に処理（`tools/aidan_idle/make_blink.py`）。前髪・まつ毛は保護。閉眼時に虹彩/白目は残さない。まぶた肌は上下の実肌の勾配＋反転テクスチャで生成し、まつ毛は元の暗色核＋茶の縁で描き直し。開→30→60→85→100(70ms)→…→開、計260ms。目元の差分PNG（`eyes/overlay_{L,R}_s{1..4}.png`、差のある画素のみalpha=255）。MASTERのα・非目元画素は不変。
- 待機: MASTERを滑らかな周期変位場で歪ませる（描き足しなし）。胸・肩・頭の呼吸（4秒周期）、腕＋手＋剣は1つの剛体群（グリップ軸の微小回転＋胸の上下に追従）、髪は遅れて揺れる（毛先ほど大）、マント/リボン/白い裾は肩からの距離で遅れが増える波。足元（ブーツ）は不動。ループ8秒（全成分が整数周期）。
- ランタイム: `tools/aidan_idle/runtime/aidan-idle-v1.js`（WebGL2、参照実装 `idle_motion.py` の鏡像）。`preview.html` は確認用。重みマップは半解像度8bit RGB（`weights_{a,b,c}.png`）。

## 画質判断（自動PASSとは別。目視）
- 手・グリップ・剣は一体で動き、引き裂け・分離なし（等倍拡大で確認）。顔・髪・衣装・マント・剣の意匠はMASTERのまま。
- まばたきは戦闘表示スケールでは自然。**残課題**: (1) 近い目の閉眼時、下まぶたに薄い肌色の帯が3倍拡大でわずかに見える、(2) 遠い目（前髪に半分隠れる）の閉眼で小さな暗い断片が残る。いずれも等倍近くで見ないと分からない程度だが、**完全な品質には手描きでの最終修正を推奨**（自動処理の限界）。
- 動きは意図的に控えめ（戦闘表示で呼吸約1px、マント約2〜3px）。

## 比較
- Fiona v2（旧6コマ差し替え）: コマ間の絵が毎回違うため形崩れ・ちらつきリスクがあり素材も6枚。本候補はMASTER1枚の連続変形＋目元差分のため絵柄は常にMASTER。
- Fiona v3（採用済み基準）: MASTER＋目元差分＋全体の微小伸縮。本候補は同じ方式を踏襲しつつ、部位別（腕剣一体・髪・マントの遅れ）の動きを追加。非目元画素不変・α不変の検証は同等。
- 未解決の既存課題（Fiona v3 の33msコマ増など）は引き継がず、本候補では60秒実測でコマ落ちなし。ただしソフトウェアGLでの計測であり実機GPUの計測ではない。
