## 2. 全滅の原因分析
- 自動検査（確定仕様の不変条件）: 気絶中に支援/祝福が出ない／復帰ラウンド差が2または3／支援間隔が気絶窓なしに4R以上空かない／最終祝福が1回／復帰後に再開 → **105戦で違反0件**（分類: すべて `faint-consistent` か `no-faint`）。実装不具合の兆候なし。
- 例（A・シード101・戦闘2）: 同一戦闘で main は R17・R19 にヒール/加護（+12HP等）が入り R20 でフィオナHP22で勝利。PR #36 は R17 に気絶 → 支援なし → R19 の破砕斬でフィオナHP19が21ダメージで倒れ全滅。**支援が止まったことによる自然な難易度上昇**（実装不具合ではない）。
- 全滅した気絶戦闘は、main同一戦闘で支援イベントを平均 2.2 回（勝利側は 2.0 回）失っていた。全滅の主因は「気絶窓に重なった支援の欠落」＋ ボットAが main でも20Rで HP がほぼ尽きる薄い余裕で戦っていること。

## 3. ボット依存性
- **ルー支援なし（支援・最終祝福を無効化した対照）**: A は 0勝/8（15R で全滅）、B は 8勝/8。→ **ボットAは「ルー支援に依存して初めて辛勝する」戦略**で、気絶版の勝率低下を過大に出す。ボットAの結果は感度の上限として扱い、難易度の根拠にはしない。
- ボットB（ポーション使用、より人間に近い）は **main 100% → 気絶版 93%（全滅3/45）**。ルーが全く支援しなくても勝てる戦略での差は小さい。
