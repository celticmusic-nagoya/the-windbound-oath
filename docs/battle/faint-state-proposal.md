# 「気絶」状態 仕様案（提案のみ・未実装・承認待ち）

作成: 2026-10-19 / 状態: **PROPOSAL**（戦闘ロジックに影響するため、承認があるまでコードは一切変更しない）

## 0. 位置づけ
- **KO**（HP0・戦闘不能）とは**独立した状態**。KO は従来どおり（Aidan/Fiona は HP0 で KO、ルーは HP を持たないため本編ではKOしない）。
- Lou KO モーション（`lou_new_ko`, 6コマ）は **KO 用**として実装済み。気絶には使い回さない（または §5 の選択肢A）。
- 現状の戦闘に気絶を与える敵技・味方技は存在しない。仕様確定後も、**付与元（技）を追加するまで本編では発生しない**。

## 1. 定義
気絶 = 「HP が残っているが、一定ターン行動できない一時的な行動不能」。HP・TP・装備・SAVE には影響しない。

## 2. 効果（提案）
| 項目 | 提案値 | 代案 |
|---|---|---|
| 行動 | 自分の手番を**スキップ**（コマンド・自動行動とも不可） | — |
| 被ダメージ | **変更なし** | 与ダメ増加(+20%)は難易度に影響するため不採用 |
| 回避・防御 | 回避不可（eva_up 無効）、防御コマンド不可 | 回避は有効のまま |
| 回復/支援の受け手 | **受けられる** | — |
| 見た目 | 待機を停止し、気絶ポーズ（§5）＋ステータス欄に「気絶 N」 | — |

## 3. 継続ターン（提案）
- 標準 **1ターン**（自分の次の手番を1回飛ばす）。上限 **2ターン**。
- 同一対象への再付与は**延長しない**（既存 BattleStatus と同じ「同種は更新」）。
- 気絶から回復した直後の **1ターンは再気絶しない**（連続拘束の防止）。
- ボス（ゴブリン・レイダー）は**気絶無効**。通常敵は将来の個別指定。

## 4. 解除条件（提案）
1. 規定ターン経過（スキップした手番の終了時に自動解除）。
2. KO になった場合は**解除**（KO が優先。蘇生しても気絶は復活しない）。
3. 戦闘終了・リトライ・シーン離脱で**全解除**（戦闘状態は保存しない＝SAVE形式は変更なし）。
4. 被ダメージでは**解除しない**。回復魔法でも解除しない（解除手段を作る場合は別途仕様化）。

## 5. 見た目の選択肢（決定が必要）
- A: Lou のみ `lou_new_ko` の1〜5コマ（眠りに落ちる流れ）を気絶ポーズとして再利用。Aidan/Fiona は専用素材待ち。
- B: 3人とも専用素材の納品を待つ（それまでは静止画 `damage` に「気絶」ラベルのみ）。
- 推奨: **B**（KO と見た目が混ざらない）。

## 6. 実装メモ（承認後）
- `js/battle-status.js` に型 `stun`（magnitude なし、remainingTurns=1〜2）を追加。ラベル「気絶」。
- ターン進行側に「stun なら行動スキップ→残りターン減算」を1か所だけ追加。自動行動・コマンド入力の両方に効くことをテストで確認。
- BattleActorState に `stun` 状態（temporary ではなく status 連動）を追加。ボス無効フラグ。
- 既存の atk/def/eva 効果・KO・低HP・勝利判定・難易度・敵パターンは不変であることを回帰で確認。
- テスト案: 付与→手番スキップ→自動解除、KO優先、戦闘終了で全解除、ボス無効、再付与で延長しない、SAVE/LOAD 前後で不変。

## 7. 承認いただきたい点
1. §2 の効果（行動不能のみ・被ダメ不変・回避/防御不可）でよいか。
2. §3 の標準1ターン／上限2ターン／直後1ターン再付与不可でよいか。
3. §4 の解除条件（被ダメ・回復では解除しない）でよいか。
4. §5 の見た目（A/B）。
5. 付与元（どの技・どの敵が気絶を与えるか）は別提案とするか。
