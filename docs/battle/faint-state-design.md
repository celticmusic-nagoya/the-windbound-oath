## 1. 確定した方針（指示どおり）
1. 行動不能・回避不可。被ダメージ倍率は変更しない。
2. 標準1ターン、最大2ターン。解除直後の1ターンは再付与しない。
3. ターン経過で解除。被弾・通常回復では解除しない。KO と戦闘終了で解除。
4. 見た目は B 案: 3人それぞれ専用の気絶モーション素材を制作する（仕様書: `docs/battle/faint-motion-asset-spec.md`）。素材が採用・実装されるまでは、気絶状態は「静止画 damage ＋ステータス欄の『気絶 N』」で表示する（モーション未採用で本編に出す場合のみ）。
5. 気絶を付与する敵・技は別提案（§9）。**付与元が無い間、本編では一切発生しない**。

## 3. 状態モデル
- `BattleStatus` に型 `stun` を追加（`magnitude` は 0 固定、`remainingTurns` は 1〜2）。`apply` の検証（battle/target/source 文字列、整数ターン）は既存どおり。ラベル「気絶」。
- 付与は新関数 `BattleStatus.stun({battle,target,turns=1,source})` 経由に限定（直接 `apply` で stun を付けても §4 の抑止を通る）。
- **再付与防止**: 解除時に内部効果 `stun_guard`（`remainingTurns=1`、表示なし）を付ける。`stun_guard` がある間 `stun()` は false を返す。`tick` が「解除したラウンド末」に生成するため、`stun_guard` は次のラウンドの敵相を1回だけ覆い、その次のラウンド末に消える（＝解除直後の1ターン）。
- 付与済みの再付与は**延長しない**（既存の「同種は更新」と同じく、残りターンが大きい方に更新せず、最初の値を維持）。上限 2 ターン。
- `clear(battle)`（戦闘開始・終了・リトライ・シーン離脱）で `stun` と `stun_guard` も消える。KO 時は `BattleStatus.release(battle,target)` で stun のみ解除（`stun_guard` は付けない）。

## 4. ターン処理の差し込み点（最小・1か所ずつ）
1. **コマンド入力**: `advanceNormalActor()` と レイダー戦の `rbActor` 切替の直前で `BattleStatus.has(battle,nextActor,'stun')` を見て、真ならそのアクターを飛ばして次へ（Fiona も気絶なら解決へ直行）。コマンドUIは出さず、ログに「エイダンは気絶していて動けない」を1行出す。
2. **解決**: 変更なし（`Acts` に載らないので何もしない）。ただし「Aidan が気絶＝`rbActs` が空の `resolvePartyRound`」でも落ちないことをテストで確認する。
3. **敵相**: 回避判定 `dodged()` は `BattleStatus.dodges()` 側の変更のみで効く。標的選択（`rbHP<=rbFHP?'aidan':'fiona'`）は変えない（気絶者を狙いやすくも狙いにくくもしない＝難易度不変）。
4. **ラウンド末**: 既存の `BattleStatus.tick` が解除と `stun_guard` 生成を行う。
5. **表示**: `BattleActorState` に `stun`（status 連動の保持ポーズ）。`BattleStatus.render` は ATK/DEF/回避のラベルに「気絶 N」を追加（Aidan/Fiona のみ。Lou は §5）。

## 5. ルー固有仕様との整合
- ルーは HP を持たず敵に狙われないため、**現状の敵技では気絶しない**。付与元を設計するときも、ルーを対象にするかは別途決定する。
- 設計上の扱い（推奨）: **初期リリースではルーは気絶無効（immune）**。理由は、`finalBlessing`（全滅時にルーの風が時間を巻き戻す）が確定済みのシナリオ演出で、気絶で阻害されるとリトライ導線（進行不能）に影響するため。
- 将来ルーを対象にする場合の最小仕様: 気絶中はラウンド末の `support()` を呼ばない（`lastSupportRound` は進めない＝解除後に即再開）。`finalBlessing` は**気絶でも必ず発動**（進行保証）。見た目は `lou_stun`（専用素材）。
- KO モーション（`lou_new_ko`）は気絶に流用しない（B案）。

## 6. 安全装置（進行不能・難易度の保護）
- **同時気絶は最大1人**（Aidan と Fiona が同時に気絶しない）。2人目への付与は無効。これで「全員行動不能」「コマンド入力が一度も来ない」状態を作らない。
- ボス戦リスタート・シーン離脱・タイトル復帰で全解除。SAVE/LOAD で気絶は保存しない（SAVE形式不変、LOAD 直後は常に気絶なし）。
- 付与元を追加するまで本編では発生しない。DEV コマンド（ステータス付与）経由でのみテスト可能。
- 難易度・敵パターン・HP/TP/MP・装備・戦闘報酬は変更しない。

## 9. 付与する敵・技の提案（別提案・承認待ち）
実装しない前提の候補。いずれも**付与はレイダー戦ではなく将来の新規敵／新規技**とし、現行ボス（ゴブリン・レイダー）の技・パターンは変更しない。
- 案1: 新規の通常敵（例: 雷系／麻痺系の森の魔物）に「気絶の一撃」を追加。確率ではなく**3ラウンドに1回の予告付き**（現行の「破砕斬」予告と同じ文法）で、予告のラウンドに防御すれば無効（ガードで防げる＝理不尽さを避ける）。
- 案2: 将来のエリア用ボスの特定技で、同時1人・1ターン固定。
- 案3: 味方技（フィオナ／ルーの術）として敵に付与する方向は、敵側の無効フラグ（`immune`）が必要なため、味方向け仕様が固まった後に検討。
- いずれも付与確率ではなく**予告＋対策可能**を原則とし、難易度は個別に評価する。

## 10. 承認結果（2026-10-19 19:02）
1. 気絶解除後の**次の1ラウンドは再付与不可**、その翌ラウンドから再付与可能（§3 `stun_guard` の解釈で確定）。
2. 初期リリースではルーは**気絶無効**。`finalBlessing`（時間巻き戻し演出）を保護。
3. エイダンとフィオナの**同時気絶は最大1人**。2人目への付与は無効（**通常ダメージは維持**＝気絶だけが無効）。
4. 付与元は案1（新規敵の予告付き攻撃・防御で無効）を基本に、**具体案は別途作成**。既存レイダーの攻撃パターンは変更しない。
5. 専用モーションは3人とも6コマ（1〜3=導入、4〜6=保持ループ）で承認。
