# PATCH.GG asset intake and technique-reference policy — 2026-11-16

Official sources: https://patch.gg/ , https://patch.gg/create/toolbox/assets , https://patch.gg/terms (updated 2026-11-11).

## Verified
- Public asset toolbox accessible for browsing; includes 3D models, materials, HDRIs and other categories.
- Patch says library assets have their own licenses and credit lines. No specific stone asset has yet been downloaded or license-verified.
- Default Patch license for other creators' Open repositories permits remix on Patch but **prohibits taking their work off Patch without creator permission**. A distinct open license (MIT, CC BY 4.0, CC0 etc.) can allow external use subject to terms.
- Patch Desktop is Windows-based; CLI/MCP is advertised, but ChatGPT direct Patch connector was not found. Do not assume an authenticated API session.
- Do not copy, trace or modify protected expressive details of restricted third-party models into THE WINDBOUND OATH. Technical study of mesh topology, modular construction, baking and shader approaches is allowed; make independent original art based on common masonry principles.

## Intake gate
1. Search a specific stone/quoin/wall/stone-floor material; save source URL, author, license text and attribution requirement.
2. Check license permits modification, redistribution and use outside Patch in a browser game. If unclear => BLOCKED, do not ingest.
3. Download actual source, verify format (GLB/FBX/OBJ/BLEND), hash and provenance; no claims of acquisition before this.
4. Isolate unmodified original in candidate staging and make derived geometry in separate work area; check scale, UV, normal, triangle count, material licenses.
5. Compare silhouette and fitting at final game size with prior FAIL renders before declaring G2 PASS.
6. If suitable licensed geometry is unavailable, use Patch solely as technique reference and continue with independently modeled, art-directed stone masters or verified CC0 Poly Haven sources.
