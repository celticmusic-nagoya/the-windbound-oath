# 2.5Dテストモード Android実機確認手順（2026-10-14）

対象: 風見の断崖（`cliff_moher_01_spiral_ascent`）のみ。他のマップは2.5Dの定義がなく、モードをオンにしても従来の2D表示のままです。

## 切り替え方（開発者用・プレイヤー向け設定なし）
- オン: URLの末尾に `?height25d=1`（例: `https://celticmusic-nagoya.github.io/the-windbound-oath/?height25d=1`）。そのブラウザに記憶され、以降は通常URLでもオンのままです。
- オフ: `?height25d=0` を付けて開く（記憶も解除）。
- 画面左下に青い「2.5D TEST」が出ていればオンです。
- セーブデータへの影響: オンで保存するとマップ上の高さ(level)が追加で保存されますが、オフで読み込んでも無視されます。保存形式は v30 のままです。

## 確認する場所
1. 通常どおり進めて風見の断崖に入る（または開発メニューから崖へ）。
2. 入口(西側)から螺旋の坂を登り、中腹→頂上まで歩く。
3. 頂上のベンチをタップして夕日の場面を開始する → 襲撃まで進む。

## 正常に見えるべきこと
- 入口は高さ0、中腹は高さ1、頂上は高さ2。坂では連続して持ち上がり、階段/坂の途中で消えたり瞬間移動しない。
- 崖の縁から落ちない。坂以外の場所から上の段へ上がれない。
- 夕日・襲撃の進行が2.5Dオフの時と同じ。
- 「2.5D TEST」オフ（`?height25d=0`）と見比べて、歩行経路・イベントが変わらない。

## 確認してほしい操作
- タップ移動と十字キー相当の両方で入口→頂上を往復（5往復）。
- 坂の途中でベンチや宝箱をタップ（反応する階層でだけ反応するのが正常）。
- 頂上のベンチで夕日イベントを最後まで。
- 崖の途中でセーブ→再読み込み→続きから。

## パフォーマンス上の注意
- 計測が必要な場合は `?dev=1&perf=1` を併用（`docs/qa/android-height-perf.md` の手順）。FPSが極端に落ちる、操作が重い、画面が崩れる場合は教えてください。
- 2.5Dオフ/オンで体感が違う時は、端末名・Chromeのバージョンと合わせて報告してください。
