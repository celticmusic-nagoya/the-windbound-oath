# FIELD-HD-OFFICIAL-MATCH-01 — 公式原本照合ゲート

## 確認できた事実
- `assets/companions/MANIFEST.json` はモルウェンv3、セレナv1、ブラムの正式採用原本とSHA-256を記録している。
- 公式サイトはモルウェンを王立魔法学院首席生徒（17歳）・王立魔法研究院研究協力生と記載。ニーソックスはディレクターが正式指定。
- v5.3比較シートは正式原本からの直接変換ではなく、**顔・髪型・衣装が不一致**とのディレクター指摘あり。従って正式採用不可。

## 未確認事項
- 正式PNGの実画素をこの作業で取得できていないため、髪型、顔、衣装、配色、アクセサリの**視覚照合はNOT_RUN**。
- v5.3比較画像から切り出す方法は正式衣装を補完できず、背景透過も保証できないため不採用。
- Android実機操作はNOT_RUN。CI PASSは実機PASSを意味しない。

## 作業ルール
1. 原本の正式SHAを保護し、原本を実際に確認できる制作環境で個別キャラの特徴を抽出する。
2. 原本と異なる生成候補は採用せず、独立した4方向RGBAを新規作成。モルウェンの髪型・ニーソックスを最優先確認。
3. 32/40/48pxで背景に重ね、視認性と色コントラストを人間が検証。技術QA・ゲーム回帰・Android実機を別々に記録。
4. 全ゲートが満たされるまで既存ゲーム画像の参照を切り替えない。

**現時点の結論: 正式画像の確認が不十分なため、新規HDドット本番適用はBLOCKED。**
