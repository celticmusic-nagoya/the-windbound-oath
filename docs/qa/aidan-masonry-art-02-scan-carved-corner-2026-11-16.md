## 1. 制作方式 F8（因果的差分）
| 要素 | 実装 | 旧方式との因果差 |
|---|---|---|
| 石の形 | 実CC0フォトグラメトリ（Poly Haven `rock_moss_set_01`、rock04は境界辺18本のため除外）を2.5〜5倍に拡大する。その表面の「窓」をレイキャストで評価し（表面被覆率、縁の落ち込み、起伏σ 4〜18mm、隠れ面が岩内部に収まるか）、最良の窓を石の露出面にする | 箱や多面体への変形ではなく、**実測した実在の岩肌**を使う（F1〜F3、F7との差） |
| 接合 | 整層荒積みのレイアウトソルバで互いに素なセルを作る。隅石は長短を交互にし、竪目地は傾ける（±2.5cm/±1.8cm）。目地厚は層ごと・目地ごとに変える。exact Boolean で「岩 ∩ セル」を取る | 床面・竪目地は構造上**共有の厳密平面**になる。生の岩を推測オフセットで置いたF4、リングで支持面が崩れたF5とは異なる |
| 隅石 | セル ∩ 岩A（−Y面の窓）∩ 岩B（−X面の窓）。2つの自然面が不規則な稜で交わる（石工の隅の仕上げに相当） | 単一の丸岩では隅を作れない、という問題を解消 |
| 稜（arris） | 露出する各稜に、角度・後退量・ヨーを変えた面取り平面を2枚入れる（目地の奥行き24mmより手前の空気側だけを削る） | D-F8-2「切断面の平らな棚」の原因を除去 |
| モルタル | 壁外形 − 全セル（exact Boolean）。目地は表面から24mm奥 | 浮き・隙間・貫通がないことを構造で保証 |
| 材質 | `rock_boulder_dry` 2k（CC0）を Box 投影。拡散・粗さ・変位バンプ、石ごとの色ばらつき、AO汚れ、苔、地衣類。モルタルは手続き的な自作材質。梁は `rough_wood` 2k（CC0） | スキャン付属テクスチャは**使っていない**（コケの濃い暗色岩のため）。normal・AOマップはダウンロードしたが未接続（マニフェストに明記） |
