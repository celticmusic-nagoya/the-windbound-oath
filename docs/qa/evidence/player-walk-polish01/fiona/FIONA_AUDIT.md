Whole-canvas native review confirms this is baked art, not renderer clipping. Direction/profile switch therefore changes equipment appearance.

Rightlegacy4 remains a separate3/4 style. Normal near-horizontal↔oblique changes can therefore swap incompatible body/staff/camera banks.

Claude should calibrate a stable body/root and ground-contact annotation, not move canvas per frame to the farthest toe. Evidence `mirror-registration.json`.
6. **No diagnosed Aidan-style internal toe guillotine.** Native boot plates show rounded existing boot silhouettes; all32 have clear outer margins. This is not a general “shoes all PASS”: skirt/leg occlusion and anatomical identity still need candidate review. Do not manufacture holes by treating a hidden far ankle as a missing-pixel defect. 7. **Loop seam/vertical motion needs art QA.** A shared lowest-alpha row does not guarantee body/foot contact continuity: frame silhouettes include staff/hair/skirts and different neutral poses. New poses should be judged with explicit support/swing labels and a ground plane at1x, including6→1.
