# Coverage and limits

- 既存ブラウザ回帰は直列。runnerは各test毎のgit archive committed HEAD、専用serverとserver停止、test前後SHA、exit、印字FAIL/FAILSを記録する。結果未回収は未実施のまま。
- 初回33本はclaim commit `e70942ea6876f8f7409bf9040abedbd85d929f1e`、追加監査probeは後続head。製品1456ファイルのmanifestでmainとの同一性を確認するため、異なるテストheadを同じheadと偽らない。
- 新規probeのnormal_routeのみtitle NEW GAMEから実pathfinder walk/表示control/touch。DEV跳躍・teleport・HP/flag代入・clock加速なし。終了地点はJSONのnormal_route_endpoint、例外はnormal_route_exceptionが正本。seeded diagnosticsは新contextで完全に分離。
- 分割回帰のstoryStage/flag/HP/monster操作、DEV撃破は該当moduleの検証条件であり、初見playerの連続体験・balanceの証拠ではない。
- 原版Node14suiteと素材回帰のFAILは保存。in-memory adapterの57PASSは診断として別保存し、原版結果を上書きしない。
- m19_perfは2map×3viewport、各8秒のcloud headless reference。平均/P99/最大/heap/nodeを取得するが、実機FPS保証・memory leak不存在の判定はしない。
- console/pageerror/HTTP観測は実際にロードした範囲に限定。静的refs0errorは動的な全URLの実機疎通保証ではない。
- Android OS pause/resume、熱・battery・実指touch、全シナリオ通しはこの環境ではNOT_RUN。ユーザーが過去に確認したPhase4/5A/5B PASSは維持し、25A総合実機PASSへ広げない。
- 通常終了後・cancel・LOAD・battle開始のportrait timerはm45で検証。すべてのanimation/timerの長時間ヒープ増加は別backlog。
- 既存仕様にないGAME OVER・未接続mapの新story・未採用Lou表情を新規BUG／不足必須素材としない。正式画像・台詞・セーブ・戦闘数値の変更なし。
