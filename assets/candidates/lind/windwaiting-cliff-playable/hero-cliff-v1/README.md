## 主崖の編集

- 合成済みC8-Bキャリアの海向きの面を、上端・中段・裾の棚として連続変形した。沿岸17地点で高さと張り出しを指定。3箇所の斜めの切れ目で棚の連続線を分断した。キャリア外周、既存の道路、海面、岩モジュール、カメラ・照明・元の材質を継承した。
- 初回の地表測定で歩行許可グリッドの最大差 0.000967 BU を検出。該当する基準三角形の頂点を固定対象に追加した。初回プレビューは最大上昇0.685 BUで頂部が尖ったため、左右の肩を広げ、中央の上昇を抑えた。今回の結果は最大上昇0.488 BU、最大Y変位1.102 BU。公式CGの画像から正史寸法は推定していない。
- 8,753頂点を編集し、UVと材質スロットを引き継いで基準三角分割を明示化した。78,932三角形で新規の非隣接自己接触0。保護した歩行面の3,184頂点、11,372本の地表レイの高さ差は0 BU。岩モジュールとの全体接合判定は未実施。
- playtestの `?hero-cliff=1&photo=1` はキャリアの表示を候補へ切り替える。移動・カメラ障害判定は既存の衝突キャリアを使用。材質なし比較は `?hero-cliff=1`。写真PBRの取得元は [構図版の手順](../composition-v1/README.md)。
