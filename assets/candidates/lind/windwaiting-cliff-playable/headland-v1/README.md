# 風待ちの崖｜主岬の平面再構成

既存 Draft PR #421、基準 `6b89b3ba17d9f53b44ccba9bfc31883cd706332f`。正式CGは現行 main と照合した `assets/approved/game/cliff/sunset_background.png`。候補は Blender 5.3.0、Z-up、海側 −Y、暫定BU。

## 正式CGの計測と設計

836×471の縮小CGの画素座標で、手計測した露岩の投影多角形は主壁9,607.5、中央露岩面8,995、外側岩肩3,952.5 px²。輪郭・岩棚端・前景の草に隠れる下端を分けて記録した。画面上の重なり順は前景草地、主岩壁、外側岩肩、沖の丘。単一画像から見えない深度と実寸は計測できないため、側面・深度は暫定設計値。測線は `headland-blueprint.png`、座標と面積の元データは `geometry-qa.json` に保存した。

6断面で構成する860三角形の新規閉鎖岩体。S1は陸側の接続、S2・S3は主岬と二段の岩棚、S4・S6は下る二つの岩肩、S5は間の谷。S5の上端高1.62 BUは両岩肩の4.74 / 3.30 BUより低く、海側の張り出しも後退する。主岬の冠は最高7.54 BU、最大の海側裾位置はY −8.70 BU。海側の既存草地の肩を最大0.631 BU後退させた。陸側で旧キャリアに埋め込む接ぎ合わせを採用し、二つのボリュームの結合は保留。

草地の頂点を高さごとに押し込む試行では折り返しに自己交差が発生。柱単位で陸側へ移し、歩行点と支持三角形の周囲に固定帯を設ける方法へ変更し、新規自己交差0を確認した。初回描画で主岬が草に隠れたため、主岬の幅と高さを増やし、草の被覆を頂部に絞った。

## 検証と再現

- 11,372本の歩行範囲レイの最大高差は0 BU。道路頂点のSHAは同一。植生54箇所の支持高は不変で、新しい岩体が植生位置を覆った箇所は0。
- 試遊は `/dev/windwaiting-cliff/?headland=1&photo=1`。既存の移動・カメラ衝突キャリアを使用する。写真なしは `?headland=1`。写真材質は [構図版の取得手順](../composition-v1/README.md) に従う。新岩材は既存のハッシュ検証済み Poly Haven CC0 *Rock Boulder Dry*。
- `comparison.png` は正式CGの構図比較、同一カメラの旧候補／新候補、固定WebGL描画。正面・斜め・上方・移動方向および夕景を保存。正式CGと候補のカメラは一致していない。
- `build_windwaiting_headland.py` を Blender 5.3.0 で実行する。元のファイルを保護するため別出力先を指定する。

```sh
blender -b -noaudio --python-exit-code 1 --python tools/map_blender/lind/build_windwaiting_headland.py -- /path/to/new-output
```

固定デスクトップWebGLで、移動・接地誤差0・風の停止と再開を確認した。253,618三角形・111 draw callsで、旧候補比 +860三角形・+2 draws。正式配置、本編統合、Android実機は未検証。
