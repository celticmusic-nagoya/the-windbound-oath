## 設計基準と構造

- 正式CGの地平線、太陽、主岬の肩、中段・外側の岩棚、水際を画像上で記録。固定夕景カメラの地平線と太陽のXを基準に、2D比較ガイドへ登録した。太陽のY残差は `reference-registration.json` に明記。CGの3Dカメラ、実寸、隠れた奥行きは未確定。Blenderと試遊の既存カメラは固定した。
- 旧V2岩体はネイティブに保管。主岬、二つの岩肩、潮位下で接続する岩盤を、段ごとに異なる平面輪郭を持つ閉じたリングから造形した。V3-Bの接続性検査で旧海岸と沖の岩体が別成分だったため、V3-Cで歩行面下の接合岩盤を追加した。結合結果は頂点37,943の1成分。境界辺、非多様体辺、検出された非隣接交差は各0。編集用部位と結合済みメッシュをBlender原本に保存した。
- 一度目は沖の岩肩が固定夕景で細すぎた。歩行範囲に近い前景を削らず、二度目は岩肩の沖行きと幅、主岬の段差の不均一さを調整。固定夕景の部位IDレイで、主岬3,308画素、岩肩A 795画素、岩肩B 63画素。接合岩盤は固定夕景で0画素であり、物理接続後も奥行きや陰影による縦の暗部は残る。Z ≤ 4.8 BUの露岩はV2の78からV3の525画素。原点はZ-upの暫定BU。部位別可視図と奥行きは `visible-ids.png`、`visible-depth.png`、`visibility.json`。
- [目標図と断面](v3-target-and-sections.pdf)は登録ガイド、設計平面と岩層、V2/V3の実測6断面。目標制御点と実測交線は `qa.json` の別フィールド。造形の検証は `comparison.png` と夕景・正面・上方・右側面の同条件クレイを参照。

## 保護と試遊

歩行11,372点、植生54点の支持高差は0 BU。道路座標とナビゲーションSHAを保存。既存の衝突キャリア、植生、風、道路を使用。隔離WebGLで固定出発点・カメラ・移動・接地・風停止と再開を確認。出発点は249,708三角形、114 draws。試遊フラグは `?cliff-v3=1&photo=1`。旧地表・植生の写真材質を使い、新岩体はクレイ。正式配置とAndroid実機は未検証。

再生成はBlender 5.3.0で `tools/map_blender/lind/build_windwaiting_cliff_v3.py`、描画とIDレイは `render_windwaiting_cliff_v3.py`、図面は `draw_windwaiting_cliff_v3.py`。編集原本、GLB、図面、PNG、QAとSHAはこのディレクトリに収録。
