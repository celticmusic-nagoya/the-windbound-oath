# 風待ちの崖｜V3-D 連続岩盤のクレイ候補

既存 Draft PR #421、基準 `1677166cb53570d65be97fe1c0104ba36bba5c17`。現行mainで登録された正式夕景CGのSHAと照合。添付8547.jpgは草地稜線、岩肩、侵食谷、岩棚・沖合岩礁の**相対関係**に使用。添付画像から手計測した座標は `qa.json` に記録した。正式CGの3D投影・世界尺度・隠れた奥行きは未確定。

## 分析と形状

- **下面と接合**。V3-Cはすでに閉じた1成分で、下面の問題は開境界ではなく、結合された複数の岩体に残る段差・面割りと暗い接合。水と別オブジェクトを隠した同一診断カメラで比較した。V3-Dは草地の戻り、上下の岩棚、潮位下の支持底を同じ断面リングにし、非平行の平面輪郭14地点で連続造形した。旧キャリアとの陸側は形状として結合。沖の小岩礁2基のみ独立。
- **段差と侵食谷**。暫定座標のX=2.78 BU付近を第一岩肩、X=5.17を谷、X=7.86を第二岩肩の制御点とした。実測図に全部位の輪郭・面構成とV3-C/V3-D断面を収録。歩行範囲への被りを検出した試作は棄却し、保護面の外で陸側の戻りを切り替えた。
- **第二岩肩の遮蔽**。候補の低い海側三角形から固定夕景へのサンプルで、第一遮蔽物の最多は既存歩道側を含む地表材（200件）。新しい岩面やクレイ草地も一部を遮蔽した。初回のクレイで長い草地側の斜面が露岩を隠したため、非歩行斜面に横向きの岩壁と岩棚を追加した。同じカメラのV3-Dでは新岩盤の露岩2,655画素、独立岩礁19画素。V3-Cの同条件でタグ付けした岩盤4,166画素より少なく、第二岩肩は63→19画素。材質別IDの面積は造形判断の補助。
- **実測と図面**。 `target-plan-and-sections.pdf` は設計平面・立面、実測6断面、CG対照、実メッシュの頂点・面図。 `qa.json` は測定値、補助図に基づく推定、頂点座標、面構成を区別した。固定夕景・正面・側面・上方と、診断下面のV3-C/V3-Dレンダーを収録。

## 保護とゲート

- **G1 BLOCKED**。正式CGのSHA一致。正史座標・尺度・正式採用は保留。
- **G3 PASS（検査範囲）**。主岩盤は1成分、岩礁は各1成分。閉境界、非多様体辺、面方向の不整合、検知された非隣接の真の交差は0。符号付き体積は正。主岩盤に面積1e-9 BU²未満の三角形が3枚。V3-Cの検出数も3枚。原本を再開して上下を描画し、GLBを出力した。歩行11,372点・植生54点の支持高差は0 BU。道路頂点SHAはV3-Cと同一。
- **G4 全体未検証**。隔離WebGLを `?cliff-v3d=1&photo=1` で実行。旧地表と植生は既存写真材質、新規岩盤と岩礁はクレイ。旧衝突キャリアと歩行グリッドを使用。対応する本編統合とAndroid実機は未実施。

Blender 5.3.0で `tools/map_blender/lind/build_windwaiting_cliff_v3d.py`、 `render_windwaiting_cliff_v3d.py` を使用。図面作成は `draw_windwaiting_cliff_v3d.py`。公開物は `SHA256SUMS` で検証できる。

**独立G2 FAIL。新規写真PBRは保留。** 陸側接合と下面は局所改善。固定夕景では第二岩肩と岩棚下部が引き続き前景に隠れる。旧地表による遮蔽200サンプルのうち、歩行点から水平0.35 BU以内は115件。独立レビューの画像SHAと所見は `independent-clay-qa.json`。隔離デスクトップWebGLでは同一出発点から移動、接地、風を検証し、243,086三角形・115 draws、移動接地誤差0 BUを記録した。
