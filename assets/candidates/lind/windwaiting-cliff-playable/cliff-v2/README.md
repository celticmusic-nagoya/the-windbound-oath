# 風待ちの崖｜精密設計図ベース再造形 V2

Draft PR #421、基準 `23496d2519885acfcad7f7471992194e5fefffcf`。最新版mainの正式CGとのSHA一致を確認。真の世界尺度・配置は暫定BUのまま。

## 造形と差分

- 固定夕景では旧地形と主岩壁の両方が下段への視線を遮る。沖側の岩棚を伸ばす方式を2試行し、Z ≤ 4.8 BU の岩材はどちらも0画素だった。そこで歩行範囲外の草地の肩に、傾斜をつけた閉じた楔形の切削を適用した。頂点圧縮の初回試行は結合後の支持面不成立で棄却し、閉じた切削体に切り替えた。固定夕景の下段は0→78画素、岩材全体は3,596→3,483画素。418×235ピクセルで最前面の新岩材を数えた値。影や色から面積を推定したものではない。
- 二つの岩肩と谷を、平面位置と高さの異なる断面に組み直し、岩棚を段状にした。S5の岩肩とS8の岩肩のあいだにS6の谷を置いた。個別の深度・高さは `structure-delta.json` の実測頂点と設計値を参照。陸側の岩体と旧キャリアを一体化し、結合meshに新規の非多様体辺・非隣接交差候補は0。独立QAで暗く見える接合は残った。
- 既存の Poly Haven CC0 *Rock Boulder Dry* の Base Color・Normal・Roughnessを保護し、BlenderとGLBに収録。UVは既存の1.30暫定BU基準を岩層方向へ傾け、横断成分を1.28倍。Normal強度は0.62。UV0・接線と既存海岸のPBRを維持。正式実寸への換算は未承認。
