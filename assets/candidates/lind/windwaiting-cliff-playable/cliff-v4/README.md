# 風待ちの崖 V4 | Draft PR #421

V3-D の `b8aec7c83f978d43372e6829b2008740c09d5a9a` から制作したクレイの比較結果。固定夕景は V3-D のカメラを継承した。設計の座標は仮ローカル Blender Unit (BU)。正式 CG のランドマークは 836 × 471 に縮小して採寸し、添付 8547.jpg のランドマークは表示画像上で採寸した。単一画像で特定できないカメラ内部諸元、不可視面、海面下、絶対スケールは推定または仮設計として記録した。

## 比較と精密化

- A は陸側から海へ連続する広い尾根を持つ。B は西の岩肩を後退させ、Y = −15.90 BU 付近の稜線を A の 5.75 BU から 4.45 BU に下げ、下段岩棚をつないだ。固定夕景、正面、上空のクレイ比較は `proposals/`。
- B は A より第二岩肩と谷が分かれ、左側面で二つの岩肩の高さと奥行きを追える。第一岩肩の露出が後退し、固定夕景で谷の深さを伝えきれない。精密化は B の海側の岩面に限定し、断面を細分化して層と侵食痕を形状に加えた。
- 精密化の初回は Boolean 接合部で許容値 1e−7 BU を超える微小交差を検出した。再試行では陸側の断面間隔を比較モデルと同じに戻し、細分化を沖側へ限定した。現在のメッシュでは同じ判定で交差ゼロ。
- 固定カメラの初回ヒットを、V4 の露岩材質面だけを含む BVH のヒットと比較した。露岩より手前の遮蔽は同一の岬メッシュ 15,289 ピクセル、草・芝 1,192 ピクセル、海 57 ピクセル。岬メッシュ値には草地キャップ、既存の地形キャリアおよび岩盤の自己遮蔽が含まれる。岩肩を覆う主因を植生だけとみなす根拠はない。次の断面設計では接地サンプルの分布と手前の遮蔽領域を重ね、可動範囲内で低い草地縁と急な岩壁を検証する。

このフォルダに新規写真素材を追加していない。候補 GLB は既存公開 PR の形状・材質と V4 のクレイ材質を使用する。GLB に同梱された既存画像 5 点は、V3-D 公開候補の同名画像と SHA-256 が全件一致した。比較図はリポジトリにある正式 CG とクレイの実描画を使用し、補助画像と非公開 handoff は再配布していない。GLB はゲームの仮設 QA 入口 `dev/windwaiting-cliff/?qa&cliff-v4=1` で選択できる。既存の移動・接地データを使用する。

## 再現

リポジトリルートから Blender 5.3 を使用。A/B は別ディレクトリに作成し、B の精密化のみ GLB をエクスポートする。

```sh
scripts=tools/map_blender/lind
for mode in A B; do
  run="/tmp/cliff-v4-$mode"
  blender -b -t 8 -P "$scripts/build_windwaiting_cliff_v4.py" -- "$mode" "$run"
  blender -b "$run/cliff-v4_UNAPPROVED.blend" -t 8 -P "$scripts/render_windwaiting_cliff_v4.py" -- "$run"
done
run=/tmp/cliff-v4-refined
blender -b -t 8 -P "$scripts/build_windwaiting_cliff_v4.py" -- B "$run" --refined
blender -b "$run/cliff-v4_UNAPPROVED.blend" -t 16 -P "$scripts/render_windwaiting_cliff_v4.py" -- "$run" --full
```

WebGL は既存 Playwright 検査を `--include-v4` 付きで実行する。計測値と画像は三角形予算の判定前に出力する。比較 PNG と精密設計図に使う固定ゲーム画像は候補の初期位置を実際に描画したもの。図面は候補ディレクトリで `python tools/map_blender/lind/draw_windwaiting_cliff_v4.py <候補ディレクトリ>` をリポジトリルートから実行して更新する。 `qa.json` には原本の面・法線・材質 ID と断面交線、 `design-targets.json` には画像採寸と仮設計の入力を保存した。
