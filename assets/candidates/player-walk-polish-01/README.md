## 2. 候補の作り方（描き直しはしていない）

- **エイダン 上下（各6コマ）**：描かれた3コマはそのまま使い、残り3コマはその3コマの**脚部分だけ**を左右反転して作りました。脚以外（顔、髪、マント、剣、腕）は元の絵のままです（`tools/mirror_legs.py`）。
  - 下：01 着地 → 02 支え・後ろ足を蹴る → 06 すれ違い → 01・02・06 の脚反転（反対の足で同じ流れ）
  - 上：03 着地 → 04 つま先離れ → 06 すれ違い → 03・04・06 の脚反転
- **フィオナ 横（左右各6コマ）**：04（歩幅最大）→ 03 → 01（すれ違い）と、この3コマの「奥の足が前」版。奥の足が前に出るときは、前の足に花が見えず、後ろ（手前）の足に花が見えるのが正しい形なので、靴の花びらを前の足から後ろの足へ移し、手前・奥の濃淡も入れ替えました（`tools/swap_side_legs.py`）。足の形・位置・胴体は元の絵のままです。右向きは main と同じ規則（左右反転＋平行移動）で作りました。
- **フィオナ 上（4コマ）**：01・03・04 を、足元の基準点 (640,790) を中心に 0.955／0.945／0.955 倍へ縮小し、待機と02の大きさに揃えました。頭の上下動は 43px から 11px に減りました。

## 4. 既知の制約・未解決（ディレクター判断／描き直しが必要）

1. **エイダン 上05（04の脚反転）**：拡大するとマント裾の白い縁に横向きの切れ目が見えます。調整は3回で打ち切りました。ゲーム表示（1倍）ではほぼ見えません。気になる場合は描き直しを依頼してください。
2. **脚反転コマの腕振り**：腕は元の絵のままなので、反転したコマでは腕と脚の対応が逆になります。正面・背面とも腕の振りが小さく、1倍表示では目立ちません。
3. **フィオナ横の花の移し替え**：前の足の花びらを消した跡に、黄色っぽい塗りが少し残ります（拡大時のみ見える）。
4. **フィオナ横と他方向の衣装・装備の不一致**：横向きの絵だけ杖を持っておらず、ドレスの配色も違います。これは元の絵の問題で、画素の加工では直せません。描き直しが必要です（ChatGPT 依頼の対象）。
5. **フィオナ斜め（3/4）**：右斜めは同じ足が4コマ続けて前に出ます。左斜め03は顔の向きが違います。画風を保ったまま反対の足を作るには描き直しが必要です。左右反転で流用すると杖を持つ手が入れ替わるため、使いません。
6. フィオナ 下：交互運びはあるので変更していません。02・04（すれ違い）が待機画像と同じかほぼ同じなので、すれ違いで足を持ち上げるコマがあればさらに良くなります（任意）。
