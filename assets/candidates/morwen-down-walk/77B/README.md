# MORWEN-WALK-4DIR-ART-FIX-02 下向き77B（HDドット絵の描き直し候補）

旧77は比較用にそのまま残している（上書きしていない）。基準画は正面の候補画（`../77/reference/`、SHA-256 73e99f19…）。

## 作り方
上76Bと同じ方法（`../../morwen-up-walk/76B/hdpix.py`）で描き直した。
- 配置: 帽子と頭は2〜52行・横0.13倍、上着とスカートは52〜100行、スカートより下のケープは100〜113行（横0.08倍）。旧77より帽子を大きく、体を短く太くし、側面の頭身と帽子の比率に合わせた。
- 顔は描き起こしている（`face_front`）。
  - 96px: 紫の瞳（上から暗・中・明の3段階）に白い光点、金の丸メガネ（つる・ブリッジ付き）、口。
  - 48px: 瞳を2×2で左右に置き、口を入れた。
  - 顔の範囲は1px整理の対象外にしている。
- 前髪は判定した髪をそのまま使い、ボブの毛先は部位の判定から作っている。
- 歩行は77と同じ。右脚は画面左側にあり、奥行き3px、脚上げ5px、骨盤と肩の逆の動き、手は脚と逆に振る。

| 指標 | 74G左 | 77（旧） | 77B |
|---|---|---|---|
| 色数（96） | 2467 | 164 | 31 |
| 1px孤立点 96／48（顔は除外） | 4.33／0.67 | 5.92／1.0 | 5.58／1.25 |
| 金のちらつき（CV）96／48 | .0178／.0331 | .0155／.0107 | .0122／.0336 |

再生成:
```
python3 build_morwen77b.py --front ../77/reference/morwen_front_candidate_73e99f19.png --out .
```
