# MORWEN-PIXEL-70 ART-70A/B/C（全体美術ブラッシュアップ・候補）

- **推奨候補：ART-70B。** 保護画素の変更は0。
- **ART-70Cは保護領域の改善案（未採用）。** 採用にはディレクターの承認が必要。変更箇所を赤く示した旧PROPOSAL_DIFF派生プレビューはMORWEN-CANON-CLEANUP-02で削除。元フレーム・生成スクリプト・判定記録は保持し、削除パス/SHAは `docs/qa/morwen-canon-cleanup-02/DELETED_PATHS.json` に記録。

- 体（胸）の揺れは追加していない。胸元のリボン・襟は68からの1コマ遅れの揺れをそのまま使っている。
