## 2. 実装
### パレット（7-1）
脚・ブーツ・プリーツ・金の各階調は、まず設計値を決め、上半身（65B F00の保護画素）に実在する最も近い色へ寄せた。寄せた色数は全35色中32色。寄せきれなかった3色（ブーツの鏡面反射、奥脚の金の明部）は設計値を使用。

役割別の階調：
- ニーソックス：最暗→シャドウ→ベース→中間明→ハイライトの5階調。奥脚用は1段暗い別系統
- ブーツ（黒紫）：5階調＋鏡面反射1色
- 金具：5階調
- プリーツ：5階調

置き換えは一括のRGB変換ではなく、部位ごとの陰影マップで行う。マップは次の要素で決める。
- 円柱の陰影（脚の断面方向の位置）
- 膝頭の明部と膝裏の折れ影
- スカート下2〜3行の遮蔽影
- ブーツ正面よりの鏡面反射の筋
- 1画素だけ孤立した色の除去（陰影を画素のまとまりで描くため）

輪郭は明るい側を素材の最暗色、影側をほぼ黒にした。手前脚と奥脚が接する所には分離線を入れた。

### ブーツ（4-3）
- 上端のカフベルトに金のバックル（枠と舌の影）
- 正面にX字の編み上げ（3行周期、金の明部・中間・穴の暗色）
- 足首ベルトと小さなバックル
- つま先の丸みにハイライトの塊と鏡面1画素
- 靴底のコバ（明るい縁）と暗い接地面、かかとブロック
- かかと着地・蹴り出しのコマだけ、足首前側に屈曲じわ
- 脚を大きく振ったコマ（すねの傾きが35°超）では、編み上げを中央の交点だけに絞った（斜めのノイズを防ぐため）

### スカート左端（作業B）
- 直線の切断領域42画素を外し、無地の濃紫プリーツとして描き直した。プリーツは3画素幅で、山・面・谷を描き分けている。
- 裾は左（背中側）へ向かって下がる流れにした。x=53・y=89で保護側の金ラインにつながり、x=36・y≈93でマントの下に入る。
- 金の裾ラインは1画素で途切れずに続く。その下に1行の影を入れている。
- 中央のチェック柄と右側のプリーツは保護対象で、一切動かしていない。
- 揺れは脚の1コマ後に追従させた（`SKIRT_SWAY=[0,-1,0,0,-1,0]`）。マントはさらに遅れて追従する（66の値のまま）。

### レイヤーとZ順（7-2、奥→手前）
`cape_back` → `far_leg` → `far_boot` → `near_leg` → `near_boot` → `skirt_left` → `skirt` → `torso` → `accessories` → `per_frame_detail_patch`

`immutable_master`は`skirt`・`torso`・`accessories`の3つ（3,643画素）を指し、上下動しか加えない。スカートは必ず脚より手前に描かれる。

画素数の内訳：accessories 299（鞄・手・ポーション）、skirt 220、torso 3,124、描き直し領域 42。

### フレーム別パッチ（7-3）
`FRAME_ART_PATCHES`と`FRAME_ART_PATCHES_48`（座標・色・理由を記録する形式）を実装した。全12枚を拡大して確認した結果、手作業の画素修正が必要な箇所はなかったため、現在は空。推測で座標は入れていない。F04で見えた編み上げの斜めノイズは、パッチではなく上記の描画ルールで直した。

### 48×64（8）
- 脚・ブーツ・スカート左端は48pxで直接描いた。階調は4つ、編み上げは1列の点、バックルは1画素、裾ラインは1画素。
- 固定レイヤーは65B・66と同じNEAREST規則で縮小している。

## 3. フレーム別の修正履歴
F00とF03で描画ルールを確定し、残りの4コマは各フレームの脚の姿勢から個別に描いている（単純な複製ではない）。

| F | 姿勢（手前／奥） | 主な調整 |
|---|---|---|
| 00 | 接地／蹴り出し | 基準フレーム。ブーツの全ルール、裾の安定、スカート揺れ0 |
| 01 | 荷重／遊脚・後方 | 1px沈む。膝の明部、スカート−1、マント−1 |
| 02 | 立脚中期／遊脚・前方 | 脚の交差。手前と奥の分離線を確認 |
| 03 | 蹴り出し／接地 | 基準フレーム。足首の屈曲じわ、つま先、裾の追従 |
| 04 | 遊脚・後方／荷重 | 1px沈む。手前脚を大きく振るため編み上げを中央の交点のみに。スカート−1 |
| 05 | 遊脚・前方／立脚中期 | 次のF00の接地へつながる姿勢（66と同じ位相） |

## 5. 残る課題
- **画風の差：** 上半身はHD画像を縮小した由来の細かいノイズ状の階調、脚は塊で塗った陰影。統一感は66より上がったが、差は残る。上半身側の整理は保護対象の変更になるため、今回は行っていない。
- **ブーツの明るさ：** 黒紫を基調にしたため、草地の背景では脚全体が暗く見える場合がある。
- **腕振り：** 66と同じく付けていない（鞄に手を添えた公式の姿勢）。
