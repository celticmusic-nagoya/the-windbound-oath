## 美術的に改善した箇所（71に適用）
| 部位 | 内容 | 変更画素（96px、F00〜F05） |
|---|---|---|
| ブーツの革・輪郭 | 手前脚の光が当たる側の輪郭を1段明るい既存色にし、暗背景でも縁が読めるようにした | ブーツ全体で5〜29、48pxで0〜11 |
| つま先 | 先端の縁に明るい色を入れ、丸みを出した | 同上 |
| 足首 | 全コマで足首前側に1行のしわを入れた（以前はかかと着地・蹴り出しのコマのみ） | 同上 |
| かかと | 背面上半分に明部を入れ、接地面を暗い線で締めた | 同上 |

- 脚の輪郭と背景の明るさの差（70B→71）：暗37.1→37.9、明188.5→188.0、苔68.7→67.7、土99.5→98.7。暗背景ではわずかに改善した。

## 変更しない方が美しいと判断した箇所
| 部位 | 判断 | 根拠 |
|---|---|---|
| 帽子の金刺繍（案HAT_GOLD） | 不採用を推奨 | 金を3段階にまとめると、刺繍の立体感を作っている中間の明度が失われ、つばが平板になる（変更218画素、すべて保護領域） |
| 胴体・スカートの金（案UPPER_GOLD） | 不採用を推奨 | ケープの縁取りや紋章まわりの陰影が平らになる（変更145画素） |
| 花飾り（案FLOWER） | 採用は任意（効果は小さい） | 花びらの孤立ノイズ14画素が周りの色に溶け込む。形は変わらず、改善はわずか |
| 眼鏡（案GLASSES） | 採用候補（承認が必要） | 金の縁が3段階でそろい、輪郭が締まる（変更28画素。目と顔は変更0、指定範囲外の変更も0） |
| 顔・前髪 | 変更しない | 公式デザインの同一性に直結する。現状の画素が正本の表情をよく保っており、1画素の調整でも印象が変わる危険が大きい |
| マントの刺繍 | 70Bのまま | 70Bで金3段階の整理とノイズ統合は済んでいる。これ以上削ると刺繍の模様そのものが消える |
