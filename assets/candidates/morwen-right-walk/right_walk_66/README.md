## 2. 方針
局所修正はせず、**腰から下を毎フレーム描き直した**。上半身は65B F00を固定意匠として、画素単位で保護している。

### 歩行周期（作業B）
左右の脚は同じ位相表を3コマずらして使う：手前脚の位相 p=f、奥脚の位相 p=(f+3)%6。

| 位相 | 足首x（腰基準） | 足の角度 | 浮き | 役割 |
|---|---|---|---|---|
| 0 | +9 | つま先上げ16° | 0 | 接地（かかとから着地） |
| 1 | +3 | 0° | 0 | 荷重（足裏全体が接地） |
| 2 | −3 | 0° | 0 | 立脚中期（体が足の真上を通過） |
| 3 | −9 | かかと上げ24° | 0 | 蹴り出し（つま先だけ接地） |
| 4 | −6.5 | −22° | 5px | 遊脚・後方（膝が前） |
| 5 | +4 | +2° | 4px | 遊脚・前方（パッシング） |

| フレーム | 手前脚 | 奥脚 | 上下動 |
|---|---|---|---|
| 00 | 接地（前） | 蹴り出し（後ろ） | 0 |
| 01 | 荷重 | 遊脚・後方 | +1（沈む） |
| 02 | 立脚中期 | 遊脚・前方（通過） | 0 |
| 03 | 蹴り出し（後ろ） | 接地（前） | 0 |
| 04 | 遊脚・後方 | 荷重 | +1（沈む） |
| 05 | 遊脚・前方（通過） | 立脚中期 | 0 |

- 立脚中の足は1コマごとに6px後ろへ動く（両脚とも6.0/6.0/6.0px）。ゲーム側の移動速度もこれに合わせる必要がある（96×128基準で6px/コマ、48×64では3px/コマ）。
- 上下動は3コマ周期（荷重のF01・F04で沈む）。
- F05→F00は、手前脚が遊脚・前方からかかと着地へ、奥脚が立脚中期から蹴り出しへ移る、表どおりの続き。
- 膝は2本の骨（腿15px・すね16.5px）で計算し、常に前へ曲がる。
- 接地している足の最下行は、毎フレーム必ず124行目（48×64では61行目）にそろえている。
- マント裾：下端を0〜−1pxずらして揺らす（荷重〜通過のコマで後ろへなびく）。
- 腕：手は鞄に置いたまま（公式意匠の「鞄に手を添える」姿勢を保つ）。腕振りは付けていない。

### レイヤーとZ順（作業C、奥→手前）
1. `U_back`：マント下部と裏地（65B F00、y≥91かつ明示した境界より左）。揺れはずらしのみ。
2. 奥脚：ニーソックス（腿）→ブーツ筒→カフ（金バックル）→足→かかと・靴底。編み上げは金のX。
3. 手前脚：構成は奥脚と同じ。配色は1段明るい。
4. `U_front`：胴体・腰・腕・手・鞄・ポーション・スカート（y≤89。x<46だけはy≤90まで）。保護対象で、上下動以外は動かさない。

フレーム別の接続補修レイヤーは不要。脚を毎フレーム一体で描くため、継ぎ目ができない。

96×128は8倍で描いてから多数決で縮小し、陰影と1px輪郭を付ける。48×64は**脚だけ48pxで描き直し**（輪郭を保つため）、固定レイヤーは65Bと同じNEAREST規則で縮小している（65Bの48px版と保護画素のRGBが一致）。
