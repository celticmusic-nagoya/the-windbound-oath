| 候補02の白い裏地・内外套が切り替わる | PR #142 では、両腕を覆う大きめの多角形を核にし、その外側28px まで境界線を探していた。そのため、腕の周りの外套・白い裏地まで06の絵に置き換わっていた |

| コマ | 本番 | PR #142 | **ARM-02** |

- 反転・塗り足し・inpaint はしていません。

## 3. 結果

**コマ間の見た目の変化**：PR #143 と同じ ROI と指標（合成RGBの平均差、0〜255）です。動きの量ではなく、見た目がどれだけ変わったかを示します。

| 境界 | 手袋の周り 本番 / #142 / **ARM-02** | 白い裏地 本番 / #142 / **ARM-02** |
|---|---|---|
| 01→05 | 27.2 / 27.3 / **34.4** | 33.3 / 31.4 / **32.5** |
| 05→02 | 35.6 / 59.0 / **54.9** | 30.8 / 50.7 / **43.4** |
| 02→06 | 52.7 / 34.9 / **38.5** | 49.8 / 39.0 / **44.2** |
| 06→01 | 50.5 / 56.6 / **50.5（本番と同じ）** | 40.4 / 47.0 / **40.4（本番と同じ）** |

- 反対の腕と胸の ROI は、全ての境界で本番と同じ値です。
- 06→01 は本番と同じになりました。
- 05→02 の白い裏地の変化は、#142 から約14% 減りました（50.7→43.4）。ただし本番（30.8）よりは大きいままです。腕が上がることで裏地の見え方が変わるのは、動きとして避けられない部分です。

**拳の位置**：胸の位置で上下の揺れを差し引いた値です。本番は手で読み取った値（±3px）、候補は提供元の値に、ずらした量（正確な値）を足したものです。
