## 1. 生成画像の適合性検査

生成画像は 958×1641 の RGBA で、四隅は透過です（`input/chatgpt_right_leg_generated.png`）。

| 項目 | 結果 | 内容 |
|---|---|---|
| 1. 右足が本人の右足（画面右）か | 合格 | 画面右の足が上がり、靴底がこちらを向いている |
| 2. 蹴り出し姿勢が自然か | 条件付き | 足が地面から高く上がった「振り上げ（足を戻す途中）」の姿勢で、つま先が地面に着く蹴り出しではない。正式02（左足）と同じ位相なので、歩行としては自然 |
| 3. 左足が接地を維持しているか | 合格 | 生成画像の左足は接地。合成では左足に正式03の画素を使うので影響なし |

| 5. 右脚の付け根とつながるか | 条件付き | 生成画像の外套・裾は**全面的に別の絵**（正面向きの飾り、異なる柄）。使えるのは脚だけ |
| 6. 提案マスク内に収まるか | 合格 | 位置を合わせた生成の右脚のうち、マスクの外に出るのは 137px だけ（切り捨て） |
| 7. 縮尺・視点・画風 | 縮尺・視点は合格／画風は不一致 | 生成画像の左ブーツを正式03の左ブーツに重ねると、倍率 0.30 で長さと幅が一致（変形なしの等倍率）。画風は上記4の通り |

**合成可否：ADJUST。** 脚だけなら合成できますが、画風の差と境界の手直しが必要です。

## 2. 局所合成の方法（`tools/composite.py`）

- 生成画像を 0.30 倍に縮小（変形なし）し、生成画像の左ブーツの底の中心 (375,1560) が、正式03の左ブーツの底 (1009,1229) に重なる位置に置きました。
- 生成画像からは、多角形で選んだ右脚の範囲だけを使い、外套の緑・白い裾・金の縁は除外しました。
- 正式03の古い右脚は、マスクの中で、左ブーツの輪郭線（最小コストの経路で追跡）より右、y≥960 の範囲だけ削除しました。
- 正式03の外套・フリルは削除していません。
- 反転はしていません。

| 試行 | 方法 | 問題 |
|---|---|---|
| 1 | 色で脚を判定 | 生成画像の金の縁が脚として混入。左ブーツの右端が欠ける。腿に穴（1,056px） |
| 2 | 膝より上はズボンの色だけ | 装甲の一部が抜ける。左ブーツの右端は縦一直線に欠ける |
| 3 | 多角形で脚を選び、直線（x≥1070）で削除 | 左ブーツの右端が縦一直線に切れる |
| 4（試作） | 削除の境界を左ブーツの輪郭線に合わせる | 下記4の課題が残る |

## 4. 採用に必要な手直し（手描き）

1. 右靴の靴底：溝の模様を消し、正式01・02 の靴底のように、なめらかな濃い茶色で塗り直す。装甲の輪郭と鋭いハイライトを、正式03の柔らかさに合わせる。
2. 膝当ての上端：水平の切れ目を、ズボンへ自然になじませる（y≈929〜945、x≈1048〜1100）。
3. 左ブーツの右輪郭（x≈1055〜1070、y≈1020〜1160）：小さな欠けを、正式03の輪郭どおりに直す。
4. 右膝の右側（x≈1120〜1150、y≈940〜1010）：正式03のフリルの断片を、外套の裏として自然に閉じる。または透明にする。
5. 閉じた透明穴 37px を埋める。

手直しの方法の候補：
- ChatGPT に試作PNG の切り出しを渡し、上の1〜5だけを修正してもらう
- 人手で修正する

修正後は、`composite.py` と同じ手順でマスク外を正式03に戻し、再検査します。
