## 旧マスク（PR #149）の問題点

`manifest.json` の `masks` に計測値があります。

| 項目 | 旧マスク | 新マスク |
|---|---:|---:|
| 編集範囲に含まれる左脚（接地している足）の画素 | **13,579**（左ブーツの右半分を含む） | 1,451（すべて、意図した重なりの帯） |
| 編集範囲に含まれる外套・裾の画素（y<1000） | **10,536**（裾と外套の縁を描き直せてしまう） | 0 |
| 03の右脚を覆う割合 | 98.7% | 97.2% |
| 推定した靴底の範囲を覆う割合 | 100% | 100% |
| 輪郭の直線部分の最長 | 181px（多角形） | 87px（地面より下の行） |

旧マスクの問題：
1. 左脚の右半分まで編集範囲に入っていた。
2. 裾・外套の縁が入っていた。
3. 直線の多角形だった。

## 新マスクの作り方と理由

- **含めるもの：**
  - 03の右脚を 6px 広げた範囲
  - 裾の下から靴までの通り道
  - 推定した蹴り出しの靴の範囲（中心 (1088,1170)、横66・縦72の楕円）
- **除外するもの：**
  - 接地している左脚（青）
  - y<1000 の外套・裾・金の縁（ズボンと背景だけを許可）
- **重なりの帯（黄、1,451px）：** 左脚のうち x≥1036・y≥1090 の部分だけを編集可にしています。蹴り出す右足は左足より手前にあるため、左ブーツの右端に重なる必要があるからです。
- **拡張した理由：** 右へ66px（x 1177まで）、下は靴底まで広げました。蹴り出しの靴は手前にあるので大きく、03の小さな右足よりも広い範囲が必要です。
- **靴底の推定位置：**
  - 体の中心 x≈1041。接地している左足（03）と右足（01・06）の靴の中心から計算しました。
  - 正式04 の左足の蹴り出しは、中心から −46px にあります。そこから右足の位置を x≈1087 と推定しました。
  - これは数値の計算で、画像の反転はしていません。

## 合成条件（後工程で保証します）

- 出力は 2048×1280・背景透過・アンカー (1024,1230)・接地線 y=1229 のまま。トリミングや拡大縮小はしない。
- 最終合成では、`proposed_mask.png` の黒の範囲を正式03の画素に機械的に戻し、差分を検査します。マスク外が一致することは、画像生成AIではなく、この後工程で保証します。
- 切り出し画像を編集した場合は、元画像の座標 (940,760) に貼り戻します。
