# PLAYER-WALK-POLISH-01｜新規描画の制作依頼（Phase B）

この環境には画像を描く・生成する手段がありません。ここに挙げるフレームは、既存画素の組み替えで代用しない（ディレクター指示 2026-11-03 22:06）ため、描き直しが必要です。
仕様の正本は `docs/art/PLAYER-WALK-POLISH-01_CLAUDE.md`（PR #129 @ `84e5c0c5`）です。納品物は `assets/candidates/player-walk-polish01/{aidan,fiona}/frames/` に候補として登録し、正式採用はディレクターが判断します。

## 共通条件

- **キャンバス・基準点（本編と同じ）**
  - エイダン：2048×1280、足元の基準点 (1024,1230)、表示倍率 0.0625
  - フィオナ：1280×832、基準点 (640,790)、表示倍率 0.1
  - 両足の接地面を基準点の y に合わせる。体の中心（骨盤）は基準点の x に置く。
- 透明背景のPNG（RGBA）。市松模様・地面の線・影を絵に焼き込まない。杖・髪・裾を含めても、画面端に透明の余白を残す。
- 顔・髪・花飾り・人間の耳・衣装・ブーツ・装備・色・頭身・画風は、既存の採用済みの絵と同じキャラクターとして描く。
- 足だけを差し替えない。膝・裾の揺れ・腕の振り（脚と逆の位相）・重心移動を、絵としてつなげて描く。
- 位相の基準（仕様と同じ6コマ）：
  1. 左足接地・右足後方
  2. 左支持・右足通過
  3. 左支持後半・右足前方スイング
  4. 右足接地・左足後方
  5. 右支持・左足通過
  6. 右支持後半・左足前方スイング → 1に戻る
- 左右の向きの取り方：
  - 正面：本人の左足が画面の右。
  - 背面：本人の左足が画面の左。
  - 左向きの横：見えている側（手前の脚）が左脚。
  - 右向きの横：手前の脚が右脚。

## A. エイダン 上・下（逆足の3コマずつ、計6枚）

| `aidan_walk_down_05` | 右支持・左足蹴り出し | main `_02`／暫定版 `_05` |

## C. フィオナ 上（背面）：描き直しは任意（2枚）

縮小を揃えた候補4枚（`fiona/frames/fiona_walk_up_01..04`）は、独立QAで交互運びが PASS でした。
ただし02は待機画像と同じもので、04も両足が揃った中立の姿勢です。仕様どおり6コマにする場合は、すれ違いの2枚（左支持・右足通過、右支持・左足通過）を追加します。

## D. フィオナ 横・左右（12枚）：杖を持ち、逆足とすれ違いを描く

現行の横向き12枚には、杖がありません。また、手前の脚が6コマすべてで前に出ていて、足が交差するすれ違いのコマもありません。
左右は**反転で作らずに別々に描きます**（杖を持つ手は右手のまま）。
- 左向き：右手は奥側なので、杖は体の向こう側に見える。
- 右向き：右手は手前側なので、杖が体の手前に見える。

| ファイル（左右とも同じ構成） | 姿勢（左向きの場合：手前＝左脚） |
|---|---|
| `fiona_side_{left,right}_01` | 左足接地・右足後方 |
| `_02` | 左支持・右足が左足を追い越す途中（脚が交差する） |
| `_03` | 左支持後半・右足前方スイング |
| `_04` | 右足接地・左足後方 |
| `_05` | 右支持・左足通過（交差） |
| `_06` | 右支持後半・左足前方スイング |

- 体の中心（骨盤）を基準点 x=640 に置く。main の右向きにある148〜149pxの位置ずれは引き継がない。
- 参照：
  - 杖の形・持ち方：main の正面・背面・斜め（`fiona_idle_down`、`fiona_walk_left_02`）
  - 横顔・髪の流れ：main `fiona_side_left_01..06`
  - 参考資料 `reference/fiona-side-cue-swap/`（花と濃淡を入れ替えただけ。逆足としては数えない）

**ディレクター判断が必要：** 横向きのドレスは緑が主体ですが、正面・背面・斜めはクリーム地に葉の重ねです。どちらを正とするか決めてから描く必要があります。全方向の統一が条件なので、正面・背面を基準にする案を推奨します。

## E. フィオナ 斜め（3/4）：第2バッチ（12枚、採否はディレクター判断）

斜め移動用の `fiona_walk_{left,right}_01..04` も、通常プレイで使われています。
- 右斜め：4コマとも同じ足が前に出ている。
- 左斜め：03だけ顔の向きが違う。

残す場合は、上と同じ6コマの位相で各6枚を描きます。斜め移動に正面・背面の絵を流用する案は表示方向が変わるため、Codex とディレクターで別途判断してください。
