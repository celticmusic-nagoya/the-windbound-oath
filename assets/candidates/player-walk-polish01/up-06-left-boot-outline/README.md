## 2. 正式03由来の半透明画素（8px）の判定

- 拡大と黒・白の背景で確認した結果、新しい膝と裾の裏地の間に、**背景が点状に透けて見える明確な欠陥**でした（PR #152 の時点では、マスク内の隙間も含めて点在していた）。
- 対処（`tools/close_speckles.py`）：範囲 x1095〜1140・y955〜1012 で、不透明な部分を 3px 閉じた形の内側にある透けた画素を、周囲の色で埋めました。
  - マスク内：3px
  - **マスクの局所拡張：29px**（PR #152 の報告にあった 8px を含む）。座標は `close_speckles_info.json`、範囲は `mask_extension_px.png` に記録しています。
  - 拡張した画素は、正式03ではすべて、外套の縁にある透明度 26〜67 の画素と、その周りの透明な画素です。不透明な正式画素は変更していません。
- 結果：閉じた透明穴は、透明度200 の基準でも 24 の基準でも 0 です（`compare/semi_alpha_8px_zoom.png`）。
