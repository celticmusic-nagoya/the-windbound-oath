## 2. 原因

1. **画素の欠損ではありません。**
   - 6コマとも、脚の付近（y≥900）に、透明度が直線状に急に切れる箇所はありません（長さ20px 以上の縦横の切断を検査して0件）。
   - 閉じた穴・切り抜きの不良・描画位置のずれもありません。
2. **右足には「蹴り出し」の絵が1枚もありません。**
   - 左足は 01・02・04・05 の4コマで、靴底がカメラ側に見える大きな姿（手前で蹴り出す）が描かれています。
   - 右足は、6コマすべてで「接地」か「奥で小さく上がる」かのどちらかです。手前に大きく出て靴底が見える姿はありません。
   - 03・04 では、右足が奥へ小さく描かれ、左足に一部が隠れます。このため、右足の存在感が乏しく、パーツが足りないように見えます。これが指摘の主な原因と判断しました。
3. **再生順の位相の誤り。**
   - 06 で左足が奥へ振り出された直後、01 では左足が手前で蹴り出す姿に戻ります。左足が接地しないまま前から後ろへ戻る、逆向きの動きになっています。
   - 01・02・05 はほぼ同じ姿勢（右で支え、左を蹴り出す）が3回出てきます。また 05 は、上半身が01から約16px 横にずれています（02 は約9px）。
4. 斜め上の未使用素材（`aidan_walk_ul_*`）は、靴・脚の描き方が別のデザインなので、部品として使えません。

## 3. 改善候補（PNG の変更なし、並べ替えのみ）

**本番の上方向の bank を 03→04→01→06 の4コマにする**（下方向と同じ4コマ構成）。

| 順 | コマ | 位相 |
|---|---|---|
| 1 | 03 | 左で支え、右が通過 |
| 2 | 04 | 右が前で接地、左を蹴り出す |
| 3 | 01 | 右で支え、左が離れる（靴底） |
| 4 | 06 | 右で支え、左が前へ通過 → 1 で左が着地 |

効果：
- 左足が逆向きに戻る動き（06→01）がなくなります。06 で前へ出た左足が、03 で着地します。
- 同じ姿勢を3回繰り返すこともなくなります。
- 上半身の横ずれが小さいコマだけを使うので（−0.6、−0.3、0、+2.0px）、02・05 による揺れ（9〜16px）がなくなります。
- 右足は 03→04 で奥から前へ運ばれ、01・06 で支える足として見えるので、出番がはっきりします。

**残る限界**
- 右足の「蹴り出し」（左で着地し、右の靴底が手前に見える姿）は、どの正式素材にもありません。並べ替えでは作れません。
- 左右反転による代用は、これまでの方針で禁止されているので行っていません。
- この姿勢を足すには、部分的な描き直しが必要です。PR #132 の部分描き直しキットと同じ方法で、03 を土台にして右脚の範囲だけを描きます。
