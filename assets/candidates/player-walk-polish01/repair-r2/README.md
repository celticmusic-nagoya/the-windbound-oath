## 2. この環境で使える画像編集手段の調査

| 手段 | 有無 | 使い道 |
|---|---|---|
| Pillow / NumPy / SciPy / OpenCV / scikit-image / ImageMagick | あり | 切り抜き・変形・合成・マスク・計測・検査 |
| Chromium + Playwright | あり | 表示確認、連続再生の確認 |
| MediaPipe・onnxruntime | あり（生成モデルなし） | 姿勢の検出はできるが、絵は描けない |
| 画像生成・インペイント（部分描き直し）モデル（Stable Diffusion 等） | **なし** | 未導入。外部からモデルを取得する通信はこの環境では制限されている |
| 画像生成のコネクタ（Adobe Firefly、Canva など） | **未接続** | このセッションには道具がない |
| ペイントソフト（GIMP・Krita 等） | **なし** | — |

結論：この環境でできるのは「既存画素の切り貼り・変形」までです。隠れた部分の描き足しや、新しい角度の脚を描くことはできません。この結論はフィオナ（下・横の逆足、横向きの杖、すれ違いのコマ）にも当てはまります。

## 3. 代替案（ディレクター判断）

1. **部分描き直し方式（推奨）：** 描くのは脚の範囲だけに限り、それ以外は正式画素を機械的に戻します。
   - 描き直しの道具：ChatGPT の画像編集、Adobe Firefly の生成塗りつぶし、または人手
   - 正式 PNG とマスクを渡し、マスクの範囲だけを描き直してもらう
   - 戻ってきた画像を `tools/inpaint_kit.py merge` に通すと、マスクの外は正式画素に戻ります。顔・髪・胴体・剣・外套・キャンバス・基準点は変わりようがありません
   - その後、寸法・基準線・透過の検査、比較シートの作成、連続再生の確認、独立QAを Claude が行います
2. Adobe などの画像編集コネクタをこのセッションに接続し、Claude が部分描き直しを操作する。品質は試すまで分かりません。
3. 描き直しが揃うまで、本編は現状のまま（周期・素材とも変えない）。

## 4. 部分描き直し用のキット（`inpaint-kit/`）

エイダン上下の逆足6コマ分です。

| ファイル | 内容 |
|---|---|
| `<対象>_mask.png` | 2048×1280。白が描き直してよい範囲（両脚と、脚が移動しうる範囲、裾の余白） |
| `<対象>_mask_preview.png` | 正式画像の上に、描き直し範囲を赤紫で重ねたもの |
| `index.json` | 元にする正式 PNG・キャンバス・基準点 (1024,1230)・基準線 y=1229・マスクの範囲・必要な姿勢 |

| 対象 | 元にする正式 PNG | 姿勢 |
|---|---|---|
| `aidan_walk_down_04` | `aidan_walk_down_01` | 右足（画面左）前で接地・左足後方 |
| `aidan_walk_down_05` | `aidan_walk_down_02` | 右支持・左足蹴り出し |
| `aidan_walk_down_06` | `aidan_walk_down_06` | 右支持後半・左足通過 |
| `aidan_walk_up_04` | `aidan_walk_up_03` | 左足（画面左）前方接地・右足手前で支持 |
| `aidan_walk_up_05` | `aidan_walk_up_04` | 左支持・右足つま先離れ |
| `aidan_walk_up_06` | `aidan_walk_up_06` | 左支持後半・右足通過 |

描き直した画像を受け取ったときの取り込み：

```
python3 assets/candidates/player-walk-polish01/repair-r2/tools/inpaint_kit.py merge aidan_walk_down_04 描き直し.png 出力.png
```

`merge` が自動で確認すること：
- キャンバス寸法が同じか（違えば NG）
- マスクの外が正式画素と完全に同じか
- 足元が基準線上にあるか
- マスク内に不透明な白背景が焼き込まれていないか

自己テスト：正式 PNG をそのまま `merge` に通し、マスクの外が同一・基準線上・白背景0 になることを確認済みです。

腕の振りは、マスクに含めていません。脚と逆の位相にすべきですが、マスクの外は正式画素に戻るためです。正面・背面では腕の振りが小さいので、変える場合は腕を含めたマスクを追加します（判断待ち）。
