## 2. 作れない理由

1. **提供元の脚の片側が描かれていない。** 04 の左足は、右足に一部が隠れています。境目で切り抜くと、隠れていた側が直線で欠けます。存在しない画素は補えません（PR #132・#133 と同じ原因）。
2. **脚の傾きが合わない。** 04 の左足は、腰から靴へ向かって体の内側（画面右下）へ傾いています。これを右の腰に平行移動すると、右足も体の中心へ向かって傾きます。外側へ蹴り出す右足としては、解剖学的に逆向きです。
3. **左右の靴の違い。** 平行移動では、左足用の靴の形と装飾がそのまま右足に付きます。反転すれば合いますが、反転は禁止されています。
