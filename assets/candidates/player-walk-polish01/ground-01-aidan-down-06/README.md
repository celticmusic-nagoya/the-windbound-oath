## 方法

画面左の支持足（解剖学上の右足）だけを、縦方向の局所ワープで下げました。

| 範囲（y） | 移動量 | 内容 |
|---|---|---|
| ≤1060 | 0px | 膝当て・すね上部はそのまま。継ぎ目なし |
| 1060〜1170 | 0→7px（smoothstep で滑らかに増やす） | すね下部を 110行で7px（6.4%）伸ばす |
| ≥1170 | 7px 一定 | 足首・靴の装飾・靴底は**伸縮せず**、そのまま平行移動 |

- 支持足と、浮いている反対の足（解剖学上の左足）との境目は、2本の脚の隙間を通る最小コストの経路で決めています（x=1100〜1126）。
- 反対の足、外套、腰、胴体、頭はすべて正式06のままです。
- 塗り足し・反転・拡大縮小はしていません。縦方向の補間は、半透明の縁がにじまないよう、色に透明度を掛けた値で行っています。
