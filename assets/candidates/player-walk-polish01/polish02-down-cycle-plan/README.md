## 1. 正式 01〜06 の脚の計測

計測方法：各列で最下端の不透明画素の位置を取り、x=980〜1220 を10px ごとに調べました。基準線は y=1229 です。
- 「浮き」は、基準線から靴の最下端までの距離（px）です。
- 「腰」は、上半身と腰の帯（y600〜880）を位相相関で比べた横位置で、正式04を基準に、画面左方向を負にしています。

| コマ | 画面左の足（解剖学上の右足） | 画面右の足（解剖学上の左足） | 腰 | 読み取れる位相 |
|---|---|---|---:|---|
| 01 | 浮き 約57、後方 | **接地**（手前で大きい） | −2 | 左足接地・右足後方 |
| 02 | **接地**：靴底がカメラ側を向き、低く大きい | 浮き 約16〜23（つま先で蹴り出す直前） | **−13** | **右足の踵接地**（下記の注を参照） |
| 03 | 浮き 約94（最も高い） | 接地 | −4 | 左支持・右足通過 |
| 04 | 浮き 約41（最も低い） | 接地 | 0 | 左支持後半・右足が前へ下りる |
| 05 | 浮き 約70 | 接地 | −5 | 左支持・右足通過（03より低い） |
| 06 | **接地**（最下端 1217〜1223、基準線より6〜12px 上） | 浮き 約77 | **−8** | 右足で支持・左足通過 |
| 04 R2 | 06 と同じ脚（+8px） | 06 と同じ脚 | 0 | 右足支持・左足通過（06と同じ姿勢） |

**注（02）：** 正面から見て靴底が見えるのは、足が手前にあってつま先が上がっているとき（踵接地）です。後方で蹴り出した足の靴底は、カメラの反対を向きます。02の靴は低く大きい（手前にある）ので、**右足の踵接地**と判定しました。ただし静止画からの推定なので、断定はできません。

**腰の横移動：** 右足が接地している02・06だけ腰が画面左（支持足の側）へ8〜13px 寄っており、左足接地の01・03・04・05は −5〜0 です。体重が支持足の上に乗るという点で、正式素材の描写は一貫しています。

## 2. 問題点

1. **今の並び（01→06）の位相：** 左・右踵・左・左・左・右の順で、右足の位相が02と06に離れて置かれています。正式素材の時点で、すでに歩行周期になっていません。
2. **04 R2 と 06 の重複：** 04 R2 の脚は正式06の脚を8px ずらしたもので、姿勢が同じです。並びに両方を入れると、同じ姿勢が2回出ます（`compare/current_with_04R2_*`）。
3. **06 の接地の高さ：** 06 の支持足は基準線より6〜12px 上にあります（ゲーム表示で約0.4〜0.75 CSS px）。04 R2 も同じです。
4. **素材の偏り：** 右足を振る位相は5種類描かれています（後方57・踵接地・通過94・前方41・通過70）。一方、左足を振る位相は06の1種類（通過77）しかありません。**「右支持後半・左足が前へ下りる」姿勢はどの正式素材にもありません。**

## 3. 05・06 の素材調査

| 必要な姿勢 | 正式素材で使えるもの | 結論 |
|---|---|---|
| 右支持・左足通過（指示書の05） | 正式06（右接地・左足 浮き77）。左支持の通過コマ（05＝浮き70、03＝浮き94）と同じ描き方 | **既存素材で成立**。06（または 04 R2）をこの位相に割り当てればよい |
| 右支持後半・左足が前へ下りる（指示書の06） | なし。左足を前方に描いた正式素材は01の「接地」だけ | **新規描画が必要**。下記の試作で確認 |
| 右足接地 | 正式02（踵接地）と正式06／04 R2（足裏全体で接地） | 既存素材で成立 |

**試作（`probe/`、候補ではありません）：** 正式06から左脚を外し、正式01の左脚（手前）を18px 持ち上げて入れました（反転なし）。結果は不合格です（`compare/planB_6frame_reorder_plus_new_legs_strip.png` の右端）。
- 01の脚は体の中心線寄りに描かれているため、06の腰に付けると支持脚と重なる
- 膝の上で輪郭がずれる
- 足の通り道を右へ約40px 移すには、腿の向きを変えて描き直す必要がある

この姿勢は、画素の組み替えでは作れないと判断しました。

## 4. 制作計画（案）

### 案A：4コマ周期（正式素材だけで成立。新規描画なし）【推奨】

| コマ | 正式PNG | 位相 |
|---|---|---|
| 1 | 01 | 左足接地・右足後方 |
| 2 | 05 | 左支持・右足通過（浮き70） |
| 3 | 02 | 右足踵接地・左足蹴り出し |
| 4 | 06 | 右支持・左足通過（浮き77） |

- 接地と通過が左右で対称に並び、腰の横移動も 左→左→右→右 で一致します。
- 外套の差は、隣り合うコマ同士の平均で今の並びと同程度です。外套は1コマごとに描き直されているため、並べ替えてもちらつきは増えません。
- 確認資料：`compare/planA_4frame_official_only_*`（4倍とゲーム表示の1倍のGIF、脚の並び）
- **Codex の作業：** 下方向の bank を4コマ（01・05・02・06）にする登録変更。距離方式の周期は、1歩の長さを保つなら90→60前後が目安です（4コマで2歩）。周期の値はディレクター判断です。PNG の変更は不要です。
- 04 R2 は使いません。06 との重複が自動的に解消します。
- 06 の支持足が基準線より最大12px 浮いている点は残ります。必要なら Codex が bank の登録で y 方向を補正します（PNG は変えない）。

### 案B：6コマ周期（並べ替え＋新規1コマ）

| コマ | 素材 | 位相 |
|---|---|---|
| 1 | 正式01 | 左足接地 |
| 2 | 正式03 | 左支持・右足通過（浮き94） |
| 3 | 正式04 | 左支持後半・右足が前へ（浮き41） |
| 4 | 正式02 | 右足踵接地 |
| 5 | 正式06 または 04 R2 | 右支持・左足通過 |
| 6 | **新規** | 右支持後半・左足が前へ下りる |

- 新規1コマの制作範囲は、脚の部分だけです。正式06を土台にして、左脚（画面右）を浮き40前後・やや手前に描きます。
- 描き直しには PR #132 の部分描き直しキットを使います（この目的用のマスクの追加が必要）。合成には PR #133 の最小差の境界合成（`seam_stitch.py`）を使えば、マスクの外は正式画素のまま保てます。
- 枠5に 04 R2 を使えば、胴体と裾が正式04と同じになります。正式06を使う場合は、04 R2 は不要です。
- 左右の非対称が残ります。右足の位相は3種類（通過94・前方41・踵）を使い、左足は2種類（通過77・新規）だけです。
