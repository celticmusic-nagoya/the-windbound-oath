## 2. 制作方法（`build_morwen74a.py`）
1. 72の基準画像（65B F00、右向きの座標）で、手前に描かれている右側の装備（鞄・紋章・花・リボン）を取り除き、ベルトを描き直す（参照画像の編集画素は`REFERENCE_EDIT_MASK_right_coords.png`）。
2. 取り除いた跡は、同じ部位の近くの画素から5×5の模様を写して埋める。帽子・後頭部・ケープ・胴・マントのそれぞれで写し元を限定し、新しい色は作らない。体の輪郭の外は透明にする。腰の無地プリーツは67の裾の生成で描く。
3. この基準で、72の生成処理（`build_morwen71.py`のGLASSES、動きの表・パレットは72と同一）を変更せずに実行する。
4. 左右反転する。歩行・接地・脚の前後・光の向き（正面側）は72と同じ。
