## 4. ゲームへの組み込み（DEV専用・本番は切り替えていない）
- 追加したもの:
  - `js/field/morwen-walk4-dev.js`
  - `index.html`のscriptタグ1行
- 有効になる条件: `WINDBOUND_DEV===true`で、かつURLに`?morwenWalk4=1`があるときだけ。条件を満たさないと何も作らない。
- コマの進め方:

| 項目 | 動作 |
|---|---|
| 通常移動 | 移動距離に連動。stride 180、300px/sで毎秒20コマ。移動速度は変えていない |
| イベント移動 | 時間に連動。840msで1周期（`?morwenMode=event`または`MorwenWalk4Dev.setMode('event')`） |
| 方向転換 | 脚の位相を引き継ぐ |
| 停止 | 次の接地コマ（F00かF06）まで1コマずつ進めて止まる |
| 再開 | 止まったコマから続ける |

- 下方向の移動中は、正面素材がないため直前の左右の向きを保つ（暫定）。
- 主人公・味方・NPC・魔物の移動設定と`FieldMovement`は変更していない（差分0）。
- 自動テスト:
  - `tests/moss/morwen_walk4dir.js`: 27/27 PASS。60・120・144Hzで毎秒20コマ、コマ飛びなし。840ms周期。転換・停止・再開。DEVゲート。保存データに触れないこと。
  - `tests/moss/morwen_walk4dir_e2e.py`（ヘッドレスChrome）: PASS。フラグOFFでは、グローバル変数・森のDOM・localStorageのキー・コンソールエラーがmainと一致。フラグONでは、右・上・左・下の移動で12コマ全部が表示され、接地コマで停止し、localStorageは変わらない。
  - 既存の`tests/moss/*.js`: 18本すべてPASS。

## 6. Android実機QAの手順（マージ前でも実施可能）
1. このPRのブランチをGitHub Pagesのプレビューで開くか、ローカルサーバーを立てて`index.html?morwenWalk4=1`を開く（DEVが有効なビルドで）。
2. DEVメニューから「モンスターアリーナ」か「苔の森」へジャンプする。
3. タップで右・左・上・下へ移動する。確認すること:
   - 向き（下は左右の向きのまま）
   - 12コマが止まらずに流れること
   - 停止するとF00かF06で止まること
   - 足元がほかのキャラクターと同じ高さにあること
4. 草原・苔の森・洞窟・夜のマップで見え方を確認する（`BACKGROUNDS_4DIR.png`は暗い背景を模擬したもの）。
