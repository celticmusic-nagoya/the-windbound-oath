# MORWEN-WALK-4DIR-ART-FIX-02 上向き76B（HDドット絵の描き直し候補）

旧76は比較用にそのまま残している（上書きしていない）。

## 作り方（イラストを縮小したものではない）
`hdpix.py`と`hd_walk.py`で作っている。
1. **部位の判定**: 公式背面画の各画素を、色と位置から部位に分ける。部位は紫の布、明るい紫（リボン・裏地）、金、肌、白、革、髪の7つ。
2. **配置の合わせ込み**: スプライトの1画素ごとに、元画のどの範囲が当たるかを決め、そこで多い部位を採用する。金は範囲の27%以上（48pxでは35%）あれば金にするので、縁取りが1pxの線として残る。帽子は2〜52行・横0.135倍、ケープは52〜113行。側面と同じ配置（帽子の幅は約60px、首は約52行、足元は124行）になる。
3. **塗り**: 色は左74G・右75の画素から部位ごとに取った3〜4段階の色だけを使う。陰影は段階に分け、3×3の多数決でならして1pxのちらつきを消す。部位の境界の小さな点も、同じ多数決で整理する。ただし金の線はならしの対象から外す。
4. **線**: 外側に1pxの暗い輪郭を付ける。部位の境目には内側の線を入れる（96pxのみ）。側面と同じ線の太さ。
5. **歩行**: 76と同じ12コマの動き。奥行き3px・脚上げ5px、骨盤と肩の逆の動き、ケープ外側の傾き、リボンと裾の遅れ、首の隙間埋め、離れた部品を鎖でつなぐ処理を含む。48pxは同じ手順を48pxの格子で直接描いている（96pxを縮めていない）。

| 指標 | 74G左 | 76（旧） | 76B |
|---|---|---|---|
| 色数（96） | 2467 | 157 | 29 |
| 1px孤立点 96／48 | 4.33／0.67 | 1.5／0.0 | 9.08／2.0 |
| 金のちらつき（CV）96／48 | .0178／.0331 | .0088／.0081 | .0081／.0000 |

色数が少ないのは、決めた段階の色だけで塗っているため。2,000色以上ある側面のような細かいグラデーションはない。この差が問題になるかは美術QAで判断する。
