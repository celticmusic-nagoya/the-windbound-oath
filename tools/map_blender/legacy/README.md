# Historical pixel-layout assembler

`lind_spatial_assemble_v1.py` preserves the superseded implementation byte-for-byte
(SHA-256 `54e3f49d92b62965517f5d9822a76244086561a098499823b6d536343241506e`).
It is retained for provenance and historical reproduction, not current world authoring.
Use the guarded parent entrypoint with `--legacy-layout` if reproduction is required.

New Lind geography must not inherit `units_per_world_px`, the old image hash, old
DOM coordinates or old placements. A new metric contract and director spatial
approval remain prerequisites; no new coordinates or scene assembler are approved here.
