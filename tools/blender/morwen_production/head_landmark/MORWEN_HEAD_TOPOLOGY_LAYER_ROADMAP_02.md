# MORWEN-HEAD-LANDMARK-02 補遺 — 顔トポロジー設計・レイヤー構造・制作ロードマップ

状態：**制作設計の提案**。美術最終設計・正式採用はChatGPT側の美術QAとディレクター判断に委ねる。数値はすべて提案値であり、PASS基準ではない。

## 0. 前提となる実測値

単位Uは「目線（瞳中心の高さ）から顎先まで」の距離。現行のVRoid頭部では U = 91.5 mm。正本はLayer 0四面図（SHA照合済み）。正本の正面・右・左でUのばらつきは1.65%。

| 比率（÷U） | 正本 | 現行VRoid | 現行モデル寸法で換算した正本値 |
|---|---:|---:|---:|
| 瞳間距離 | 0.99 | 0.91 | 90.7 mm |
| 目の幅（白目＋虹彩の可視範囲） | 0.43 | 0.40 | 39 mm |
| 目の高さ | 0.18–0.23（左右差あり） | 0.27 | 16–21 mm |
| 両目頭の間隔 | 0.58 | 0.58 | 53 mm |
| 口幅（推定） | 0.31 | 0.27 | 28 mm |
| 目線→口 | 0.62 | 0.65 | 57 mm |
| 口→顎先 | 0.39 | 0.35 | 36 mm |
| 鼻先の高さ（目線より下・側面） | 0.23 | 0.38 | 21 mm |
| 鼻先の前方突出（瞳より前・側面） | 0.49–0.53 | 0.38 | 45–48 mm（※） |
| 顎の前方突出（側面） | 0.14–0.16 | 0.07 | 13–15 mm |
| 耳中心の位置（瞳より後ろ） | 1.04–1.09 | 1.12 | 95–100 mm |

※ RBF候補で、側面図の鼻に合わせると鼻先が棘状に尖った（失敗1/2回）。2Dの側面図は鼻を誇張して描く傾向があるため、**鼻の前方突出量は3D目標PNGの3/4ビューを含めて美術側が決める**。上の値は上限の参考とする。

## パターン1：顔のトポロジー（エッジループ）設計

### 1-1 全体構造
- 顔は「前面のお面状ループ（額→こめかみ→頬→顎）」と「後頭部シェル」に分ける。VRoidと同じ分け方で、首側の境界は首リングの頂点に**位置を一致させる**（現行は境界38頂点が0.1 mm以内で一致）。
- ポール（5辺以上が集まる頂点）は動かない場所に置く：こめかみ、頬骨の外側、顎の下面。目・口の周り、鼻筋には置かない。
- 正面と側面のシルエットに沿うループを、少なくとも1本ずつ通す。正面は頬〜顎の輪郭（目線から0.25U・0.5U・0.75U下）、側面は正中線。

### 1-2 目の周り
- 目の開口を囲む同心円ループを**3重**にする。①まぶたの縁、②まぶたの面、③眼窩への移行。縁のループは**16辺**（ゲーム用）〜**24辺**（高解像度レンダー用）。
- 上まぶたは、横方向の行を**最低3本**持たせる。まばたき・ウインク（Blink、Blink_L/R）で閉じたとき、まぶたの線が下に凸の弧になるようにするため。閉じた線の位置は、開口の高さの下から約40%を提案値とする。
- 目頭にはつまむための頂点を1つ置く。目尻はまつ毛の跳ね上げ方向（やや上向き）に1本延長し、アイラインの板と頂点を揃える。
- 下まぶたのループは頬のループへそのまま連続させる。笑顔（Joy）で頬が持ち上がったとき、下まぶたを押し上げられるようにするため。
- 瞳・白目・ハイライトは別パーツ（パターン2参照）。目の形は主にテクスチャで決めるので、**目の板ポリゴンを変形でゆがめない**（今回の方針。目の幅・高さの差は目パーツを作り直して合わせる）。

### 1-3 口の周り
- 唇の合わせ目（閉じた線）を囲む同心円ループを**4重**にする。①合わせ目、②唇の縁、③唇の外周、④口輪筋の外周で、④は小鼻の横へ流す。
- 合わせ目のループは**12〜16辺**。口角には縦方向のエッジを2本追加する。A・I・U・E・O、笑顔、驚き（正本の表情例：口を開けた顔）で口角の角が潰れないようにするため。
- 口内（歯・舌・口腔）は顔と同じオブジェクトの別マテリアルにする。シェイプキーを同期させるため（VRoidと同じ方式）。
- 正本の口は小さい（0.31U、推定）。口幅を変えても口角ループの辺数は変えない。

### 1-4 鼻筋
- アニメ調でも、側面のシルエットを支えるには、**鼻筋に沿った縦の行を最低3本**（鼻根・中間・鼻先手前）と、**鼻先を囲む小さなリング（6〜8辺）**が必要。現行VRoidは鼻先付近の頂点が少なく、ランドマーク変形が1点に集中して棘状になった。これが今回の実測で得た根拠である。
- 小鼻はモデリングしないか、ごく浅いふくらみにとどめる（正面の正本でも、鼻は陰影だけで描かれている）。
- 鼻根は目のループ③とつなげ、目と目の間に余計なループを足さない。メガネのノーズパッドが乗る位置なので、ここは**平らな面**にしておく。

### 1-5 輪郭（頬・顎・こめかみ）
- 顎先には、正中線上に辺を1本通す（V字の顎先を立てるため）。ポールは顎の下面に逃がす。
- 下顎の輪郭ループは、顎先から耳たぶの下へ1本流す。正本は正面で尖ったV顎、側面で顎が前に出ている（0.14–0.16U）ので、ここが側面シルエットの支えになる。
- 頬は、頬骨の高さ（目線から0.25U下）に横方向のループを1本通す。正本ではここが髪に隠れて「隠れている可能性あり」と判定されたので、形状の決定は3D目標PNGを優先する。
- こめかみは前髪と横髪に隠れて計測できない。密度は低くてよい。

### 1-6 ベースメッシュの推奨頂点数（提案。最終的な表示サイズは未決定）

| 部位 | 頂点数（四角面主体） |
|---|---:|
| 目の周り（左右合計、ループ①〜③と移行部） | 260–320 |
| 口の周り（ループ①〜④と口角の補強） | 140–180 |
| 鼻（鼻筋の3行と鼻先リング） | 40–60 |
| 頬・顎・輪郭 | 260–340 |

### 1-7 シェイプキー（表情）
- 現行VRoidの56キー（名前は`target_0…55`）は、名前と役割の対応表を作ってから引き継ぐ。名前が汎用なので、そのまま使うのは避ける。
- 最小セット：Blink、Blink_L、Blink_R、A、I、U、E、O、Joy、Angry、Sorrow、Fun、LookUp/Down/Left/Right。正本の表情例（通常・微笑・目を閉じた笑顔・驚き）を、必須の検証ポーズとする。
- **メガネとの干渉を必ず確認するキー**：Joy（頬が上がる）、Blink（まぶたが前に出る）、ウインク（片側の頬が上がる）。

## パターン2：メガネ・前髪・顔の干渉とレイヤー構造

### 2-1 オブジェクトの分割

| オブジェクト | 内容 | 理由 |
|---|---|---|
| 頭部の肌（Face） | 顔の肌、口内、**まつ毛・アイライン・眉の板**（別マテリアル） | まばたきのシェイプキーと同期させる。分けると、全キーを転写して維持する必要が出る |
| 目（Eyes） | 白目・虹彩・ハイライト（左右） | 正本の紫の瞳への差し替えと、視線ボーンでの制御。形状は変形でゆがめない |
| メガネ（Glasses） | フレーム、レンズ、ノーズパッド、つる | 変形しない剛体。`J_Bip_C_Head`に重み1.0で親子付け |
| 前髪（Hair_Bangs） | 前髪の房 | 揺れ物ボーン（スプリングボーン）と衝突判定を、メガネ・顔と個別に設定する |
| 横髪（Hair_Side_R / Hair_Side_L） | 左右別のオブジェクト | **正本の髪は左右非対称（G1で保護）**。ミラーモディファイアは使わない |
| 後ろ髪・内側シェル（Hair_Back / Hair_Cap） | ボブの外形と、頭皮を隠す内側シェル | VRoidのHairBackは作り直し（REBUILD） |
| 帽子（Hat） | つば・とんがり・リボン・花・宝石 | 揺れ物ボーンを持つ別リグ。被ったときに髪が潰れる形状差分は、髪側に持たせる |

### 2-2 前後関係（顔から外側へ）と隙間の提案値
肌 → 目パーツ → まつ毛・アイライン → **レンズの裏面** → フレーム → 前髪 → 帽子のつば

| 隣り合う層 | 最小の隙間（提案） | 確認するポーズ |
|---|---|---|
| 目パーツの最前面 ↔ レンズの裏面 | 4–6 mm（0.05–0.07U） | Joy、Blink、ウインク |
| まつ毛の板の先端 ↔ レンズの裏面 | 2 mm 以上 | 目を見開いたポーズ（Surprised） |
| ノーズパッド ↔ 鼻筋 | 0–0.5 mm（接触） | 全キー（鼻筋は表情で動かさない） |
| つる ↔ こめかみ・耳の上 | 1–2 mm | 頭部ボーンの回転 |
| 前髪 ↔ フレーム上辺 | 2–3 mm | 前髪の揺れ（衝突判定で保証） |
| 前髪 ↔ 額の肌 | 2–4 mm | 静止時。正本では前髪が目元にかかる |
| 帽子の内側 ↔ 髪の頂点 | 1–3 mm | 正本の髪の頂点位置（実測済み）を基準にする |

- 前髪がメガネや目より手前に来るのは正本どおり。眉やまつ毛を前髪越しに透かして見せる表現（アニメでよくある手法）は、**描画エンジンが未決定**なので、描画順序とステンシルの方針はディレクター判断の項目とする。
- スプリングボーンの衝突判定は、頭部（球2つ）、メガネ（カプセル1つ）、首（カプセル）に置く。前髪の衝突半径は、フレームまでの隙間より小さくする。

### 2-3 リグとシェイプキー
- 既存のVRoid骨格（`J_Bip_C_Head`と`J_Bip_C_Neck`）を再利用する。メガネ・帽子は頭部ボーンに追従させる。
- メガネ側にシェイプキーは持たせない。干渉は顔側のキーの可動量で解決する（レンズを動かすと、正本の見た目が表情ごとに変わってしまうため）。
- 検証は自動化する。全シェイプキーと主要ボーンポーズについて、各層の最短距離をBVHで計測し、隙間の提案値を下回った箇所を一覧にする（次の作業で実装を提案）。

## パターン3：制作ロードマップ（チェックリスト）

今回の実測に基づく推奨は、**ゼロから作り直すよりハイブリッドを優先する**こと。頭蓋・リグ・首の接続はVRoidを再利用し、顔の前面（鼻・目・口）を局所的にリトポロジーし、目・髪・メガネ・帽子は独立パーツとして作る。ゼロから作る場合も、下の工程0〜2とQAは同じ。

**工程0 準備**
- [ ] Layer 0四面図と3D目標PNGのSHA照合（v5.61正本はGitHub未登録のためBLOCKED。登録されたら照合を追加）
- [ ] 正射影カメラ4台を、`compare_head_landmarks.py`と同じ較正（px/m、目線・瞳アンカー）で配置する
- [ ] `HEAD_LANDMARKS_3D.json`と`CANONICAL_LANDMARKS_2D.json`のランドマークを、Emptyとしてシーンに読み込む（実測と推定を色で分ける）

**工程1 大まかな形出し（球・立方体から始める場合）**
- [ ] 頭の高さ・幅を正本の髪シルエットではなく頭蓋で決める（頭蓋は髪に隠れて計測不能なので、VRoidの頭蓋を参照する）
- [ ] 目線・顎先・耳の位置をUの比率で合わせる（上の表）
- [ ] 正面と側面のシルエットの差を、比較シートで確認する。この段階では数値の微調整をしない

**工程2 主要な形（顎・鼻・額）**
- [ ] 側面の正中線（顎の突出0.14–0.16U）と、正面のV顎を合わせる
- [ ] 鼻の突出量を美術側に確認してから作る（2D側面図の誇張問題）
- [ ] 4方向の比較シートを生成し、差分をJSONに記録する

**工程3 トポロジー**
- [ ] パターン1のループ（目3重、口4重、鼻筋3行と鼻先リング、輪郭）を作る
- [ ] ポールの位置を確認する（目・口・鼻筋にないこと）
- [ ] 首リングの頂点をBody側と一致させる（隙間0.1 mm以下）
- [ ] 反転面0、非多様体0、重複面0

**工程4 目・口・眉の板**
- [ ] 目パーツを正本の目の幅0.43U・高さに合わせて作り直し、紫の虹彩テクスチャを入れる
- [ ] アルファの配線を作り直す（現行VRoidの材質はアルファが未接続）
- [ ] まつ毛・アイライン・眉の板の頂点を、まぶたのループに揃える

**工程5 UVとテクスチャ**
- [ ] 顔のUVでは、目・口の周りのテクセル密度を上げる。シームは髪の下と顎の下に置く

**工程6 シェイプキー**
- [ ] 最小セットを作る。正本の表情例4種を検証ポーズにする
- [ ] まぶたを閉じた線の形と、ウインクで頬が上がる量を確認する

**工程7 独立パーツ（今回のタスクでは接続位置の計測のみ）**
- [ ] メガネ → 前髪・横髪・後ろ髪（左右非対称） → 帽子の順に作る
- [ ] パターン2の隙間を、全キー・全ポーズで自動計測する

**工程8 リグとウェイト**
- [ ] 頭部・首はVRoid骨格を継承する。髪・帽子のスプリングボーンと衝突判定を設定する

**工程9 QA**
- [ ] G1：正本SHAの照合、非対称性をミラーしていないこと
- [ ] G2：美術QA（ChatGPT側とディレクター）。技術PASSを美術PASSとして扱わない
- [ ] G3：CIで再現できること（固定したbpy環境）
- [ ] G4：ゲーム内QA（現時点では未実施）

**全工程に共通**
- 同じ欠陥に同じ手法で2回失敗したら手法を変える。試行のたびに台帳へ記録する。
- 判断が必要な事項は推測で決めない：鼻の突出量、描画エンジンと描画順序、表示サイズと頂点予算。
