# MORWEN-HEAD-STRUCTURE-01 — 頭部構造診断レポート

- 対象: VRoid CC0 `Base_Female.vrm`（ZIP SHA-256 `bf2717cf…68eb3` / VRM SHA-256 `1995f174…8149b`）
- 基点: `feature/morwen-production-pipeline-01` @ `165a6c6` → 作業ブランチ `feature/morwen-head-structure-01`
- 証跡: `_qa/head_structure_01/`（ローカル bpy 5.3.0 で実行した結果）。
- CI再現: GitHub Actions [#43457599069](https://github.com/celticmusic-nagoya/the-windbound-oath/actions/runs/43457599069) SUCCESS @ `083d6e4`（apt Blender 5.0.1、Cycles CPU）。成果物 `morwen-head-structure-01`（ID 14054612570、digest `sha256:b0b28993…0c5173`）。ローカルと同じ数値（78.81%、境界38/38一致、溶接後の成分数 18/17）を確認し、画像も目視で同等であることを確認した。
- 先行CI失敗: #43457328177（`python3-numpy`不足のためglTFインポートが失敗。修正済みで、台帳に記録）。
- 元データは変更していない。計測はすべてメモリ上のコピーで行い、実行前後でVRMのSHAが一致することをスクリプト内で検証している。

## 1. 結論（要約）

1. **黒い描画異常の原因はレンダリングである。メッシュ・法線・材質の欠陥ではない。** 旧 `render_neutral_skin_head.py` では、+Y を向く顔に対して唯一のAREAライトが背後 (+X, −Y, +Z) にあり、補助光もワールド光（工場出荷時グレー 0.05）しかなかった。そのため顔の正面側が影になって黒く写った。加えて `from_pydata` による再構築でカスタム分割法線が失われ、フラットシェーディングになっていたため、面ごとの明暗の段差が増幅されていた。同じ断片・同じシェーディングで照明だけを変えたA/B比較（`SHEET_legacy588_oldlight.png` と `SHEET_legacy588_relit.png`）で、黒色が消えることを確認した。
2. **側面・背面の欠損は抽出方法の構造的な誤りである。** 588頂点の島は、UVシームで分割された顔肌の**断片**にすぎない（顔肌1350面のうち1064面、78.81%）。VRoidの頭部は「Faceメッシュ＝顔のお面」と「Bodyメッシュ＝後頭部・首の肌＋HairBackキャップ」に分かれている。Faceの開放境界にある38頂点は、すべてBodyの頂点と0.1mm以内で一致しており（最大1µm）、穴はない。
3. **完全な頭部は既に存在する。** Face全体＋Bodyの頭部肌を合わせると閉じた頭部になり、4方向とも欠損はない（`SHEET_clay.png`）。

## 3. 連結成分（Connected Components）

|---|---:|---:|---:|

旧来の成分数は、glTFインポートでUV/法線シームごとに頂点が複製された結果、水増しされていた。MESH_QA_02の「Face 34成分・Body 179成分」は、解剖学的な部品数ではない。

- Faceの残り17成分は、左右対称の重ね板（虹彩、ハイライト、まつ毛、アイライン、眉、EyeExtra）と口パーツ。
- Bodyの主成分：3949頂点。肌7412面とHairBack 394面が一体。Tops（1035頂点）は閉じたメッシュ。ネクタイ（98頂点）に非多様体エッジが1本あるが、頭部外のため本タスクの対象外。

## 4. 法線・重複・境界

| 項目 | Face | Body |
|---|---:|---:|
| 巻き方向の矛盾エッジ（反転面） | 0 | 0 |
| 重複面 | 0 | 0 |
| 縮退面 | 0 | 0 |
| 非多様体エッジ（3面以上） | 0 | 1（ネクタイ） |
| カスタム分割法線 | あり | あり |

頭部中心から外向きの割合：Face肌は1350面中1276面、Body肌（頭部）は372面中366面、HairBackは394面中394面。外向きでない面は眼窩や鼻孔などの凹部にあり、反転ではない。法線パスでは肌に赤（裏面）は出ていない。赤が出るのは、横から見たまつ毛・アイラインの片面板の裏側だけで、これは仕様どおりの挙動である。

## 5. 材質・シェーダー

- 全材質がglTFの**unlit**としてインポートされている（Emission＋Light Path＋Transparent）。
- 材質設定上のブレンドは BLEND（眉、まつ毛、アイライン、ハイライト、EyeExtra、HairBack）と HASHED（肌、白目、虹彩、口、服）。ただし**画像のアルファはどの材質でも未接続**（`alpha_linked: false`）。
- 背面カリングあり：肌、白目、虹彩、口、EyeExtra、HairBack。なし：眉、まつ毛、アイライン、ハイライト、服。
- 元材質のレンダー（`SHEET_original.png`）に黒色異常はない。アルファ未接続は、ライティングを伴う再シェーディングや別エンジンへ移す際の**潜在的リスク**として記録する（今回の黒色の原因ではない）。

## 6. スキニング・Shape Keys

- Faceの全2054頂点がウェイト済み（影響ボーン1本、主に`J_Bip_C_Head`へ1810頂点）。Bodyもウェイトのない頂点は0。
- Shape Keys：Faceに56個（名前は`target_0…55`の汎用名、最大変位72.7mm）。**全キーの値は0**。レンダーと計測はレストポーズ・基本形状で行っており、表情キーの影響はない。

## 7. 黒色異常の原因分類

| 分類 | 判定 | 根拠 |
|---|---|---|
| レンダリング | **主因（確認済み）** | 背後からの単灯と補助光不足。A/Bで照明だけを変えると解消 |
| 構造（抽出方法） | **副因（確認済み）** | 断片抽出によるフラットシェーディング化と、顔肌の21%欠落 |
| 法線 | 原因ではない | 巻き方向の矛盾0、法線パスで肌に裏面なし |
| 材質 | 原因ではない（潜在リスクあり） | 診断材質でも元材質でも黒色なし。アルファ未接続は別件として記録 |

## 8. 部位別の判定（REUSE / REBUILD / BLOCKED）

| 部位 | 判定 | 理由 |
|---|---|---|
| 頭蓋・後頭部（Bodyの頭部肌） | **REUSE**（構造） | 閉じた形状、法線正常、Faceと境界で一致 |
| 顔のお面の形状・トポロジー（Face肌＋口内） | **REUSE**（構造） | 欠陥なし、56個の表情キーとウェイトがある。**正式デザインへの似せ方の採否はChatGPT側の美術QAとディレクター確認に委ねる** |
| 目・眉・まつ毛・アイラインの重ね板 | **REUSE**（形状）／材質はREBUILD | 形状は健全。正式のvioletの瞳に合わせたテクスチャ差し替えと、アルファ配線の作り直しが必要 |
| HairBackキャップ（頭皮に貼り付いたテクスチャ髪） | **REBUILD** | 正式の層状ボブ・前髪・サイドの房は体積のある髪形状を必要とし、頭皮キャップでは表現できない |
| 首より下の体型 | **BLOCKED** | 本タスクの範囲外で、プロポーション計測も行っていない |
| 旧手法（588頂点の断片抽出＋背後単灯） | **廃止** | 失敗1/2回として台帳に記録。同じ手法では再試行しない |

総合評価：**頭部ベースは構造上REUSE可能**。髪はREBUILDが必要。顔の似せ込み（目・鼻・あごのランドマーク）の判断は美術QAに委ねる。

## 9. 診断レンダリング

すべて同一の正射影カメラで撮影した（`ortho_scale` 0.40m、距離2.0m、中心は`J_Bip_C_Head`の位置＋Z方向0.10m）。中心には十字マークを描画している。

- `SHEET_parts.png` — 溶接後の連結成分ごとの色分け
- `SHEET_material.png` — 材質ごとの色分け（凡例は`HEAD_DIAGNOSTIC_RENDER_QA.json`）
- `SHEET_normals.png` — 青＝表面が見えている、赤＝裏面が見えている
- `SHEET_clay.png` / `SHEET_wire.png` — 粘土表示とワイヤーフレーム。ライトはカメラ基準で、全方向同じ条件
- `SHEET_original.png` — インポートしたままの材質
- `SHEET_legacy588_oldlight.png` / `SHEET_legacy588_relit.png` — 原因特定のためのA/B比較
- `HEAD_VS_CANONICAL_LAYER0_UNCALIBRATED.png` — 正式Layer 0四面図の頭部切り出し（SHA照合済み）と、粘土表示・元材質の比較。**縮尺は合わせていない定性比較であり、ランドマーク照合ではない**

粘土表示で見えるFace/Body境界の線は、2つのオブジェクトの法線が不連続になっていることによる陰影の段差で、穴ではない（境界38頂点はすべて一致）。

## 11. ChatGPT側への引き継ぎ

1. 顔の比較には、今後588頂点の断片画像を使わないこと。`SHEET_clay.png`（Face＋Body頭部の完全な頭）を使う。
2. 美術QAで判断してほしい点：正式の目・鼻・あごに対して、顔のお面の形状を似せられるか（REUSE継続か、スカルプト・リトポか）。
3. 髪・帽子・メガネは別ジオメトリとして新規に制作する（HairBackは再利用しない）。
4. ライティングのある材質に移行する場合は、重ね板材質のアルファ配線を作り直す。
5. 次の工程で正式四面図と比較するには、縮尺合わせ（頭頂からあごまでを基準にする）とランドマークの注記が必要。推測による寸法合わせは禁止。
