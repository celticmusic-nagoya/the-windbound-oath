### 2.2 残っている三角形同士の交差（正直な報告）

カードの三角形と肌の三角形の交差ペアは **まだ残っています**（例: neutral でアイライン 32 / まつ毛 4、joy で 112 / 21）。基準（32 / 30、joy 248 / 105）より減っていますが 0 ではありません。交差しているのはカードの透明部分で、不透明テクセルの埋没は上表のとおり 0 です。見た目には出ない想定ですが、エンジンのアルファ処理（カットアウトかブレンドか）によっては見える可能性があり、**未解決**として扱います。

### 2.3 眼窩の見え抜け・目の突き抜け（今回追加した検査）

- 初回レンダーで、±45° から目の内側に **頭の内部が見える三日月状の抜け**（トゥーンでオレンジ、クレイで黒）を発見しました。
- 平行光線（正射影カメラ相当）を 7方向（正面、±45°、上下30°、±45°＋上30°）× 7状態で目の開口へ当て、最初に当たる不透明面が Face の裏面なら「見え抜け」として数えます。
  - 眼球半径 0.022 m: 1目あたり 106–159 本の見え抜け
  - 0.03 / 0.045 / 0.07 m を比較 → **0.07 m で全方向・全状態 0 本**
- 目の面の縁は斜め方向の被覆量（リムの奥行き × tan60°）だけ広げ、正面の肌が覆わなくなる地点で止めます（頭の外に出さないため）。
- 突き抜け検査（Basis のリム外にある目の頂点で、前方を不透明な肌が覆っていないもの）: neutral **0**。Surprised の 23 頂点（リムの外 最大 2.3 mm）は、上まぶたが Basis より大きく開くために正当に見えている部分です。
- 参考: 基準（VRoid の目の板）にも、sorrow・fun・blink で 1–3 本の見え抜けがありました。

### 2.4 目の開口・瞳孔間距離とカノン（Layer 0、U = 0.0915 m）の比較

## 5. Claude による所見（自己レビュー・美術QAではない）

良くなった点
- 引き伸ばされた VRoid の目の板が消え、正面・±45°・Surprised でも虹彩とハイライトが歪みません。紫の目はカノン（紫眼）と一致します。
- 閉眼時の目の露出と、Joy でのアイラインの肌への埋没（最大 2.5 mm）がなくなりました。

気になる点（未解決）
- 目の色は評価用の値で、確定パレットではありません。虹彩はやや明るく大きく、3D 目標 PNG の落ち着いた紫と比べると彩度が高い印象です。
- 上の §2.4 のとおり、目の形・大きさ・左右差はカノンと違います（左目が細い非対称が出ていない）。
- 下まぶたの縁に、±45° で肌色（トゥーンでは薄いオレンジ）の細い眼窩の壁が見えます。見え抜けではなく肌の表面ですが、美術的には気になる可能性があります。
- 口は VRoid のままで、U で放射状のしわと小さな穴、Angry と O で口の周りの面の段差、上唇のギザつきがあります（基準と同じ。今回は悪化していませんが、改善もしていません）。
- ゲームサイズ（64 px）では目は読めますが、32 px では虹彩と白目がほぼ一体化します。最終表示サイズは未定です。
