## Not approved
- Miku/Vocaloid/VTuber branded character models unless explicit rights for this project's specific commercial game use, derivative modification, redistribution and GitHub storage are established.
- Models from Sketchfab/BOOTH/VRoid Hub without model-specific license record.
- NC (noncommercial), ND (no derivatives), personal-use-only, unclear provenance, ripped game assets.

## Acquisition acceptance criteria
1. Official download URL, publisher, model name, version and downloaded SHA256.
2. License URL and locally preserved license notice; permission for commercial use, modification, game bundling, source-repository storage checked independently.
3. No proprietary branded textures, logos or character identity imported into Morwen.
4. Sandbox staging only, no overwrites of canonical references.
5. Five-angle render + wireframe, G1/G2/G3/G4 gates.
6. Any asset obtained without license certainty is QUARANTINED, not integrated.
