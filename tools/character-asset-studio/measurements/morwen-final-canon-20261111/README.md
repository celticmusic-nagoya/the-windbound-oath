## 名前の左右
- 名前の Left／Right は、画像の画面上の左／右（画面の既存の決まり）で、体の左右ではない。正面では画面の左がキャラクターの右、背面では画面の左がキャラクターの左。
- 側面（left／right のファイル）では脚が重なっているため、*Left を手前の脚、*Right を奥の脚とした。体の左右は決めていない。
