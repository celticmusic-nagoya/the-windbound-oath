## 固定キャンバス
- 全方向・全レイヤー共通: 1200×1600、原点は左上、+x 右・+y 下、接地 y=1540、中心 x=600。PR #229 のリグを基準にした候補で、**DERIVED_CANDIDATE**（正式な値ではない）。
- 正本からキャンバスへの変換は、方向ごとに既存の `normalized/morwen-final-canon-20261111/view_transforms.json`（SHA を固定）を明示的な行列で使う。縦横同じ倍率、せん断なし、反転なし。根拠は接地点の位置合わせだけで、体の比率は評価していない。
- 寸法の差: 正面・背面・左は 1152×1536 の RGB（透過なし）を 1.041667 倍。右は 1200×1600 の RGBA で等倍。

## レイヤー
L0 共通素体 / L1 インナー・基本衣装 / L2 制服・メイン衣装 / L3 帽子・マント・バッグ・装飾。zOrder の範囲は 0／100／200／300 から。各スロットの `image` に `{path, sha256}` を書けば、コードを変えずに差し替えられる。

## 非対称デザイン
本人の右側は、正面で画面左、背面で画面右、右向きで奥、左向きで手前。左右反転での流用は禁止。
ガーター・バッグ・帽子の花・リボンは別々の項目として、方向ごとに記録した（`qa/ASYMMETRY_LEDGER.md`）。不一致と、見えない（遮蔽の可能性がある）ものは、修正画像が納品されるまで BLOCKED。正本は変更していない。
