06 / データ入出力

運用上の制限

表示・座標記録・寸法とアルファ・SHA-256の検査を実装。身体の解剖学的整合性、デザイン一致、関節運動の自然さは自動合格にしません。素体R2.1は最終正本4方向に対して未測定のため参照不可（BLOCKED）。すべての画像は端末内で処理します。

07 / モーション参考スタジオ
