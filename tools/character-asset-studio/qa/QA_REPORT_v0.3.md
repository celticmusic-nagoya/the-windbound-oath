## Grid Overlay 解析（未承認の参考値）
- 対象: 左半分（側面）。肌色マスクから足の開き幅を求め、5コマで平滑化。極大を接地、極小を通過とし、切り出したフレームで目視確認した（フレームは保存していない）。
- 接地 F85, 140, 194, 243, 297, 349, 404, 458, 511。通過 F111, 165, 215, 267, 318, 372, 428, 483。
- 1歩 49〜55コマ（平均53.25）、1周期 103〜109コマ（平均106.3）。25fps で換算すると約4.25秒／周期・約28歩/分で、通常の歩行よりかなり遅い。スロー再生かどうかは確認していない。
- 側は A/B（交互）とし、解剖学的な左右は特定していない。F0〜84（歩き出し）と F511 以降（減速・方向転換）は除外した。関節アンカーは計測していない。
- 720p（24コマ・1秒）と Long-Stride Slow Motion（1524コマ）は、再生とコマ送りができることだけ確認した。数値は記録していない。
