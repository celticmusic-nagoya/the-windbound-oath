- 実機結果（2026-11-11）: 固定表示は実機QAで PASS（ディレクター報告）のため、固定解除・折りたたみの修正は行わない（UI改善は保留方針）。
- 判断（エミュレーション時点、参考）: 390px前後では、固定部分が画面の6〜7割を占める。ボタンは指でスクロールすれば固定部分の下に出せるが、自動スクロールやフォーカス移動では隠れる。**固定の解除または折りたたみの切り替えは必要と見込む。** ただし、本タスクの指示（実機で不具合を確認した場合のみ修正）に従い、S-1〜S-3 の実機結果を待ってから最小修正する。
- `http://192.168.x.x` のような HTTPS でないLANアドレスで開くと、ブラウザが SHA-256 計算機能（`crypto.subtle`）を無効にする。そのため、動画の読み込み（「エラー: Cannot read properties of undefined (reading 'digest')」）と、正本の照合ができない。Android 実機QAは README の HTTPS のURLで行う。
