## タスクのQA項目
1. **1枚だけ登録して12コマ比較:** 登録済み1枠・未登録11枠。未登録の枠にはスプライトを描かず（紫の画素0）、「未登録」と表示。枠数の表示あり。再利用プレビューをオンにすると11枠が「仮表示（f0を再利用・素材ではない）」になり、スタジオの登録フレームは [0] のまま。→ PASS（`motion_*_03_cycle12_missing.png`、`motion_*_04_cycle12_reuse.png`）
2. **6・8・12コマで登録済み画像が正しく表示されるか:** 12フレームすべてに、識別できる4種類の画像を順に登録。各枠のスプライトフレーム番号が期待どおりであること、同じ画像を割り当てた枠どうしは画素が同一で、違う画像の枠どうしは異なることを確認した。→ PASS（`motion_*_05_cycle12_all.png`）
3. **390px・1440px の視覚QA:**
   - 自動判定: 動画とスプライトが縦横比を保って表示領域の幅か高さいっぱいに拡大されること、拡大率がそれぞれ独立していること、「足元を揃える」後の足元の差が1.5px以内であること、キャンバスの表示サイズ、横スクロールなし、操作部品が高さ44px以上であること。
   - スクリーンショットのAI目視確認: 390pxで比較画面と再生操作が上部に固定されること、ボタンの文字が折り返さないこと、「未登録」と「仮表示」が読めること。
   - → PASS（`motion_*_06_compare_aligned.png`）。人間による目視確認は未実施。
4. **v0.2・v0.3 のデグレ:** v0.2 E2E 44/44、v0.3 のモーション項目（コマ送りの正確さ、比較、フェーズ、アンカー、JSON）は E2E に残したまま全件 PASS。
