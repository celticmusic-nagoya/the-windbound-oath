### Producer-side deterministic review packet
Python 3.11+: `python tools/production-studio/pack_review_images.py SOURCE_DIR_OR_ZIP REVIEW_SPEC_JSON OUTPUT_ZIP`.
Select only already-inspected PNG/JPEG exact paths and SHA-256 pins (max 24 images, 8 MiB each, 32 MiB total). Spec fields: repository, pr, head, stage, g2, adoption, content_reviewed, rights_reviewed, review_ref, rights_note, entry_sha256; for source ZIP additionally run_id, artifact_id, archive_sha256, archive_bytes. Boolean review flags record the producer's attestation, not verification by this tool. Use a stable isolated source; the tool verifies signatures and selected bytes, not image decoding, actual rights, or G1–G4. It produces a deterministic image-only ZIP with receipt and SHA256SUMS, verifies selected CRC/readback and refuses overwrite. It does not upload, approve publication or write native files. Producer may reuse a reviewed packet in an existing qualified checkpoint upload step, never publish private/native/raw sources. Coordinator must continue the existing exact receipt/publication gate.
